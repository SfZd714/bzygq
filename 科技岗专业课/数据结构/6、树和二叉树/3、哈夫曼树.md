# 一、哈夫曼树的基本概念

## 路径、路径长度与带权路径长度详解

# 路径（Path）

**定义**：在树结构中，从根节点到某个节点所经过的边（分支）的有序序列。

-   **示例**：在下图中，从根节点A到叶子节点D的路径是 A → B → D。

| Plain TextA/ \B C/ \D E |
| --- |

 Length）

**定义**：从根节点到某个节点所经过的边的数量（即路径的“步数”）。

-   **示例**：
-   根节点A到叶子节点D的路径长度为 2（经过A→B和B→D两条边）。
-   根节点A到叶子节点C的路径长度为 1。

 Path Length）

**定义**：树中所有节点的路径长度之和，分为两种：

1.  **内部路径长度**：根节点到所有非叶子节点的路径长度之和。
2.  **外部路径长度**：根节点到所有叶子节点的路径长度之和。

**示例**：
| Plain TextA/ \B C/ \D E |
| --- |

-   **外部路径长度**：
-   A→D：2
-   A→E：2
-   A→C：1
-   总和：2 + 2 + 1 = 5

# 节点的权（Weight）

**定义**：赋予节点的一个数值，通常表示该节点的实际意义（如字符出现的频率、优先级等）。

-   **示例**：
-   在哈夫曼树中，叶子节点的权值可能是字符的频率。
-   下图叶子节点的权值分别为：D(5)、E(9)、C(3)。

| Plain TextA/ \B(7) C(3)/ \D(5) E(9) |
| --- |

 Path Length, WPL）

**定义**：树中所有叶子节点的权值乘以其路径长度，再求和。

**公式**：

**示例**：
| Plain TextA/ \B C(3)/ \D(5) E(9) |
| --- |

-   **计算过程**：
-   C的路径长度：1 → 权值×路径长度 = 3×1 = 3
-   D的路径长度：2 → 5×2 = 10
-   E的路径长度：2 → 9×2 = 18
-   **WPL = 3 + 10 + 18 = 31**
