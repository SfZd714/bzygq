# 数组

## 数组定义

数组是一种基本的数据结构，用于存储一系列相同类型的元素，这些元素在内存中是连续存放的，可以通过一个索引来访问。数组可以是一维的，也可以是多维的，如二维数组或三维数组等。

## 数组的优点与局限性

数组是一种基础且重要的数据结构，其元素存储于连续的内存空间，并且所有元素类型相同。这种存储方式蕴含着丰富的先验信息，系统能够利用这些信息对数据结构的操作效率进行优化。

### 连续存储的优势

空间效率高：数组在内存中为数据分配了一块连续的内存块。与一些需要额外指针或标记来维护数据关系的数据结构不同，数组不需要额外的结构开销来管理元素之间的连接或层次关系。这使得数组在存储相同数量和类型的数据时，占用的内存空间相对较小，提高了空间的利用率。

支持随机访问：由于数组元素在内存中是连续排列的，并且每个元素的类型相同，因此可以通过简单的计算来确定任意元素的内存地址。对于一个具有 个元素的数组，访问其中第 个元素的时间复杂度为 O(1)O(1)O(1)。只需要知道数组的起始地址、元素的大小以及元素的索引，就可以直接定位到目标元素，这为快速获取数据提供了极大的便利。

缓存局部性好：计算机的高速缓存机制旨在减少 CPU 等待从主存中读取数据的时间。当访问数组中的一个元素时，计算机不仅仅会加载该元素，还会将其周围的其他数据一起缓存到高速缓存中。因为数组元素在内存中是连续的，后续对相邻元素的访问很可能已经被缓存，从而可以直接从高速缓存中读取数据，避免了再次访问主存的延迟，显著提升了后续操作的执行速度。

### 连续存储的局限性

插入与删除效率低：在数组中进行插入和删除操作时，尤其是当数组中元素数量较多时，需要移动大量的元素。例如，在数组的某个位置插入一个新元素，需要将该位置及之后的所有元素依次向后移动一个位置；删除一个元素时，则需要将该元素之后的所有元素依次向前移动。这些操作的时间复杂度为 O(n)O(n)O(n)，随着数组规模的增大，插入和删除操作的效率会显著降低。

长度不可变：数组在初始化时就需要确定其长度，并且在后续使用过程中长度是固定的。如果需要存储更多的元素，就需要创建一个更大的新数组，并将原数组中的所有数据复制到新数组中。这个过程涉及到大量的数据复制操作，开销很大，时间复杂度为 O(n)O(n)O(n)。同样，如果数组中的元素数量减少，原数组所占用的内存空间也不会自动缩小，造成了一定的空间浪费。

空间浪费问题：在为数组分配内存空间时，往往需要预先估计所需的空间大小。如果分配的数组大小超过了实际需要存储的数据量，那么多余的空间就会被浪费。而且由于数组长度固定，无法动态调整，这些浪费的空间在整个数组的生命周期内都无法被有效利用。

# 矩阵压缩存储

## 稀疏矩阵

### 稀疏矩阵定义

稀疏矩阵中大部分元素为0的一种特殊情况。稀疏矩阵在计算机科学中有着广泛的应用，例如在图像处理、网络分析、机器学习等领域，稀疏矩阵的存储和计算方法与普通矩阵不同，可以大大节省存储空间和计算时间。

### 稀疏矩阵的存储方法

三元组法：三元组法将稀疏矩阵中的非零元素用一个三元组（行号、列号、值）表示，并按行优先顺序存储这些三元组，这种方法可以显著减少存储空间的使用。三元组表属于顺序存储表示形式，表示各非零元素的三元组采用以行序为主序的存储结构依次存储。在三元组表中，除了存储表示元素的三元组外，还应该存储稀疏矩阵的行数、列数和非零元素的个数才能唯一的确定一个稀疏矩阵。

十字链表法：当稀疏矩阵的非零元素个数和位置在操作过程中变化较大的时，就不适合采用三元组的方式来存储稀疏矩阵。

十字链表法将稀疏矩阵中的每个非零元素用一个结点表示，每个结点包含行号、列号、值以及指向同一行和同一列的下一个非零元素的指针。

其中head表示头节点、row表示非零元素的行下标、col表示非零元素的列下标、value用于存储非零元素的值、down用于链接同一列的下一个非零元素、right用于链接同一行中的下一个非零元素。

这样，每个非零元既是某行链表中的一个节点，又是某列链表中的一个节点，构成了十字交叉的形式，故称这样的存储结构为十字链表，这种方法不仅节省存储空间，还便于进行矩阵的各种操作。

## 特殊矩阵

### 对称矩阵

对称矩阵是指元素以主对角线为对称轴对应相等的矩阵。对于对称矩阵，只需要存储主对角线及其上方或下方的元素，从而节省存储空间。

### 三角矩阵

三角矩阵是指矩阵的上三角或下三角（不包括对角线）中的元素均为一个常数或零的矩阵。根据三角矩阵的性质，可以采用压缩存储方法，只需存储对角线及其上方或下方的元素。

### 对角矩阵

对角矩阵是指所有非零元素集中在以主对角线为中心的带状区域中的 n 阶方阵，即除了主对角线上和直接在对角线上、下方若干条对角线上的元素外，所有其他元素均为0。对角矩阵可以通过存储对角线及其附近的元素来节省存储空间。

# 广义表

## 广义表的定义

广义表（Generalized Lists），也称为列表（Lists），是线性表的一种推广。线性表中的元素仅限于原子项，原子是作为结构上不可分割的成分，它可以是一个数或一个结构。而广义表中的元素既可以是原子，也可以是另一个广义表。

## 广义表的存储结构

广义表通常有两种常见的存储结构：

-   头尾表示法：

-   对于广义表中的每个节点，有三个域：标志域（tag）、指针域（hp）和指针域（tp）。

-   标志域用于区分该节点是原子节点还是子表节点。若 tag = 0，表示该节点是原子节点，此时 hp 域存储原子的值；若 tag = 1，表示该节点是子表节点，hp 域指向该子表的表头节点，tp 域指向该子表的表尾节点。

-   孩子 - 兄弟表示法：

-   每个节点也有三个域：标志域（tag）、指针域（hp）和指针域（tp）。

-   标志域同样用于区分原子节点和子表节点。若 tag = 0，hp 域存储原子的值；若 tag = 1，hp 域指向该子表的第一个子节点（孩子节点），tp 域指向该子表的下一个兄弟节点。

## 广义表的操作

广义表的基本操作包括求表头、求表尾、创建广义表、销毁广义表等，以下是使用 Java 简单模拟广义表的求表头和表尾操作的示例代码：

```java
// 定义广义表节点类class GLNode {
    int tag; // 标志域，0 表示原子节点，1 表示子表节点
    Object data; // 若为原子节点，存储原子数据；若为子表节点，存储子表引用
    GLNode hp; // 指向表头节点
    GLNode tp; // 指向表尾节点

    public GLNode(int tag, Object data, GLNode hp, GLNode tp) {
        this.tag = tag;
        this.data = data;
        this.hp = hp;
        this.tp = tp;
    }
}

// 广义表操作类public class GeneralizedList {

    // 创建广义表
    public static GLNode createList() {
        // 构建广义表 (a, (b, c))
        // 先创建原子节点 a
        GLNode a = new GLNode(0, "a", null, null);
        // 创建原子节点 b 和 c
        GLNode b = new GLNode(0, "b", null, null);
        GLNode c = new GLNode(0, "c", null, null);
        // 创建子表 (b, c)
        GLNode subList = new GLNode(1, null, b, new GLNode(1, null, c, null));
        // 构建最终广义表 (a, (b, c))
        return new GLNode(1, null, a, new GLNode(1, null, subList, null));
    }

    // 求广义表的表头
    public static GLNode getHead(GLNode list) {
        if (list != null && list.tag == 1) {
            return list.hp;
        }
        return null;
    }

    // 求广义表的表尾
    public static GLNode getTail(GLNode list) {
        if (list != null && list.tag == 1) {
            return list.tp;
        }
        return null;
    }

    public static void main(String[] args) {
        // 创建广义表
        GLNode list = createList();

        // 求表头
        GLNode head = getHead(list);
        if (head != null && head.tag == 0) {
            System.out.println("表头: " + head.data);
        }

        // 求表尾
        GLNode tail = getTail(list);
        if (tail != null && tail.tag == 1) {
            System.out.println("表尾存在");
        }
    }
}
```
