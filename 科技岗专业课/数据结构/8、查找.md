## 顺序查找

## 什么是顺序查找？

![](../_images/quesion_imgs_image_1769736256935_0_1769736256945_830.png)

**顺序查找**（Sequential Search）是一种基础查找算法，通过按数据存储的原始顺序逐个比较元素，直到找到目标值或遍历完所有元素。适用于**无序和有序序列** ，是计算机科学中最直观的查找方法之一。简单来说顺序查找的场景有点儿像大家查字的时候，从第一页开始一页一页的查找，直到找到你想要的字。

这样的逐个遍历元素和依次比较的算法，无疑是低效的，尤其是当元素出现在最后一个位置的时候查找的时间复杂度是O（n），而且数据量越大，查找速度越慢，是一种不太常用的算法。

## 顺序查找算法步骤

1.  初始化一个 “指针”（数组用索引，链表用节点引用），指向数据集合的第一个元素；
2.  比较当前指针指向的元素和目标值：

    -   如果相等，直接返回当前的位置（索引 / 节点）；
    -   如果不相等，指针向后移动一位，继续比较；

1.  重复步骤 2，直到指针遍历完整个数据集合；
2.  遍历结束后仍未找到目标值，返回一个特殊标记（比如数组返回 - 1，链表返回 null）。

## 代码实现（Java）
```
public class SequentialSearch {
    public static int search(int[] arr, int target) {
        for (int i = 0; i  target) {
            j = m - 1;          // 目标在左半区间
        } else {
            return m;           // 找到目标
        }
    }
    return -1;                  // 未找到目标
}
```

## 哈希查找

哈希查找（Hash Search）是数据结构中效率极高的查找算法，也叫散列查找，它和你之前学习的顺序查找、二分查找有本质区别 —— 后两者是 “基于遍历 / 折半缩小范围”，而哈希查找是 “基于映射直接定位”。核心逻辑：先通过哈希函数（散列函数）将数据元素的关键字映射为哈希地址（对应哈希表的索引），存储数据时存入该地址；查找时，用相同的哈希函数计算目标值的哈希地址，直接定位到该地址查找，无需遍历大量元素。它的核心优势是平均时间复杂度接近 O (1)，是实际开发中（尤其是大规模数据、高频查找场景）最常用的查找算法之一，Java 中的HashMap、HashSet底层都依赖哈希查找的思想。

## 真题
| 【国家电网2019】设某散列表的长度为 100，散列函数 H(k)=k%P，则 P 通常情况下最好选择()
A.99
B.97
C.91
D.93
答案 ：B
解析 ：在散列表设计中，使用除留余数法时，P 选择素数可更好分散键值、减少冲突。选项中仅 97 是素数 |

| 【中国铁塔2021】下列哪个查找方法的平均查找长度与查找表中数据元素个数无关？
A.哈希（散列）查找
B.顺序查找
C.折半查找
D.B+树查找
答案 ：A
解析 ：顺序查找和折半查找的平均查找长度与元素个数有关，而哈希查找通过散列函数和冲突处理确定数据存储位置，平均长度与元素个数无关 |

| 【中国铁塔2019】哈希查找中 k 个关键字具有同一哈希值，若用线性探测法将这 k 个关键字对应的记录存入哈希表中，至少要进行（）次探测
A.k
B.k+1
C.k(k+1)/2
D.1+k(k+1)/2
答案 ：C
解析 ：线性探测法中，第 1 个关键字需 1 次探测，第 2 个需 2 次……第 k 个需 k 次，总探测次数为 1+2+…+k=k(k+1)/2 |
