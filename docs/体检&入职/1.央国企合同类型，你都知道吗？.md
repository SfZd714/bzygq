# 1.央国企合同类型，你都知道吗？

现在秋招已经差不多进入尾声了，很多同学都拿到了央企、国企的offer，这里给大家讲一下央企国企合同类型以及他们之间的区别。

其实无论是社招还是校招，央国企合同类型，一般分为都分为3类：带编合同、正式合同和劳务派遣，现在一般央企无论校招和社招都是签订的正式合同，而劳务派遣则是和第三方公司签订的，不算作央企国企的正式员工。

# 带编制合同

带编合同属于前朝余孽了，很多央企研究所在转制之前一般都是有企业编制或者事业单位编制，这些单位在转制之前得员工一般都是由编制的，转制的时候也是采用新人新办法，老人老办法。以前有编制的员工保留编制，新入职的员工就不再发放编制了。

例如某些央企以前可能叫做“xxx研究院”，这些央企在转制之前都是类似事业单位的存在，因此里面。很多老员工都是带有编制的，而近些年进入的新员工除了博士之外几乎都没有编制了。

不过，即使没有带编合同，你只要跟央企签订了正式的劳动合同也是央企的正式员工，各种福利待遇和稳定性都有保障。

# 正式合同

与央企国企本体或者分公司签订的劳动合同，就是正式劳动合同，也意味着你成为了这个央企的正式员工，享受正式员工所规定的一切福利待遇，比如说五险一金、企业年金、补充医疗保险和节假日福利等。

现在对于大多数央企、国企而言，无论是社招还是校招员工都是签订的“劳动合同”，除了极少数单位、极少数岗位会给编制之外，都统一是合同工了。

虽然现在央企不给编制了，但是并不意味着不稳定，大多数上级单位100%控股的央企，只要合同期间没有违法犯罪，违反单位纪律的情况下是不会有裁员的情况发生的。没错！就算你在单位天天怼领导，也不会被裁，但是领导会不会背后搞你我就不清楚了。

央国企单位根据单位的不同，首次签订合同3年、5年和8年都有可能，我都见过，一般签2次固定期限合同之后，第三次就是无固定期限合同，对于效益较好的单位来说，只要单位不倒闭，一般也就约等于终生合同了。

虽然和私企一样，央企也是跟员工签订劳动合同，但是和私企不同的地方在于央企一般不会主动裁员，稳定性较好，到期一般没有续签风险，只要单位效益稳定，干到退休也不是不可能。

私企则不同了，随时一个业务调整，都有可能出现批量裁员的情况，并且年龄大了之后私企老板也会想方设法搞走你，不和你续签。

# 劳务派遣

劳务派遣是大多数央国企社招的时候采用的合同形式，顾名思义就是你和第三方劳务公司签订劳动合同，然后被派遣到目标央企上班，所以你并不是这个央企的正式员工。

虽然工资比较高，但是央企员工内部享受的福利待遇和晋升通道，劳务派遣员工是无法享受的，甚至无法进入这个公司的内部oa网站，该央企的系统中也没有你的名字更别说档案了。

这个模式和现在比较火热的华为OD形式比较类似，不同在于央企一般会告诉你是劳务派遣，不会给你安一个啥啥啥人才的名头，少数比较恶心的央企会用你学历不够来pua你，然后忽悠你能转正。

例如我曾经社招面试过中石油某研究所，最后面完了才告诉我是劳务派遣，也就果断拒绝了。

对于劳务派遣来说，如果你是领导的什么亲戚那么是可以先让你干几年劳务派遣然后再给你转正的，对于普通社招的牛马来说你就不要期待了。

有些东西，进去的时候没有，以后都不会有了。
