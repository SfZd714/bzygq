# 关于央国企校招的加分项

**1、硕士以上学历：**  目前大型央企集团，二级以上公司的招聘要求对于学历这块儿已经上涨到硕士研究生以上了（未明确卡985/211），所以对于学历是本科的同学，想办法考研、保研才是去央国企最基本的要求。

**2、党员优先、校级以上获奖优先、国家级奖学金优先：** 很多央国企招聘当中，会明确写明，相同情况下党员优先，大家还不是党员的同学抓紧机会入党，说不定有机会因为这个脱颖而出。星主本身是党员，在央企内部每月都会有党组织活动，党员的教育与普通员工还有所不同。

校级以上获奖和国家奖学金这个没啥好说的，同党员一样，有什么三好学生、优秀毕业生可以优先考虑。

**3、专业资格证书：** 对于某些专业来说，提前考取国家认可的专业资格证书也是有助于你在面试过程中脱颖而出的。

**4、神秘力量：** 这个需要让大家知道的是，依靠神秘力量去央国企的确实挺多的，但是并不是没有就进不去。至少我身边的同事90%都是走正规途径，靠校招、社招进去的，所以有这种情况，但是大家别过分妖魔化。

最后，其实还是那句话，核心的是学历/学校、党员、优秀学生、国家奖学金是锦上添花，有当然好，没有也不必去苛求，重点是消灭央国企就业过程中的信息差。
