# 1.央国企简历筛选流程&一些注意事项

## 一、央国企简历筛选流程

简历投递：一般央企国企都有专门的招聘网站，需要在这些网站上更新简历信息，所以相对来说投递简历较为麻烦。建议大家准备好一份简历的word版本，直接复制粘贴节省些时间。如成飞：航空工业成飞校园招聘

机器审核：国企网申一般分为两轮审核：机器筛选和人工审核。机器筛选通过关键词匹配给每个部分打分，因此关键词的准确性非常重要。例如，“大学英语4级”要明确写出来，不要简写为“CET-4”，以免机器无法识别。

人工审核：在机器筛选之后，人工审核会重点关注你的优势项目。例如，你是否是党员，是否获得过国家级奖学金，是否参加过重要赛事，以及个人掌握的技能等。这些优势内容需要放在简历的最前列，突出撰写，吸引审核人员的注意。

## 二、央国企简历注意事项

（1）教育经历的撰写

从高到低：教育经历应按照从最高学历到最低学历的顺序撰写。明确填写高考当年的录取批次。

教育类型：如果是参加统招的，应填写“全日制统分统招”，以确保信息的准确性和完整性。

（2）实习经历的描述

突出个人优点与经历：实习经历部分应贴合应聘岗位来描述，详细说明你负责的工作职责、具体完成的任务以及取得的成果，最好使用数字量化这些成果，以增强说服力。

强调岗位匹配度：描述时要重点强调你的经历如何与应聘岗位匹配，这样可以增加简历的竞争力。

（3）个人评价有没有必要写？

综合展示：个人评价部分应包括自我评价、特长爱好、论文及学术水平。虽然这部分不是必写，但建议一定要写，展示个人综合能力和求职意向。

技能匹配：可以多展示自己的组织能力、写作能力等，尽量向岗位需求靠拢。

（4）简历排版与信息完整性

简洁明了：国企所需求的简历排版要简洁明了，基本信息如学历、籍贯、专业、荣誉证书等要填写完整准确。

含金量高的内容优先：将含金量高的内容放在简历的最前面，确保在简历初次被看到时就能吸引审核人员的注意。

（5）简历页数越多越好吗？

简历页数并不是越多越好。一般来说，1-2页是最佳长度。简历应该简洁明了，突出重点。过长的简历可能会让HR感到阅读负担，难以抓住关键信息。

（6）项目经历越多越好吗？

项目经历不在于数量，而在于质量和相关性。选择那些能够展示你技能和经验的项目，特别是那些与应聘职位相关的项目。

（7）学生会主席/社团加分还是扣分？

学生会主席的经历通常是一个加分项，因为它显示了你的领导能力、组织能力和团队合作精神。但是，央国企一般不太喜欢过于高调的人，在写简历的时候请避免过于 高调。

（8）党员是加分项吗？

党员身份在某些情况下可以是一个加分项，尤其是在申请央国企或政府机构的职位时。党员身份通常表明你具有良好的政治素质和社会责任感。
