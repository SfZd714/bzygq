# 项目经历的STAR法则和三段式法则

看了很多小伙伴写的简历，项目经历的描述这块儿五花八门。但是项目经历这一块儿其实是你简历当中除了教育背景、实习经历（头部）之外最重要的就是你的项目经历。

面试官一般是**百忙之中抽点儿时间面试，然后看看你的简历**，在这个过程中**第一眼先看看你的学历，第二眼就是看你以前的工作/实习单位，然后完事儿之后就开始看你的项目经历了**，并且项目经历也是面试官花费时间最多，最关注的部分

因此，项目经历可以说是简历中最为重要的部分，而且写好项目经历的是有方法，这里浣熊老师就给大家分享两种写好项目经历的方法——STAR法则和三段式法则。

#  STAR法则

STAR法则是一种叙述经历或回答问题的结构，关于项目经历/个人经历的介绍 “STAR” 法则是一个非常有效的方法，这种方法无论是在描述技术类的经历和非技术类的经历都可以起到很好的效果。
具体来说STAR代表以下四个方面：

**Situation（情境）**：描述背景或情境，包括时间、地点、环境和相关人物。

**Task（任务）**：叙述在这个情境中你所面临或分配给你的具体任务或目标。

**Action（行动）**：详细说明你为完成任务或达成目标所采取的行动步骤。

**Result（结果）**：描述采取行动后的结果，包括成功的地方、学习到的教训、以及任何量化的成果。
例如下面这个例子清楚地展示了您在Java后台开发岗位上的技术能力和解决问题的方法，同时也表明了您在团队中的协作和沟通能力。以下是一个使用STAR法则构建的，针对Java后台开发技术岗位的面试回答示例：

**情境 (Situation)**：在xxxx年，我作为Java开发团队的一员，参与了一个旨在重构公司现有订单管理系统的项目，以提高系统性能和可扩展性。

**任务 (Task)**：我的主要任务是设计和实现一个新的RESTful API接口，该接口能够处理复杂的订单查询和处理逻辑，并确保与前端应用的无缝集成。

**行动 (Action)**：

我首先分析了现有系统的架构和性能瓶颈，与团队合作确定了重构的技术方案。
设计了RESTful API的端点，并定义了清晰的输入输出模型，以支持订单的创建、查询、更新和删除操作。
使用Spring Boot框架实现了API的开发，并利用Hibernate和JPA进行数据库操作，确保了数据的一致性和完整性。
编写了单元测试和集成测试，以确保代码质量和功能的正确性。
与前端开发团队紧密合作，确保API的可用性和易用性，通过API文档和代码审查来促进团队协作。

**结果 (Result)**：

成功按时交付了新的API接口，并在项目中实现了超过预期的性能提升，响应时间缩短了40%。
通过代码审查和自动化测试，显著提高了代码的可维护性和项目的稳定性。
新API的使用得到了前端团队的高度评价，为后续的订单管理功能提供了坚实的基础。
通过这次经历，我加深了对微服务架构和RESTful API设计的理解，并提升了我的系统设计和团队协作能力。
通过这种方式，你的项目经历将更加具体、有说服力，并能够展示你的专业能力和成就。
可以通过这个模型把自己的每一段经历写到表格里梳理一下，就会发现原本描述不清的经历，往这个模板上一套就会变得极其清晰明白。说一点题外话，在做任何项目时，都可以套一套这个模板，来让自己的任务变得更清晰。

 # 三段式法则

对于国企面试官，可能有些年龄大的没那么高级，你用STAR法则写出来的简历他可能看不懂，这里推荐一种更加简洁明了的三段式项目经历/实习经历等个人经历类的写法。
所谓三段式，其实和STAR法则异曲同工，都是完成了发现问题、解决问题、取得成果的一个完美闭环，其中面试官最关心的可能是你工作中所取得的成果，下面是三段式法则的内容：

**1、项目背景：** 简洁明了的项目背景能够让面试官快速对你的工作产生兴趣，一定要记得突出项目的来源、实验室背景、实习公司的背景等这些能让你项目显得很牛和抓住面试官眼球的东西。

**2、工作内容：** 叙述你在解决这个问题过程中发现问题、解决问题的历程，对于技术类经历写清楚你用到的技术点之类的。

**3、工作成果：** 工作成果是你项目当中最重要的部分，是你整个经历的闭环，不能说项目做了那么久最后是瞎忙，啥产出没有吧？
通过三段式法则来写上面的例子如下：

**项目背景：** 在xxxx年，我作为Java开发团队的一员，参与了一个旨在重构公司现有订单管理系统的项目，以提高系统性能和可扩展性。我的主要任务是设计和实现一个新的RESTful API接口，该接口能够处理复杂的订单查询和处理逻辑，并确保与前端应用的无缝集成。

**工作内容：**
我首先分析了现有系统的架构和性能瓶颈，与团队合作确定了重构的技术方案。
设计了RESTful API的端点，并定义了清晰的输入输出模型，以支持订单的创建、查询、更新和删除操作。
使用Spring Boot框架实现了API的开发，并利用Hibernate和JPA进行数据库操作，确保了数据的一致性和完整性。
编写了单元测试和集成测试，以确保代码质量和功能的正确性。
与前端开发团队紧密合作，确保API的可用性和易用性，通过API文档和代码审查来促进团队协作。

**工作成果：**
成功按时交付了新的API接口，并在项目中实现了超过预期的性能提升，响应时间缩短了40%。
通过代码审查和自动化测试，显著提高了代码的可维护性和项目的稳定性。
通过三段式的方式也能让你的项目经历的描述显得更加丰满，让面试官能够快速get到重点信息，增加对你经历的感兴趣程度。
