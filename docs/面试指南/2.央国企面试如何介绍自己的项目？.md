# 2.央国企面试如何介绍自己的项目？

**央国企面试如何介绍自己的项目？**

# 央国企项目经历到底看重啥？

很多朋友都有疑惑，央国企面试应该如何介绍自己的项目才能增加面试官的好感呢？

说说这个问题之前，我们不妨先想想对于应届生面试官更看重什么东西？是搬砖技巧还是牛逼哄哄的掌握一堆高大上的技术 or 技术名字的拼写？

no！其实面试官最关心的核心问题是你的学历能力和解决问题的能力，同时再有一些和工作岗位相匹配项目经历就很nice了。关于项目经历，我们核心的逻辑只有以下4点：

第一：**展示项目背景的牛逼**，让面试官对你的项目感兴趣。

第二：发现问题、解决问题的能力，进而展示自己处理工作难题的能力。

第三：预埋问题，诱导面试官问出你已经准备过的问题。

第四：展示自己的项目成果，有数据有真相，让面试官知道你不是在瞎忙活。

下面我们将从以上这三个方面来告诉大家如何在面试中介绍自己的项目，击中面试官扑通扑通的心脏（PS：当然也可能击不中，有些国企面试官就只看学历，表达能力就行）。

# 央国企，实验室做的项目就行

大多数学生都没有机会去接触真的工业项目，这个事情学生知道，面试官也知道。或许互联网面试官喜欢你的什么高并发秒杀项目，央国企的面试官确实不懂技术，但是也知道你一个学生搞不出这些东西来。

所以，拿着你们实验室的自然科学基金、横向项目、企业合作项目和你自己做的项目之类的其实央国企的面试官都认可。

如果非要排个序的话大概是大的**企业合作项目 > 横向项目 > 自然科学基金 > 自己做的项目**。

但是注意的是，如果你们实验室的横向、自然科学基金等项目和你的投递岗位的方向不一样，一定要自己做一个和岗位相关联的个人项目，否则可能面试机会都无。

比如你去应聘Java后台开发的岗位，那么一定要有相关的项目经历，对于应届生来说即使是网上的个人项目，比如什么外卖系统，商城系统，也是认可的。

但是，面试过程中不要试图把自己的项目吹得太牛逼，我知道一些网上的项目会教吹得什么高并发，秒杀系统。

但是这些东西，没有经过真实场景验证，就是一个玩具，你一个学生来谈这些高并发，秒杀系统是非常可笑的事情。

相反，你最好把你真实的在做项目过程中遇到的一些你觉得很困难的问题，作为难点，突出你的问题解决能力才是更有效的方式，面试官也可以通过这些点来展开问你一些基础知识。

# 如何展示发现问题&解决问题的能力？

所有面试的问题最终目的其实就是看你发现问题和解决问题的能力，甚至有的面试官在看完你学历觉得不错之后，只需要面试确认一下你的沟通表达能力是不是有问题就可以了。

沟通表达能力不行可以多找室友，朋友多联系，甚至你比较孤独的话每天对着镜子跟自己说话也不是不行。只要做到说话口齿清晰，不结巴就可以了，面试的时候还是得说普通话才行，更加重要的问题其实是如何让面试官发现你解决问题的能力。

**第一步（项目背景）**：首先让面试官了解你牛逼哄哄的项目背景，很多同学的履历其实非常优秀的，名校，重点实验室，然后国家重点项目 。所以呢，你介绍的时候一定要把这些东西给突出出来，比如你的重点实验室，你的大厂实习，你的国家重点项目。大多数人对你做的东西的实际内容其实并不了解的，但是对你的重点实验室，重点项目的title还是能够比较直观的了解到的。所以，直接让你的学校，实验室和实习公司为你的项目背书。（PS：没有好的项目和实习的朋友可以忽略这个）

**第二步（工作内容）：**说清楚你要解决的什么问题，不是简简单单的老师说让我做，我就直接去做了跟个机器人一样。就算是老师让你做的，你也一定要说清楚做这个东西的原因是什么。具体来说就是存在什么问题，发现问题之后你是怎么去解决的。这其实就是你发现问题和解决问题能力的体现，对于开发类的项目来说，你可以在这个期间加入说说你用了什么样子的技术来解决这个问题的。体现出你的思考问题的过程和解决问题的能力。

# 怎样预埋陷阱，让面试官正中你的下怀？

项目介绍中一定不要记流水账，我做了xxx工作，然后又做了xxx工作，你又不是一个机器光做那么多事情有什么意义。

一定要在项目介绍过程中夹杂你的私货，点出想让面试官问的问题，这里以计算机专业的为例哈，比如介绍项目的时候你可以这样说：

这个项目遭遇了上亿级的海量消息传输的性能瓶颈问题，由于随着我们项目的用户量增加而消息队列的**集群**大小并没有增加，这就导致了项目线上运行的过程中出现了**消息积压**的问题。为了解决这个问题，我们采用了**Reactor模式**来重构了消费者模块，运用了**线程池**等相关技术来提升消费效率。

在前面的这段介绍中，就刻意的提到了一些面试官可能会感兴趣的问题，或者是面试官认为比较有技术含量的问题，通过这些关键词来诱导面试官问到相关的东西。当然，提前你需要将这些东西包含的技术等内容了解清楚，准备好答题的模板。

当然，大多数央企国企没这么心机，对技术提问也不会那么深入，但是大家项目介绍的过程中一定要埋下陷阱，让面试官来提出你准备过的问题。

# 无数据不真相——项目成果的重要性。

很多同学的简历介绍项目这一块都没有项目成果，忙忙活活半天，我总得知道你干出啥成果来了吧，所以项目成果一定要说。

（1）科研项目（纵向项目）

如果你的项目是实验室的科研项目，那么你**研究取得的性能和指标的提升、发表的sci论文、发表的专利和产出的软件项目等**都可以作为你的项目成果。

（2）横向项目

横向项目一般很难有实际的产出，但是可以写例如自己完成多少个模块的开发，完成的项目成功投入实际生产环境使用等，都可以算作是项目成果。

（3）实习项目

大多数企业的实习都会有实习转正的机会，而大家实习转正一般会做一个ppt来汇总你在实习期间所做的事情，并且总结你的实习成果。所以如果大家有实习的话，实习期间的工作成果就参考你的转正答辩ppt来写就行了。

（3）玩具项目

玩具项目是比较难有啥有意义的项目成果的，所以大家可以写诸如熟悉了xxx软件的使用，熟悉了xxx技术栈，提升了学历能力等等。
