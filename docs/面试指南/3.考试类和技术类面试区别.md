# 3.考试类和技术类面试区别

**考试类和技术类面试区别**

# 面试形式区别

**（1）考试类央企面试形式**

考试类的央国企面试形式比较多样化，有结构化面试、半结构化面试、无领导小组面，也有和技术类面试比较接近的单面和问答式面试，例如：

-   银行管培生面试：无领导小组面试 + 半结构化面试

-   国家能源集团：半结构话面试 + 技术单面

-   国家电网：半结构化面试

不同国企的面试形式不同，这个需要根据最终笔试通过后再来进行针对性的面试准备，大家可以提前先了解各种类型面试的含义。

**（2）技术类央企面试形式**

技术类央国企面试的形式比较单一，大多数是技术类的单面、技术类的多面试，然后二面一般是HR提问一些通用的央国企问题即可。

# 面试内容区别

**（1）考试类央国企面试内容**

考试类央国企的面试很少涉及到技术问题，都是很简单的问问你的一些信息就算完事儿了，整个过程体验也会比较友好，例如：

-   请简单介绍一下你自己。
-   你在大学/研究生期间最自豪的成就是什么？
-   谈谈你的一次失败经历，以及你从中学到的东西。
-   你认为自己的哪些特质适合应聘的职位？
-   你在平时的研究学习中有没有遇到压力比较大的情况？你是如何处理压力和挑战？
-   你为什么选择来成都？未来有定居成都的计划嘛？

关于央国企通用面试内容，这部分后续在《浣熊手册》中会有专门的介绍，这里知识展示。

**（2）技术类央国企面试内容**

央国企技术类面试则类似于互联网面试的简单版，面试官通常也是研发部门的技术人员，因此会问问项目情况、技术八股和场景题之类的，例如中国恩菲Java后台一面：

1.自我介绍

2.rocketmq，怎么保证消费的顺序？

3.四个线程分别返回abcd，怎么全部完成之后统一返回

4.gc有做什么优化？（调整年轻代大小）

5.spring cloud有了解吗？有什么优势？

6.volatile有什么作用？

7.重排序可能会带来什么问题？

8.mysql是靠什么实现主从同步的？

9.kotlin能实现3d效果吗？跟java有什么区别？

10.如果让你负责前端和后端分配任务，你会怎么分配？哪些事情应该由前端做？哪些让后端做？

11.mysql怎么实现查询第10000到第12000之间的数据？

12.你修改数据之后，是怎么保证redis跟mysql数据一致性的？

针对于技术类央企的面试，大家一定要针对你所报的方向，好好组织和学习相关技术类面试的八股文。

# 面试成员组成区别

对于面试官的成员组成，无论是技术类央企的面试还是考试类央企的面试，组成成员都差不多，这里我们都以2面的情况来给大家说明：

**（1）一面/技术面试**

一面或者技术面试一般是科室内的技术人员（2～3人）+ 科室主任来进行面试，这个部分的面试人员很大概率是你以后要进去的科室未来的同事，他们对你的面评会直接影响到你最终的录取情况。

**（2）二面/综合面试**

二面或者综合面试一般是科室主任 + 部门领导+HR进行面试，这部分面试主要是部门的大领导对你个人进行一个面试考察，同时还有HR会对你进行相关问题的提问。

# 决策方式区别

大家作为应届生或者被面试者，一般很难了解面试官打分的流程和如何确定自己是否被录取的，这里根据技术类央企和考试类央企的不同，来给大家讲讲是如何确定面试成绩和最终录取情况的。

**（1）考试类央企**

垄断类央企的面试成绩打分比较严格，而且一般会根据一些集团内的评分要求给出你具体的分数，例如：60分、80分、90分等。

这个评价过程也是比较主观的，但是集团内部会有一些评分的标准，少数有关系的可能面试分数直接爆炸都有可能。

最后面试分数会和笔试分数一起，算出一个你的总分，来决定你最后是否能够被录取。

**（2）技术类央企**

技术类央企的面试结果的得出就相对来说比较随意了，一般是面试完了之后，几个面试官都给出一个结论，这个人“过”或者“不过”，然后科室主任根据面试官的反馈再加上自己的考量来决定过还是不够。

这里说下大领导，我们说二面或者叫综合面试过程中有个部门大领导的存在，实际上他不太懂技术，主要是根据你个人的眼缘和谈吐来打分的，所以决定你最终能否通过的其实是你同科室的未来的同事。

所以对于准备技术类央企的小伙伴，相关技术栈知识一定要扎实，这类面试也是最容易出现看学历的情况。因为大多数人，包括up本人在内，还是喜欢学历较好的候选人。

# THE END

如果是考试类央企，大家好好好准备结构化面试、无领导小组面、半结构化面试。

如果是技术类央国企，大家好好准备技术八股，同时准备一些央国企的常见问题。
