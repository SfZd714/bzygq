# 1.央国企笔试概述

## 哪些央国企需要笔试？

大多数培训机构教大家培训都是针对需要笔试的央企，然而需要笔试的央国企只是少部分垄断、半垄断央企，如中国烟草、国家电网、三桶油等。
实际上，大量的央企其实没有那么严格的考试，也不会组织正式的笔试，最多让你线上填写一个性格测试或者做一个线上的笔试题，而且笔试的内容也不完全是外面培训班所培训的行测。

所以大多数培训班培训行测都是在误人子弟，并不利于应届生扩大择业的范围，增加秋招时的央国企的选择面，光去准备考试实际上是得不偿失的。
但是，既然有央企招聘的时候需要笔试，这里本熊就给大家汇总一下哪些央国企需要笔试，并附上招聘链接，大家可以自行查看笔试内容，也可以直接参考《浣熊央企手册》当中的关于笔试内容和占比的划分。

## 央国企的笔试内容？

央国企的笔试内容不同的公司之间略有差异，但是主要分为以下三个科目：专业综合知识 + 公共基础知识 + 英语

### 专业综合知识

大家在学校学习的你们专业的专业课，以计算机专业为例就是《操作系统》、《数据结构》、《计算机组成原理》、《计算机网络》，对于电网来说还多一个信息新技术。
像中石油这类央企，专业综合知识是专门作为一次笔试来进行考试的，而电网、烟草的笔试则是和后面的公共基础知识结合在一起的，比例在50%～70%不等，所以这才是央国企笔试准备的重点。
准备的策略最全面的方法就是刷考研的专业课资料，但是央国企考试的专业课考试会简单非常多，所以不想刷那么难的题的话也可以买中公、粉笔等机构最专业的资料（但是他们的班就真的不建议报了）。

### 公共基础知识（行测）

公共基础知识的组成比较复杂，并且有些央企的笔试内容这部分还有差异，大体是以下几门课程的集合：行测 + 申论 + 企业知识 + 时事政治 ，针对于不同国企这几类内容的考试比例，参考《浣熊央企手册》当中的文章 “笔试指南3.央国企笔试内容&所占比例”，这里面会有更加全面的介绍。

#### 央国企行测 & 时事政治

经常考公的小伙伴都知道，行测包含这几部分内容：数量关系、逻辑推理、资料分析、常识题的判断、语言的理解和表达，但是央国企的笔试并不是公务员考试，也不是专门的行测考试，对于大部分国企来说行测的内容只占有20%左右，甚至更少。

时事政治这方面，大家在刷行测的时候一起关注一下，应该问题不大，考察的也不会非常多，最多1～2道题。
所以培训结构上来就给你培训行测各种刷题技巧实际上是一种本末倒置的行为，考公可以这样弄，央国企非常不建议这样弄，这样做是本末倒置的行为。

#### 央国企申论

这部分内容大多数央国企的笔试是不考低，只有烟草会有30%左右的写作题，所以如果是准备央国企笔试的话，这部分不建议作为重点准备，弄2个模板就行了。

#### 企业知识

中石油、电网、烟草等都是属于我们国家的垄断行业，因此这些央企在招聘的时候会考察一部分企业知识，考生需要提前了解下相关企业、行业的知识才能做对这部分题。

## 央国企笔试重要吗？

### 垄断类央企非常重要

这个问题不是绝对的，对于烟草、电网、三桶油、中铁和国家能源这种垄断央企来说，笔试流程非常正规，笔试内容相对固定和通用，并且不卡学历。
这一类垄断央企的笔试就非常重要，很多学校/学历非常优秀的学生，不好好准备相关笔试，简历都到不了HR手里就直接把你卡掉。
所以，这类央企也相对较为公平，不看学历、学校、项目、实验室之类的，仅仅根据你的笔试成绩、面试成绩来决定你能不能进去。
当然，也会存在有那种三代烟草人的情况，但是我们还是得去试一试的，自己尽力了就没啥好遗憾的了。

### 非垄断央企不是特别重要

半垄断、非垄断央企和军工央企等，虽然有笔试但是没那么重要，如中电29所有笔试，但是考察的全部都是专业知识，只要你专业过硬其实无需特别的去准备的。
当然这类央企你去报机构，刷行测申论肯定是别想能进去了，所以大家报国企机构真不如看b站上的免费行测申论视频。
另外，还有一些工程类央企，虽然集团硬性规定必须做一个笔试，但是笔试卷子科室主任做完就丢了，看都不看。
只要你把上面填完，笔试就算你过了，其它的主要是看学历、履历、公司和项目等东西。
