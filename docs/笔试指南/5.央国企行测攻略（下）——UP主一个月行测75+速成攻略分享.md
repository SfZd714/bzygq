# UP为什么会去学行测？

作为应届生的UP很早的时候就拿到互联网大厂的offer了，所以秋招的大部分时间都是在看一些央国企和体制内的岗位，想找个钱多又能躺平的地方。

虽然当时也拿到了很多央企的offer，但是年轻气盛的我还是嫌弃那些地方钱太少了，没技术，不能实现我的梦想。

这些想法把我作为应届生的狭隘和天真展现得淋漓尽致，如今确实是有回去抽在学校的我2巴掌的冲动。

幸运的是，在这期间我做了一件事，虽然最后没有成功，但是是到目前为止我在研三期间干得少数几件人事儿之一——参加某行政单位局考试。

当时UP主参加的是深圳市某行政单位局考试，待遇非常顶当时宣传的时候说的是到手35w+，公积金各种待遇拉满，而且还是公务员身份。

虽然当时UP主已经拿到了腾讯号称总包40w的offer，但是对这个岗位还是心动了，毕竟又是公务员，还有军装、工资还高属于是UP主的Dream 工作。

所以，正好UP主把腾讯当保底，就一心想着冲一冲深圳某行政单位局的岗位，搏一把没有遗憾。

想法虽然很好，但是UP确实一直都是走的技术路线，准备的也都是论文、项目、LeetCode之类的东西，从来没有接触过行测/申论这些内容。

那么，如何才能在短时间内（大概只有2个月时间，因为期间还要去做体检政审，UP本身还要做实验室项目，改论文什么的，综合准备时间不到一个月）拿到高分的行测和申论的分数呢？

# 我是如何做到一个月行测/申论75+的？

时间这么紧，蛮干肯定不行的，去把b站上的行测视频都刷一遍考试都特么考完了，上岸简直是天方夜谭。

所以，这种情况下肯定不能够老老实实按步就班的学习，而是应该想一种快速拿到高分的方法。

学习和考试其实是两个领域，两回事情，学习得好不代表考试能得高分，考试能拿高分也不代表你学习很好。

针对考试获得高分最为重要的手段其实并不是系统的学习，而是另外一件事情——刷题。

既然我们没有时间系统的去复习那厚厚的一本书，也没有时间去死扣每一种题型和每一种解法，那么何不跳过系统性学习的阶段，直接刷题呢？

然后从你刷的题中去总结高频高点，去总结重点知识，去行测你自己的一套解题策略，不断丰富自己的刷题技巧，然后在短时间内获得较高分数。

##  1: 先刷一张公务员行测卷子，总结自己的弱点

众所周之，行测考试的内容是**言语理解、判断推理、资料分析、数量分析、基本常识**

考试5中类型的科目，看似很多，但是大家仔细想想，言语理解不就是高中语文吗？基本常识这个不是靠日常积累吗？数量分析、资料分析实际上不就是高中数学，让你在非常非常有限的时间内解题或者在大量干扰文本中找出有用的数据并进行计算吗？

所以，对于各位至少是本科学历的大学生，我可以大言不惭的告诉大家，言语理解、资料分析、数量分析、基本常识，都是可以不用学的！！！

你现有的储备知识和行测考试的考察需要的能力，区别在于刷题速度（当然，UP知道准备公务员考试、电网、烟草还是需要系统学习的，但是至少对于应付大多数国企的行测而言，用我这套方法完全够了！）

所以，大家开始速成行测的第一步，不是先去找视频课程从言语理解啥啥啥的开始看，而且那些教行测老师自己的水平咋样其实UP也不太好评价。**反而，你应该先找一套卷子，卡时间，直接开刷，最后总结你各个模块所扣分的比例。**

我知道啥都没看过就直接开始刷题非常难受，但是请坚持，这只是一开始的一个小测试而已，卷子做完&总结，咱们就以这张卷子为蓝本开始针对性的复习。

##  2: 分析薄弱环节&原因

刷完第一套卷子之后，不出意外的话大家扣分从高到低排序应该是：**数量分析 > 判断推理 > 资料分析 > 基本常识 > 言语理解**，UP当时个人的自测结果是这样的，大家可以根据自己的实际情况来安排。下面，我来分析下这个排序的原因：

数量关系之所以扣分最多，其实不是因为不会做，而是时间不够，如果一个题给你10分钟来做其实你大概率是可以全对的，因为很多其实就是高中知识。但是由于时间卡得太死，你没那么多时间打草稿所以正确率不高，甚至做不出来。

判断推理则是由于涉及到图形推理、逻辑推理之类的，没有相关的基础和套路确实很难做对，这个其实就是我们需要去刷视频，补充的环节了。

资料分析的话，其实是整个行测中除言语理解最简单的内容，如果你第一次测试分数不高其实也没有关系，因为这个是提分最容易的部分。你如果分数不高的话，只是暂时没有掌握好正确的刷题节奏和方法。

基本常识&言语理解，这部分内容其实就属于个人的最基本的能力了，一般来说问题不会太大，最好也根据你自己的薄弱的环节来进行补足。

##  3: 补足薄弱环节知识档案，针对性补充基础知识

有了上面的分析，大家其实可以知道对于个人而言的弱点在什么地方，也知道应该针对性的去补充什么知识。

这个时候，针对大家薄弱的环节就可以去看相关的视频、课程来补充这部分的基础知识，然后做少量的练习题来巩固。

另外，针对这些你薄弱的环节，一定要建立知识档案和知识体系，在参考人家视频、课程教程的基础上，总结出一份自己的解决问题的方法和逻辑，然后在后续的刷题过程中不断、反复的去重用和优化自己的解题思路和逻辑。

这里还是推荐用脑图的方式，去把你补充的知识空白和弱点去管理起来，针对自己常错的，不明白的问题在脑图中建立档案，每次做错了都要总结归纳到一起。

这个环节具体的操作方法，见UP后续出的文档。

##  4: 疯狂刷题，完善、巩固自己的解题策略

在上面你对自己薄弱的环节有所了解，并通过专业课程的方式去学习、巩固了相关薄弱的知识点之后。（如果你告诉UP你全部是弱点，那没办法了，你还是老老实实报个班从头开始学吧～～）

就可以开始不断循环刷题，不断重复上述的方法来完善自己的知识体系结构和解题策略。

至于刷题的节奏，由于UP还有很多其它事情要做，当时是第一天刷一套行测试卷，然后第二天修改总结这套试卷，平均下来2天一套行测试卷。如果大家自律能力比较强也可以每天刷一套然后修改总结完。

这样不断的反复迭代，不断强化自己同类型题目的解决方法，丰富自己的知识体系结构，只需要很短的时间就可以获得最高的分数。

需要强调的是，针对大家的薄弱题型，一定要准备自己的解题策略和思路，别人的你容易忘记，但是自己的反复总结和反复操作的解题思路一定不会忘记。
