# 2.性格测试攻略

## 什么是性格测试？

央国企招聘当中性格测试是非常重要的一环，几乎大型的央国企在进入正式笔试、面试流程之前就会先进行性格测试，通过性格测试会直接pass掉一些性格有缺陷，心理有问题的人，避免给企业带来风险。
性格测试一般是线上机考的形式，一般是在限定时间内（通常30分钟）回答大量问题（约100题），这些问题主要涉及行为选择和性格爱好。
通过这些问题，评估考生是否适合公司的工作内容，例如抗压能力和对上司交代任务的执行力等，性格测试的结果只有通过和不通过两种，不计分。
和大家平常在网上做的性格测试，测试出你是I人还是E人的那种性格测试基本一致，但是相对来说题可能会更多，同时测试也更加准确。

##  哪些央国企会有性格测试？

几乎所有的国企在招聘时都会包含性格测试环节，例如：中航工业、航天科技、中国五矿、中国建筑、国家电网和三桶油等等。
央国企非常重视员工的性格，如果招聘到性格有缺陷的员工，会给公司和领导的管理代来巨大麻烦。
首先，大型央国企几乎不可能将其辞退，遇到性格有缺陷的人，其同事和领导可能会受到他的负面影响，影响工作的正常开展。
其次，央国企还是一个比较讲究人情世故的地方，需要员工有一定的情商和不偏激的性格，如果招聘到性格偏激的员工，可能要担心他们会影响领导管理。
总之，性格测试帮助国企筛选出性格适合岗位要求的员工，避免一些风险，毕竟央国企还是相对较为稳定的地方。
##  性格测试会刷人吗

答案是肯定的，性格测试必然会刷人，而且比较难受的是一般面试开始之前就会进行性格测试，如果性格测试都没过导致没有面试的话，既不能积累面试经验也白白浪费一次进央国企的机会。
央国企国企主要从事垄断性和基础性行业，如银行、三桶油（能源服务业）、通信运营商和建筑企业等。
对于央国企的职能岗位而言，这些职位需要每天面对客户、同事和合作伙伴，要求考生具备良好的心理素质和脾气。因此，性格测试会筛选出急躁易怒、有沟通障碍或重度强迫症的人，以降低招聘风险。
对于央国企的研发类岗位而言，由于每天打交道的是一些技术、数据之类相对枯燥但是却要求万无一失的数据之类的。因此会倾向于筛选出一些性格内向、严谨的人来从事这些岗位。
领导在面试的时候，也是会参考你的性格测试成绩来确定是否录取你的。
## 性格测试的考查点

国企招聘考试中的性格测试一般基于大五人格理论。大五人格理论是一种心理学模型，将人格特质划分为五个主要维度。这五个维度分别是：
**1. 开放性（Openness）:**
  - 特点: 开放性反映了一个人对新体验和新想法的接受程度。具有高开放性的人通常有丰富的想象力、强烈的审美观、深厚的情感体验和创造性思维。他们喜欢探索新的领域，具有求知欲和冒险精神。
  - 相关性: 在国企中，这类特质有助于员工在变化的环境中保持灵活性和创新能力，特别是在需要解决问题和创新的岗位上。

**2. 责任心（Conscientiousness）:**
  - 特点: 责任心衡量了一个人的自律性、组织能力和成就动机。高责任心的人通常表现出高度的自律、条理性、尽职尽责和谨慎小心。他们在工作中表现出很强的责任感和公正性，追求卓越和成就。
  - 相关性: 对国企来说，责任心是非常重要的，因为这些岗位通常要求员工具有高效的工作习惯和强烈的责任感，确保工作按时、高质量完成。

**3. 外倾性（Extraversion）:**
  - 特点: 外倾性反映了一个人的社交性和活力。高外倾性的人通常热情、外向、果断，喜欢社交活动和与人交往。他们通常表现出乐观和活跃，容易与他人建立联系。
  - 相关性: 在需要频繁与客户、同事或合作伙伴互动的岗位上，高外倾性的人往往更适应，能够更好地处理人际关系和团队合作。

**4. 宜人性（Agreeableness）:**
  - 特点: 宜人性衡量了一个人的利他性和合作意愿。具有高宜人性的人通常表现出信任、利他、直率、依从和谦虚。他们愿意帮助他人，具有较强的同理心和合作精神。
  - 相关性: 国企中的许多岗位需要员工能够很好地与同事、客户和合作伙伴合作，高宜人性的人能够更好地适应团队工作和服务性岗位。

**5. 神经质性（Neuroticism）:**

  - 特点: 神经质性反映了一个人的情绪稳定性和情绪反应性。高神经质性的人通常容易体验到负面情绪，如焦虑、敌对、压抑和情绪不稳定。他们在面对压力时可能会表现出更大的情绪波动。
  - 相关性: 对于国企而言，情绪稳定性是非常重要的。具有高神经质性的人在工作中可能难以保持冷静，容易出现情绪问题，影响工作效率和团队氛围。因此，在性格测试中，过多选择偏向神经质性的答案可能会降低通过测试的几率。

综上所述，国企在性格测试中更倾向于选拔那些在开放性、责任心、外倾性和宜人性方面表现较好的人，而避免录用在神经质性方面得分较高的考生。因此，在回答性格测试问题时，尽量避免选择过多表现出情绪不稳定或负面情绪的答案，这样可以提高通过测试的几率。

## 如何通过央国企的性格测试？

如前所述，只要避免选择过多偏向神经质性的答案，绝大多数考生都能轻松通过性格测试。具体注意以下几点：
###  避免选择偏激的选项:

  - 例如：当你专心工作时，有人打断你，你会选择什么选项？
    - (A) 欢迎他，放下工作询问对方什么事
    - (B) 友好地提醒他你正在工作，请稍后
    - (C) 感到非常恼怒，强硬地要求对方不要打扰
  - 避免选择C这种偏激选项，显得不太好相处。

### 避免选择过于自闭、孤独的选项:

  - 例如：参加聚会时，你倾向于？
    - (A) 一个坐在角落
    - (B) 积极与所有人交流
    - (C) 只与熟悉的人交流
    -
  - 例如：周末时，你更愿意？
    - (A) 待在家里，拒绝一切邀约
    - (B) 提前规划好周末行程
    - (C) 不主动规划，接受朋友的邀约
    -
  - 一两个选择孤独选项没问题，但所有问题都选择独自一人，可能被判定为“有沟通障碍”。

### 不要为了追求速度而误选答案:

  - 例如：你去一个派对或社交场合时，你会选择什么选项？
    - (A) 很大声地入场以引起注意
    - (B) 安静地入场，找你认识的人
    - (C) 非常安静地入场，尽量保持不被注意
  - 读清楚问题和选项，避免误选而白白失去机会。

###  不要前后选择不一致

有些性格测试题型是会前后重复的，做选择的时候一定要根据自己最真实的想法来，不要前后不一致，这样也非常扣分的。90%以上的考生直接正常回答，也能轻松通过性格测试，因此无需特别针对进行复习。除非你觉得自己性格比较孤僻、朋友较少，或有重度强迫症（轻度没事），否则不需要专门练习。
