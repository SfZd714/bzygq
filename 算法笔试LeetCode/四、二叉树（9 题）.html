适用对象：银行科技岗 / 软开中心（工行、农行、中行、建行、交行、邮储、招商银行、微众银行、渤海、城商行等）+ 运营商（中国移动、中国联通、中国电信）技术岗。

配套清单：银行与运营商校招LeetCode高频50题.md 第四部分「四、二叉树」。

使用方法：先看题目自己写一遍，再看思路与代码对照，最后脱稿在纸上或白板手写一次，直到 bugfree。

题号说明：本文沿用总清单的题号（26~34 题），便于对照复习。

一、这一专题怎么学 ​

「二叉树」是银行与运营商笔试 / 面试手撕的高频专题，也是递归思想的主战场。银行科技岗常把二叉树当「热身题 + 追问题」组合考：先来一道层序遍历 / 最大深度热身，再追问平衡二叉树、最近公共祖先这类自底向上的递归。学习时抓住四条主线：

  1. 遍历是地基：前序 / 中序 / 后序（递归 + 迭代）、层序（BFS 队列）。几乎所有二叉树题都是在遍历的基础上加工——层序遍历加工成右视图 / 自底向上 / Z 字形，中序遍历加工成验证 BST、第 K 小。递归三行模板要写到肌肉记忆，迭代法（显式栈）是面试常考加分点。
  2. 自顶向下 vs 自底向上：最大深度（后序自底向上）、平衡二叉树（后序返回高度，用 -1 标记不平衡）、验证二叉搜索树（递归带区间）。核心是「先想清楚每个递归函数返回什么、终止条件是什么」。
  3. 层序 BFS 变体：层序遍历（LC 102）、右视图（LC 199，每层取最后一个）。凡是「按层处理」的题，模板都是「队列 + 每层先记 size」，一套模板能套四题。
  4. 递归分治构造：从前序 + 中序遍历构造二叉树（LC 105）。前序定根、中序分左右，用哈希表把「值 → 中序下标」缓存起来实现 O(1) 定位。

二叉树节点定义（LeetCode 默认提供）：

java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

26. LC 144 / 94 / 145 前序·中序·后序遍历 ​

题目描述 ​

给你二叉树的根节点 root，返回它节点值的前序 / 中序 / 后序遍历结果。

三种遍历的访问顺序：

  • 前序（144）：根 → 左 → 右；
  • 中序（94）：左 → 根 → 右；
  • 后序（145）：左 → 右 → 根。

示例（中序）：

输入：root = [1, null, 2, 3]
输出：[1, 3, 2]

解题思路 ​

递归版是二叉树最基本的模板，三种顺序只差一行「访问根」的位置：

java
void dfs(TreeNode node) {
    if (node == null) return;
    // 前序：这里先访问 node.val
    dfs(node.left);
    // 中序：这里再访问 node.val
    dfs(node.right);
    // 后序：这里最后访问 node.val
}

迭代版是面试真正的考点，考察「递归转迭代 = 显式栈」：

  1. 前序 / 中序：一套「一路向左 + 栈回溯」的模板。区别只在访问时机——前序在入栈前访问根，中序在出栈后访问根；
  2. 后序：直接模拟最繁琐（要判断是否已经遍历过左右子树），推荐逆前序法——按「根 → 右 → 左」遍历，结果用头插法 / 最后反转，就得到「左 → 右 → 根」。

复杂度分析 ​

  • 时间复杂度：O(n)，每个节点访问一次。
  • 空间复杂度：O(n)，递归栈或迭代栈最深为树高（最坏 O(n)）。

Java 代码 ​

递归版（三合一模板，能默写）：

java
import java.util.ArrayList;
import java.util.List;

class Solution {
    // 前序
    public List preorderTraversal(TreeNode root) {
        List res = new ArrayList<>();
        dfs(root, res);
        return res;
    }

    private void dfs(TreeNode node, List res) {
        if (node == null) return;
        res.add(node.val);          // 前序：根
        dfs(node.left, res);
        dfs(node.right, res);
    }
}

中序递归把 res.add(node.val) 移到 dfs(node.left) 和 dfs(node.right) 之间；后序移到两个递归之后，不再重复贴出。

迭代版（前序 / 中序一套模板）：

java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    // 前序迭代：入栈前访问根
    public List preorderTraversal(TreeNode root) {
        List res = new ArrayList<>();
        Deque stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                res.add(cur.val);       // 前序：先访问
                stack.push(cur);
                cur = cur.left;         // 一路向左
            }
            cur = stack.pop();
            cur = cur.right;
        }
        return res;
    }

    // 中序迭代：出栈后访问根
    public List inorderTraversal(TreeNode root) {
        List res = new ArrayList<>();
        Deque stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;         // 先走到最左
            }
            cur = stack.pop();
            res.add(cur.val);           // 中序：出栈时访问
            cur = cur.right;
        }
        return res;
    }
}

后序迭代（逆前序 + 头插反转）：

java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.LinkedList;
import java.util.List;

class Solution {
    public List postorderTraversal(TreeNode root) {
        LinkedList res = new LinkedList<>();
        Deque stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                res.addFirst(cur.val);  // 头插 = 整体反转
                stack.push(cur);
                cur = cur.right;        // 先右后左
            }
            cur = stack.pop();
            cur = cur.left;
        }
        return res;
    }
}

面试追问要点 ​

  • 为什么后序迭代最难？后序要求「左右子树都遍历完再访问根」，需要标记第二次回到节点；逆前序法把它转化成「根右左 + 反转」，绕开了难点。
  • 递归转迭代的本质？把系统调用栈换成显式栈，前序 / 中序用一个栈就能模拟。
  • Morris 遍历 O(1) 空间？用线索指针复用空闲右指针，面试提到「了解思想」即可，手撕一般不要求。
  • 手撕建议：递归三行 + 前序 / 中序迭代「一路向左 + 栈回溯」+ 后序「逆前序」能独立默写，这是二叉树专题的第一关。

27. LC 102 二叉树的层序遍历 ​

题目描述 ​

给你二叉树的根节点 root，返回其节点值的层序遍历（逐层从左到右访问）。每一层节点值放在一个独立的列表里，结果按从根到叶子的层序排列。

示例：

输入：root = [3, 9, 20, null, null, 15, 7]
输出：[[3], [9, 20], [15, 7]]

解题思路 ​

标准 BFS + 队列，模板非常固定：

  1. 根节点入队；

  • 时间复杂度：O(n)，每个节点入队出队各一次。
  • 空间复杂度：O(n)，队列最多容纳一层的节点数（最坏是满二叉树的最后一层约 n/2）。

30. LC 236 二叉树的最近公共祖先 ​

题目描述 ​

给定一个二叉树，找到该树中两个指定节点 p 和 q 的最近公共祖先（LCA）。

最近公共祖先的定义：对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。

示例：

输入：root = [3, 5, 1, 6, 2, 0, 8, null, null, 7, 4], p = 5, q = 1
输出：3

解题思路 ​

后序递归：自底向上找，是二叉树「返回结果给父节点」的典型题。

递归函数 lowestCommonAncestor(node, p, q) 的含义：在 node 这棵子树里找 p、q 的最近公共祖先；如果只找到其中一个，就返回那个节点。

对当前节点分三种情况：

  1. node == null 或 node == p 或 node == q：直接返回 node（遇到 p / q 本身就不再往下搜，因为一个节点可以是它自己的祖先）；
  2. 左右递归结果都不为空：说明 p、q 一个在左子树、一个在右子树，当前节点就是最近公共祖先，返回 node；
  3. 只有一个不为空：说明 p、q 都在同一边，返回那一边的结果（它可能是那一边子树里算出的 LCA，也可能只是 p 或 q 本身）。

自底向上的第一个「左右都不为空」的节点，就是最近公共祖先。

复杂度分析 ​

  • 时间复杂度：O(n)，每个节点最多访问一次。
  • 空间复杂度：O(height)，递归栈深度，最坏 O(n)。

Java 代码 ​

java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) return root; // p、q 分居两侧
        return left != null ? left : right;             // 都在同一边，返回那一边
    }
}

面试追问要点 ​

  • 为什么用后序？必须先拿到左右子树的结果，才能判断当前节点是不是 LCA，天然就是「左右中」的顺序。
  • 为什么 root == p || root == q 直接返回？一个节点可以是它自己的祖先；遇到 p / q 就没必要往它的子树里再搜了。
  • 如果 p 是 q 的祖先怎么办？后序保证正确：搜到 p 时直接返回 p，q 在 p 的子树里，最终 LCA 就是 p。
  • 变体：二叉搜索树的 LCA（LC 235）？利用大小关系单边下降，p、q 都小于 root 去左，都大于 去右，否则 root 就是答案，不需要递归两边。
  • 变体：如果节点有 parent 指针？把 p 到根的路径节点存进 Set，再让 q 向上走，遇到的第一个在 Set 里的节点就是 LCA，O(height)。

31. LC 199 二叉树的右视图 ​

题目描述 ​

给定一个二叉树的根节点 root，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

示例：

输入：root = [1, 2, 3, null, 5, null, 4]
输出：[1, 3, 4]

解题思路 ​

BFS 层序（推荐）：右视图 = 每层最后一个节点。直接把层序遍历模板搬过来，在收集本层节点时判断 i == size - 1，是就加入结果。

DFS：优先遍历右子树，同时带 depth 参数；depth == res.size() 说明是这一层第一个到达的节点，加入结果。因为先走右，第一个到达某层的节点必然是这一层最右边的可见节点。

两种写法都行：BFS 更直观、不易错；DFS 代码更短，能体现对递归深度的理解。

复杂度分析 ​

  • 时间复杂度：O(n)，每个节点访问一次。
  • 空间复杂度：O(n)，BFS 队列最多一层节点；DFS 递归栈 O(height)。

32. LC 105 从前序与中序遍历构造二叉树 ​

题目描述 ​

给定两个整数数组 preorder 和 inorder，其中 preorder 是二叉树的先序遍历，inorder 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

示例：

输入：preorder = [3, 9, 20, 15, 7], inorder = [9, 3, 15, 20, 7]
输出：以 3 为根、9 为左子、20 为右子（20 的左孩子 15、右孩子 7）的二叉树

解题思路 ​

递归分治，核心是「前序定根、中序分左右」：

  1. 前序遍历的第一个元素是根；
  2. 在中序遍历里定位这个根，根左边是左子树、右边是右子树；
  3. 用左子树节点数 leftSize 回推前序里左右子树的区间；
  4. 递归构造左右子树。

复杂度分析 ​

  • 时间复杂度：O(n)，哈希表定位 O(1)，每个节点构造一次。
  • 空间复杂度：O(n)，哈希表 O(n) + 递归栈 O(height)。

33. LC 230 二叉搜索树中第 K 小的元素 ​

题目描述 ​

给定一个二叉搜索树的根节点 root 和一个整数 k，请你设计一个算法查找其中第 k 小的元素（从 1 开始计数）。

示例：

输入：root = [3, 1, 4, null, 2], k = 1
输出：1

解题思路 ​

利用 BST 中序遍历递增的性质：

  • 二叉搜索树的中序遍历结果是严格递增序列；
  • 因此「第 k 小」就是中序遍历第 k 个访问到的节点。

递归中序遍历 + 计数器：count 记录已访问节点数，数到 k 时记录答案并停止（后续用 count >= k 剪枝，不再递归）。

进阶思路：如果频繁查询，可以给每个节点维护「左子树节点数」，插入 / 删除时同步更新；查询时根据左子树大小决定去左、取根还是去右，单次降到 O(height)。面试提一嘴即可。

复杂度分析 ​

  • 时间复杂度：O(n)（最坏遍历到第 k 个前所有节点）；用子树大小进阶可到 O(height)。
  • 空间复杂度：O(height)，递归栈深度。

Java 代码 ​

java
class Solution {
    private int count = 0;
    private int result = 0;

    public int kthSmallest(TreeNode root, int k) {
        inorder(root, k);
        return result;
    }

    private void inorder(TreeNode node, int k) {
        if (node == null || count >= k) return; // 剪枝：数够了就停
        inorder(node.left, k);                  // 左
        count++;                                // 访问当前节点
        if (count == k) {
            result = node.val;
            return;
        }
        inorder(node.right, k);                 // 右
    }
}

面试追问要点 ​

  • 为什么用中序遍历？BST 中序 = 升序，第 k 小就是中序第 k 个访问的节点，这是 BST 的核心性质。
  • 能不用递归吗？迭代中序 + 计数器同样可以，且天然支持提前停止；建议两种都会。
  • 进阶：频繁查第 k 小怎么做？维护每个节点的左子树大小，查询 O(height)，插入 / 删除时更新；能说出这个方案是加分项。
  • 变体：第 k 大（剑指 54）？中序反过来「先右后左」数到第 k 个，或等价于找第「n - k + 1」小。
  • 如果树会频繁插入删除，还有更优结构吗？平衡树 / 树状数组可到 O(log n)，了解即可，银行手撕用中序即可。

## 三、总结与复盘清单

1. **遍历是二叉树的第一性原理**：前序 / 中序 / 后序（递归三行模板）+ 层序（BFS 队列）全部练到肌肉记忆；迭代法重点背「前序 / 中序一路向左 + 栈回溯」和「后序逆前序反转」，这是银行手撕的硬要求。
2. **层序模板是万金油**：LC 102（层序遍历）→ LC 199（右视图，每层最后一个）→ LC 104（最大深度，数层数）→ LC 107（自底向上，结果反转）→ LC 103（Z 字形，交替反转）。一套「队列 + size」模板能套五题，先练熟 102。
3. **自底向上的递归**：最大深度（后序 +1）、平衡二叉树（-1 标记不平衡并剪枝）、最近公共祖先（左右都不为空即答案）。三题共同的套路是「先想清楚递归函数返回什么、终止条件是什么」，再把子树结果组合成当前节点的答案。
4. **BST 一条线**：验证（区间法或中序递增）、第 K 小（中序计数）、从前序 + 中序构造（递归分治）。核心都挂在「中序递增」和「前序定根、中序分左右」两条性质上，理解性质比背代码重要。
5. **手撕建议**：这 9 题建议全部达到「5~8 分钟 bugfree」水准；层序遍历（LC 102）、最大深度（LC 104）、遍历迭代法出现率最高，也最常被当作热身题，优先练到肌肉记忆；平衡二叉树、最近公共祖先是追问概率最高的两题，重点练到能边写边讲。
6. **讲解习惯**：写完代码主动讲清时间 / 空间复杂度；碰到递归题先说「每个递归函数返回什么、空节点怎么处理」，再说主流程——面试官最在意你能否把递归讲明白，而不是默默背答案。
