# 银行、运营商校招 LeetCode 高频算法题清单（约50题，附来源标注）

> 适用对象：银行科技岗 / 软开中心（工行、农行、中行、建行、交行、邮储、招商银行、微众银行、渤海、城商行等）+ 运营商（中国移动、中国联通、中国电信）

## 总体结论

- 难度封顶 Medium，常见组合 1E + 2M；面试手撕集中在基础题。
- 刷题范围以《剑指 Offer》+ LeetCode Hot 100 为主，去重后约 200~300 题。
- 银行笔试近年编程题成趋势（招商银行、农行软开上机、微众银行等）；运营商（中国移动、中国联通）会在技术笔试/面试直接考算法编程题。
- 来源标注直接列出题目的来源公司 / 单位；属银行科技岗普遍手撕、无单一公司来源的题目，以文字直接说明（如「银行科技岗手撕高频」）。

## 备考策略（银行 + 运营商版）

1. **刷题范围**：剑指 Offer + LeetCode Hot 100 刷透即可，去重后约 200~300 题；每天 1~2 题，做到不看题解能快速给出思路。

2. **优先级三档**：

- 第一档（必会）：反转链表、两数之和、LRU、二叉树三序遍历 + 层序、快速排序、归并排序、二分查找、买卖股票 I、最大子数组和、第 K 大元素。

- 第二档（常考）：无重复字符最长子串、有效括号、最小栈、最近公共祖先、爬楼梯、打家劫舍、零钱兑换、全排列、子集、岛屿数量。

- 第三档（看余力）：滑动窗口最大值、K 个一组翻转、编辑距离、最长公共子序列、排序链表、背包类。

3. **手撕要求**：排序和 LRU 练到肌肉记忆（LRU 要求 10 分钟 bugfree）；二叉树遍历面试官常要求**迭代法**；链表反转会连环问「反转一段 / K 个一组」。

4. **笔试形式差异**：

- 银行：多数大行笔试以行测 + 计算机基础（选择题）为主，编程题近年成趋势（招商银行、农行软开上机、微众银行等）；难度 Easy~Medium。

- 运营商：中国移动 / 中国联通会在技术笔试 / 面试中直接考算法编程题（如中国联通 IT 岗 3 题：快排、最长无重复子串、第 K 大），同时喜欢让你**讲清算法原理与复杂度**（快排最坏情况、哈希冲突解决、DP vs 贪心适用场景）。

5. **SQL 不能丢**：银行非常重视数据库，笔试常配 SQL 题（牛客网 SQL 专项练习）。

6. **八股准备**：银行 / 运营商技术面试八股较浅，掌握数据结构、OS、网络、数据库基础即可，不必深挖。
