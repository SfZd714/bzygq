## 一、这一专题怎么学

「动态规划」是银行与运营商笔试 / 面试中**区分度最高**的专题：入门题人人会写，但面试官更看重你能不能讲清「状态怎么定义、转移方程怎么来、边界怎么初始化」。学习时抓住四条主线：

1. **DP 三步法**：先定义状态（`dp[i]` 或 `dp[i][j]` 表示什么），再写状态转移方程，最后确定边界初始化与循环方向。几乎所有 DP 题都套这一个框架，面试官追问的也永远是这三步。
2. **一维线性 DP**：爬楼梯（斐波那契）、打家劫舍（相邻互斥）。套路是「第 i 个状态由前面若干状态转移而来」，空间通常能压缩成滚动变量 O(1)。
3. **买卖股票系列**：一次买卖（LC 121，维护历史最低价）→ 多次买卖（LC 122，贪心累加正收益）。招商银行笔试连考两道，是「DP vs 贪心」对比的最佳素材。
4. **二维 DP 两张模板**：路径类（不同路径，`dp[i][j] = dp[i-1][j] + dp[i][j-1]`）和字符串类（编辑距离、最长公共子序列，`dp[i][j]` 表示「前 i 个 vs 前 j 个」）。先画一张 3×3 小表推一遍，再写代码。
5. **背包类**：零钱兑换（LC 322）是完全背包求最小值，每种硬币无限用。能分清「完全背包 vs 0-1 背包」「贪心 vs DP」是运营商八股里的加分点。

DP 三步法的通用骨架（面试时先背这四行，再往里面填）：

```java
// 1. 定义状态：dp[i] 表示「前 i 个 / 到达 i 的最优值」
// 2. 状态转移：dp[i] 由哪些前面的状态推出
// 3. 边界初始化：dp[0]（或 dp[1]）赋初值
// 4. 按转移方向从小到大填表，返回 dp[n]
int[] dp = new int[n + 1];
dp[0] = 边界值;
for (int i = 1; i  prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
}
```

### 面试追问要点

- 为什么贪心是对的？每个上涨区间拆成逐日交易，收益和等于区间的「峰 - 谷」，全部累加就是最大总利润。
- 和 121 的对比？121 只能交易一次求最大差值；122 多次交易直接累加正收益，这是最常被追问的对比题。
- 能否用 DP 状态机？可以：`dp[i][0]` 表示第 i 天不持有、`dp[i][1]` 表示第 i 天持有，转移就是买入 / 卖出 / 不动。追问时能补出状态机是加分项。
- 「同一天先卖后买」为什么不影响结果？等价于第 i 天「昨天卖 + 今天买」，相邻差累加的总收益不变。
- 招商银行笔试原题（贪心解），和 121 连在一起考的概率很高。

## 38. LC 198 打家劫舍

### 题目描述

你是一个专业小偷，计划偷窃沿街房屋。每间房内藏有现金 nums[i]，但不能偷相邻的两间，否则会触发报警。求能偷到的最大金额。

```
示例：
输入：nums = [2, 7, 9, 3, 1]
输出：12（偷第 1、3、5 间：2 + 9 + 1）
```

### 解题思路

定义 `dp[i]` = 前 i 间房屋能偷到的最大金额。对第 i 间房屋只有两种决策：

- 不偷第 i 间：`dp[i] = dp[i-1]`
- 偷第 i 间：`dp[i] = dp[i-2] + nums[i]`

取较大者。注意「前 i 间」的状态天然包含了「第 i 间不偷」的情况，不用单独判断。
边界：`dp[0] = nums[0]`，`dp[1] = max(nums[0], nums[1])`。

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n)，可滚动压缩到 O(1)。

### Java 代码

```java
class Solution {
    public int rob(int[] nums) {
        if (nums.length == 1) return nums[0];
        int[] dp = new int[nums.length];
        dp[0] = nums[0];
        dp[1] = Math.max(nums[0], nums[1]);
        for (int i = 2; i  amount ? -1 : dp[amount];
    }
}
```

### 面试追问要点

- 为什么初始化成 amount+1 而不是 Integer.MAX_VALUE？amount+1 已经大于任何可行解，且不会像 Integer.MAX_VALUE 那样加 1 溢出。
- 完全背包和 0-1 背包的区别？0-1 背包每种硬币只能用一次、内层倒序；完全背包无限用、内层正序。这是八股常考点。
- 贪心为什么不一定对？coins = [1, 3, 4]、amount = 6，贪心取 4+1+1 用 3 枚，但最优是 3+3 用 2 枚。所以必须 DP。
- 怎么判断凑不出？dp[amount] 仍等于初始大数 amount+1，说明不可达，返回 -1。
- 变体 LC 518 零钱兑换 II 求方案数？`dp[i] += dp[i - coin]`；要求「组合数」时先遍历硬币再遍历金额。

## 40. LC 72 编辑距离

### 题目描述

给你两个单词 word1 和 word2，求把 word1 转换成 word2 所使用的最少操作数。你可以对 word1 执行三种操作：插入一个字符、删除一个字符、替换一个字符。

```
示例：
输入：word1 = "horse", word2 = "ros"
输出：3
```

### 解题思路

定义 `dp[i][j]` = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数。分两种情况：

- `word1[i-1] == word2[j-1]`：这两个字符已相等，不用操作，`dp[i][j] = dp[i-1][j-1]`。
- 不相等：取三种操作的最小值再加 1
  - 删除 word1 的第 i 个字符：`dp[i-1][j] + 1`
  - 在 word1 中插入一个字符来匹配 word2 的第 j 个字符：`dp[i][j-1] + 1`
  - 替换 word1 的第 i 个字符：`dp[i-1][j-1] + 1`

边界：`dp[i][0] = i`（word1 全删成空串）、`dp[0][j] = j`（空串插入成 word2）。填表方向从左到右、从上到下。

### 复杂度分析

- 时间复杂度：O(m×n)。
- 空间复杂度：O(m×n)，可滚动压缩为 O(n)。

### Java 代码

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        // 边界：一个串为空
        for (int i = 0; i <= m; i++) dp[i][0] = i;
        for (int j = 0; j <= n; j++) dp[0][j] = j;

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(dp[i - 1][j],          // 删
                               Math.min(dp[i][j - 1],          // 插
                                        dp[i - 1][j - 1])) + 1; // 换
                }
            }
        }
        return dp[m][n];
    }
}
```

### 面试追问要点

- 三个操作怎么对应三个转移？删除对应 dp[i-1][j]（word1 少一个字符），插入对应 dp[i][j-1]（word2 少一个字符），替换对应 dp[i-1][j-1]（两边各少一个）。
- 为什么必须用二维状态？两个字符串各自的推进进度都要记录，一维装不下「两个前缀」的关系。
- 边界为什么是 i 和 j？一个串为空时只能靠全删或全插，操作数正好等于另一个串的长度。
- 空间优化怎么做？dp 每一行只依赖上一行和当前行，可以滚动成一行 O(n)。
- 银行科技岗手撕高频，能画 3×3 dp 表讲解比背代码更能拿高分。

## 41. LC 62 不同路径

### 题目描述

一个机器人位于 m×n 网格的左上角，每次只能向下或向右移动一步，求到达右下角有多少条不同的路径。

```
示例：
输入：m = 3, n = 7
输出：28
```

### 解题思路

定义 `dp[i][j]` = 到达网格 (i, j) 的路径数。机器人只能从上方或左方到达当前位置，所以：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

边界：第一行只能一直向右、第一列只能一直向下，路径数都是 1。
另一种等价思路是组合数：总共要走 m+n-2 步，从中选 m-1 步向下，即 C(m+n-2, m-1)。

### 复杂度分析

- 时间复杂度：O(m×n)。
- 空间复杂度：O(m×n)，可滚动压缩为 O(n)。

### Java 代码

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for (int i = 0; i < m; i++) dp[i][0] = 1; // 第一列
        for (int j = 0; j < n; j++) dp[0][j] = 1; // 第一行

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### 面试追问要点

- 为什么第一行第一列全是 1？因为只能走直线，只有一种走法。
- 加障碍物（LC 63）？遇到障碍物的格子 dp = 0，初始化边界时也要跳过障碍。
- 空间优化？一维滚动 `dp[j] += dp[j-1]`，行内从左往右更新。
- 组合数做法？C(m+n-2, m-1)，但中间乘积可能溢出 int，建议用 long 或用 DP 表更稳。
- 这题是「路径类二维 DP」的模板题，理解了它的转移方向，很多网格 DP 都能套。

## 42. LC 1143 最长公共子序列

### 题目描述

给定两个字符串 text1 和 text2，返回它们的最长公共子序列的长度。子序列不要求连续，但字符的相对顺序必须一致；如果不存在公共子序列返回 0。

```
示例：
输入：text1 = "abcde", text2 = "ace"
输出：3（"ace"）
```

### 解题思路

定义 `dp[i][j]` = text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度。分两种情况：

- `text1[i-1] == text2[j-1]`：这两个字符可以接上，`dp[i][j] = dp[i-1][j-1] + 1`。
- 不相等：只能二选一跳过一个字符，`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。

边界：i = 0 或 j = 0 时 dp 为 0（空串没有公共子序列）。填表从左到右、从上到下。

### 复杂度分析

- 时间复杂度：O(m×n)。
- 空间复杂度：O(m×n)，可滚动压缩为 O(n)。

### Java 代码

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[m][n];
    }
}
```

### 面试追问要点

- 为什么不等时取 max(dp[i-1][j], dp[i][j-1])？text1 的第 i 个或 text2 的第 j 个至少有一个不在公共子序列里，两种情况都试、取更大。
- 和「最长公共子串」的区别？子串必须连续：相等时 dp[i-1][j-1] + 1，不等时 dp[i][j] = 0（清零），最后取全局最大；子序列通过「跳过」容忍不连续。
- 子序列不要求连续体现在哪？转移里的「跳过」分支就是允许不连续的关键。
- 变体：打印出 LCS？可以从 dp 表右下角回溯，或者记录转移方向。
- 和编辑距离的相似点？都是「前 i 个 vs 前 j 个」的二维 DP，一张表可以对比记忆。

## 三、总结与复盘清单

1. **DP 三步法万能框架**：先写「状态定义 dp[i] 或 dp[i][j] 表示什么」，再写「状态转移方程」，最后补「边界初始化 + 循环方向」。面试官最在意你能不能把每一步讲清楚，而不是默默写代码。
2. **一维线性 DP 两题模板**：爬楼梯（斐波那契，dp[i] = dp[i-1] + dp[i-2]）、打家劫舍（相邻互斥，dp[i] = max(dp[i-1], dp[i-2] + nums[i])）。共同套路是「第 i 个状态由前面若干状态转移」，空间通常能压到滚动变量 O(1)。
3. **二维 DP 两张模板**：路径类（不同路径，dp[i][j] = dp[i-1][j] + dp[i][j-1]）与字符串类（编辑距离 / 最长公共子序列，dp[i][j] 表示「前 i 个 vs 前 j 个」）。填表方向都是「左上 → 右下」，先画 3×3 小表推一遍再写代码。
4. **买卖股票系列**：一次买卖（LC 121）维护历史最低价；多次买卖（LC 122）贪心累加正收益。能补一句「122 也可写成持有 / 不持有两状态的 DP」是加分项，运营商的面试官尤其爱对比 DP 与贪心的适用场景。
5. **背包边界要分清**：零钱兑换是完全背包（硬币无限、内层正序、求最小值），和 0-1 背包（每种一次、内层倒序）别混；贪心对零钱兑换不一定对，coins = [1, 3, 4]、amount = 6 的反例要会讲。
6. **手撕建议**：爬楼梯、打家劫舍、不同路径、买卖股票 I 是「必拿分」的入门题，练到 5 分钟 bugfree；零钱兑换是银行笔试原题高频，要能 8 分钟写出带边界判断的完整版；编辑距离、最长公共子序列属于「讲清思路比背代码更重要」的题，建议 10 分钟 bugfree，并会画 dp 表。
7. **讲解习惯**：写完主动报时间 / 空间复杂度；DP 题先讲「dp[i] 表示什么、转移方程怎么来的、边界怎么初始化」，再说主循环——这套话术说下来，面试官基本就知道你真正理解了 DP。
