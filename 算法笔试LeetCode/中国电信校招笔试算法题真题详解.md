## 一、30 秒结论

1.  **考不考**：中国电信研发 / 计算机类岗位笔试一定考编程题，形式为机考 ACM 模式，需自行处理输入输出；通信 / 理工类岗位一般不设独立编程大题，可能只以代码阅读、程序逻辑辨析等客观题形式出现。
    
2.  **考多难**：集团统一笔试的编程题以 Easy 送分题为主（判断两位数、RGB 交换、赛跑排名），是三大运营商里编程题最友好的；但天翼云、数字智能科技分公司会出现 Medium 难度（数位统计、前缀和 / 异或区间计数、递归 / DFS、枚举推公式），部分题目有超时坑。
    
3.  **题型结构**：主流是「行测 + 专业基础 + 编程」三件套。编程题通常 2~3 道、每题 20 分；真正拉开差距的常常是行测速度与专业基础知识，而不是编程题。
    
4.  **怎么准备**：编程保底刷熟 Easy 全对，再补「7 好数」「区间整除 / 异或计数」这两类前缀和 + 哈希模板；专业基础与行测要同步投入，缺一不可。

## 三、真题汇总（按年份与公司批次）

### 3.1 集团统一笔试·计算机卷（2025 秋招·第一批）

时长 2 小时，共 25 道行测（2 分 / 题）+ 25 道专业基础（2 分 / 题，覆盖网络、C 语言、数据结构、操作系统、概率统计）+ 3 道编程题（20 分 / 题）。

1.  判断两位数（Easy，签到题）：输入整数 n，10 ≤ n ≤ 99 输出 YES，否则 NO。
    
2.  RGB 交换排序（Easy）：给定 R、G、B 三个字符乱序排列，任意两两交换，求排成 RGB 顺序所需的最小交换次数。
    
3.  赛跑排名（Easy）：a、b、c、d 四名选手各自给出完成的圈数和距起跑线距离，求 a 的排名。
    

### 3.2 集团统一笔试·开发类（2024-10-26，2025 届秋招）

结构为 15 行测 + 15 专业知识 + 2 道编程题。

1.  7 好数统计（Medium）：统计 \[1, n\] 内首位与末位均为 7 的正整数个数（如 7、77、707、7997）。
    
2.  区间整除条件计数（Medium）：给定数组 a 与整数 x、k，求恰好包含 k 个能被 x 整除元素的连续子区间个数。
    

### 3.3 集团·第二次算法笔试（2024 秋招，算法岗加场，约 10-27）

共 2 道编程题，难度整体高于集团第一批。

1.  连号好数计数（Easy~Medium）：统计 \[1, n\] 内十进制数位「每一位比上一位多 1」的数字个数（如 1、2、…、9、12、123、1234）。
    
2.  异或前缀和区间计数（Medium）：统计满足「区间异或值等于 x 且区间长度为偶数」的非空子区间个数；另有简版：区间异或和为 0。
    

### 3.4 集团秋招（2025-09-12 / 2025-09-13）

两场均为行测 + 专业 + 3 道编程题的常规结构。

-   09-12 场次：第 1 题判断两位数，第 2 题 RGB 交换，第 3 题括号匹配最小交换次数（栈）。有考生反馈第 2 题偏难时可用暴力拿部分分。
    
-   09-13 场次（真题改编帖）：结构同上，编程题第 3 题同样考察栈与括号交换。
    

### 3.5 某批次计算机卷（2025）：末题递归 / DFS

-   末题与完全平方数相关：给定一个数字，判断用它的各位数字能否重排得到一个完全平方数。
    
-   常见做法：DFS 枚举全排列 + sqrt 判断；或预生成范围内完全平方数，再比对各位数字出现次数。考生反馈纯递归只过 20%、DFS 只过 60%，预生成平方数再匹配更稳。
    

### 3.6 天翼云（约 2024-09-12）

结构：40 道客观题 + 3 道编程题（共 60 分），时长 2 小时，难度明显高于集团卷。

1.  维护以 i 为起点的最大值序列（Easy，签到）：后缀最大值 / 滑动窗口最大值维护即可通过。
    
2.  等比数列求值（Medium）：条件可化简为 q^a = n·(q − 1) − 1 的形式，枚举公比 q 暴力可拿约 70% 分。
    
3.  数组修改最小化绝对差和（Medium~Hard）：允许修改两次数组元素，使相邻元素差的绝对值之和尽量小；贪心可拿部分分，最大差并列时需进一步讨论。
    

### 3.7 数字智能科技分公司（2025 校招）

-   结构：行测 + 专业知识 + 编程大题（约 3 道，机考 ACM 模式）。
    
-   考点方向：以数位统计、位运算、前缀和、递归 / DFS 为主，与集团卷相比更接近互联网公司笔试风格。

### 4.4 括号匹配最小交换次数（2025-09-12 / 09-13，Easy~Medium）

**题目描述**：给定一个只含左括号和右括号的字符串，左右括号数量相等（题目保证存在合法解）。每次可以交换任意两个位置的字符，求使整个字符串成为合法括号序列所需的最小交换次数。

**输入格式**：单行一个括号字符串 s。

**输出格式**：单行一个整数，表示最小交换次数。

**样例**

```undefined
输入：)(
输出：1
```

```scss
输入：()))((
输出：1
```

**解题思路**：只有一种括号时，用一次扫描代替栈：

-   维护一个计数器 bal，遇到左括号 bal += 1；
    
-   遇到右括号时，若 bal > 0 则 bal -= 1（匹配成功），否则 unmatched += 1（这个右括号没有可配对的左括号）。
    

扫描结束时 unmatched 就是「多出来的右括号」数量，它们恰好等于「多出来的左括号」数量。每交换一次最多能修正两个位置，所以最少交换次数 = ⌈unmatched / 2⌉ = (unmatched + 1) // 2。

**参考代码（Python）**

```python
s = input().strip()
bal = 0
unmatched = 0
for ch in s:
    if ch == '(':
        bal += 1
    else:
        if bal > 0:
            bal -= 1
        else:
            unmatched += 1
print((unmatched + 1) // 2)
```

**复杂度**：O(n)，空间 O(1)。

**易错点**：

-   交换的是任意两个位置，不是相邻交换；若是相邻交换，问题变为求逆序对，答案不同。
    
-   只统计一种括号类型，多类型括号时需用栈判断合法性，不能直接用本公式。

### 4.5 7 好数统计（2024-10-26 开发类，Medium）

**题目描述**：一个数称为 7 好数，当且仅当它的首位和末位都是 7，例如 7、77、707、7997、70007。给定正整数 n，统计区间 \[1, n\] 内共有多少个 7 好数。

**输入格式**：单行一个正整数 n。

**输出格式**：单行一个整数，表示答案。

**样例**

```undefined
输入：100
输出：2
```

说明：\[1, 100\] 内的 7 好数只有 7 和 77。

**数据范围**：原题 n ≤ 10^5；变体题 n 可达 10^18，需用构造法。

**解题思路**

-   暴力法（n ≤ 10^5 时足够）：遍历 7 到 n，把每个数转字符串，判断首尾字符是否均为 ‘7’。复杂度 O(n·log n)。

### 4.10 等比数列求值（天翼云，约 2024-09-12，Medium）

**题目描述**：给定正整数 n，求是否存在整数公比 q ≥ 2 与整数指数 a ≥ 1，使得 q^a = n·(q − 1) − 1。若存在，输出一组满足条件的 (q, a)。

**输入格式**：单行一个正整数 n。

**输出格式**：若存在，输出两个整数 q、a；否则输出 -1。

**样例**

```undefined
输入：3
输出：2 1
```

说明：q = 2、a = 1 时，2^1 = 2，n·(q − 1) − 1 = 3×1 − 1 = 2，成立。

**数据范围**：n 可达较大值（约 10^9 量级），枚举公比 q 到 n 会超时，需估算剪枝。

**解题思路**：由 q^a = n·(q − 1) − 1 出发，枚举公比 q，用对数估算指数 a，再回代验证：

-   对每个 q，令 target = n·(q − 1) − 1；
    
-   用 a = round(log\_q(target)) 估算指数（注意 q ≥ 2，target 需 ≥ 1）；
    
-   验证 q^a == target 且 a ≥ 1，成立即输出。
    

剪枝：q 从 2 枚举到约 n 即可，实际上 q 再大时 a 只能为 1，可直接判断 target == q。更快的做法是先估算 a 的上界（因为 2^a 增速极快，a 不会很大）。

**易错点**：0 不是正整数，不计入；两位数以上注意相邻位差值恒为 1（不允许 12、34 之外的如 13）。
