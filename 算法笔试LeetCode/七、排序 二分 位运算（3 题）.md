## 一、这一专题怎么学

排序、二分、位运算是银行 / 运营商面试「手撕基本功」里最容易被点名的三类。运营商（中国联通、中国移动）笔试直接考过手写快速排序；二分查找在考察中被列为第一档必会基本功；位运算则常以「金融数据处理」为背景考异或去重。这一专题题量不大，但要求「会写 + 会讲」：

1. **手写快速排序练到肌肉记忆**。10 分钟之内写出分治 + partition，并能在白板上讲清楚：平均 O(n log n)、最坏 O(n²) 是怎么来的、怎么避免最坏情况（随机 pivot / 三数取中）。中国联通 IT 岗笔试把快排列为 3 题之一，中国移动研究院也考。
2. **二分查找务必把边界写对**。强烈建议只用一种自己背得住的写法（本文用左闭右闭 [l, r]），并牢记「循环不变量」：区间里始终只保存还没排除的元素。二分最怕在 while 条件、mid 更新、l/r 收缩上三处不一致，导致死循环或越界。
3. **位运算记住三条异或性质**：a ^ a = 0、a ^ 0 = a、异或满足交换律与结合律。把数组全部异或一遍，成对元素抵消为 0，剩下的就是只出现一次的数。LC 136 就是这一招的招牌题，银行科技岗手撕常拿它当位运算代表题。
4. **会讲复杂度**。考官喜欢顺着快排连环追问最坏情况、稳定性、和归并排序的取舍；顺着二分追问找左边界 / 右边界、溢出防护；顺着异或追问「出现两次」「出现三次」「出现两个」的升级题。每个追问都要能接住。

## 48. 手写快速排序

### 题目描述

给定一个整数数组，要求实现快速排序，输出非递减排序后的数组。面试时不仅要能写对，还要能讲清分治思想与时间 / 空间复杂度，尤其要能解释最坏情况。

示例：

```
输入：[3, 6, 1, 8, 2, 5]
输出：[1, 2, 3, 5, 6, 8]
```

### 解题思路

快速排序是典型的分治算法：

1. 选一个基准元素 pivot（这里取区间左端元素，并用随机下标与左端交换，规避最坏情况）。
2. partition：用双指针从右向左找小于 pivot 的填到左边，从左向右找大于 pivot 的填到右边，最后把 pivot 放到最终位置。此时 pivot 左边都不大于它，右边都不小于它。
3. 递归处理 pivot 左右两个子区间，直到区间只剩一个元素。

关键点：partition 之后 pivot 已经「归位」，它不参与后续递归。

### 复杂度分析

- 时间：平均 O(n log n)；最坏 O(n²)，发生在每次 partition 都把区间分成 1 和 n-1（例如已有序数组且固定取首元素作 pivot）。
- 空间：O(log n) 递归栈（平均）；最坏 O(n)。
- 稳定性：不稳定（partition 交换会改变相等元素的相对顺序）。

## 50. LC 136 只出现一次的数字

### 题目描述

给定一个非空整数数组 nums，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。要求实现线性时间复杂度，并且只用常数级别的额外空间。

示例：

```
输入：[2, 2, 1]
输出：1

输入：[4, 1, 2, 1, 2]
输出：4
```

### 解题思路

利用异或的三大性质：

1. a ^ a = 0（自己异或自己抵消）；
2. a ^ 0 = a（与 0 异或等于自身）；
3. 异或满足交换律和结合律（与运算顺序无关）。

把数组里所有元素依次异或一遍，成对出现的元素会两两抵消为 0，最后剩下的就是那个只出现一次的数字。全程一趟遍历、一个变量，正好满足 O(n) 时间和 O(1) 空间。

### 复杂度分析

- 时间：O(n)，遍历一次数组。
- 空间：O(1)，只用一个变量。

### Java 代码

```java
class Solution {
    public int singleNumber(int[] nums) {
        int ans = 0;
        for (int x : nums) {
            ans ^= x;
        }
        return ans;
    }
}
```

### 面试追问要点

- 问：为什么异或能找出只出现一次的数？答：成对元素异或为 0，0 异或任何数得它本身，且异或满足交换结合律，顺序无关。
- 问：除了异或还能怎么做？答：用 HashMap 统计出现次数，O(n) 时间 O(n) 空间；但题目要求常数空间，所以异或是正解。
- 问：如果其他元素都出现三次、只有一个出现一次（LC 137）？答：对每一位统计所有数该位上 1 的个数，对 3 取余，余下的位拼起来就是答案；也可用状态机写法。
- 问：如果有两个数只出现一次，其余都出现两次（LC 260）？答：先全体异或得到 a ^ b（非零，至少有一位为 1），取最低的为 1 的那一位把原数组分成两组，两组各自异或分别得到 a 和 b。
- 问：位运算在金融数据处理里有什么用处？答：异或可用于数据校验（如 RAID 校验、网络传输校验）、查重去重、找出异常数据。

## 三、总结与复盘清单

1. **三题必须能 10 分钟 bugfree 手写**：快速排序、二分查找、只出现一次的数字。写完用边界用例自测一遍（空数组、单元素、已有序、target 在两端、全相同元素）。
2. **必须能脱稿讲清的三个原理**：
   - 快排：分治 + partition，平均 O(n log n)，最坏 O(n²) 及规避手段；
   - 二分：循环不变量与左闭右闭边界约定，防溢出写法；
   - 异或：a ^ a = 0、a ^ 0 = a、交换结合律。
3. **高频追问清单**（考官沿着这三题展开，务必准备）：
   - 快排稳定性、随机 pivot、快速选择求第 K 大；
   - 二分的左 / 右边界变体、插入位置、统计出现次数；
   - 异或升级题 LC 137、LC 260，以及校验 / 去重的应用场景。
4. **错题复盘**：如果某一题写了超过 15 分钟或有一次 bug，把它记到自己的复盘清单，隔天重写一遍；排序和二分练到「肌肉记忆」为止。
5. **与前面专题联动**：排序在「三数之和」「合并区间」「数组第 K 大」里是前置步骤；二分在有序场景都能用；位运算与「子集」的二进制枚举也有相通之处。复习时可跨专题串一遍。
