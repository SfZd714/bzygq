## 一、这一专题怎么学

「数组 / 哈希 / 字符串」是银行与运营商笔试 / 面试手撕的**第一优先专题**，出现频率最高。学习时抓住四条主线：

1. **哈希表做 O(1) 查找**：两数之和、两数组公共元素这类「找互补 / 找交集」的题，暴力是 O(n²)，用哈希表降到 O(n)。面试官常追问：哈希冲突怎么解决（链地址法 / 开放寻址）、为什么用 HashMap 而不是数组。
2. **双指针 / 滑动窗口**：三数之和（排序 + 双指针）、无重复字符最长子串（滑动窗口）、移动零（快慢指针）、合并两个有序数组（从后往前）。核心是「单调移动、不去重复计算」。
3. **排序 + 贪心**：合并区间、三数之和的前置排序。先排序让顺序有意义，再贪心地决策。
4. **字符串基本功**：替换空格（从后往前 / StringBuilder）、最长回文子串（中心扩展）。

## 1. LC 1 两数之和

### 题目描述

给定一个整数数组 `nums` 和一个目标值 `target`，请你在该数组中找出**和为目标值**的那两个整数，并返回它们的数组下标。每种输入只对应一个答案，且同一个元素不能重复使用。

示例：

```
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]  因为 nums[0] + nums[1] = 2 + 7 = 9
```

### 解题思路

暴力做法是两层循环枚举所有数对，O(n²)。优化的关键：我们想知道「对于当前数 `x`，`target - x` 是否在数组中」，这本质是一个**查找问题**。

用哈希表把「值 -> 下标」存下来，遍历一遍数组：

- 对每个元素 `nums[i]`，先查哈希表里有没有 `target - nums[i]`；
- 有就直接返回两个下标；
- 没有就把 `nums[i]` 放入哈希表，继续。

因为边遍历边存，所以不会出现「同一个元素用两次」的问题。

- 时间复杂度：O(n)，只需遍历一遍。

给定一个字符串 `s`，请你找出其中**不含有重复字符的最长子串**的长度。

示例：

```
输入：s = "abcabcbb"
输出：3  最长子串是 "abc"，长度为 3
```

### 解题思路

典型的**滑动窗口**问题。窗口用 `[left, right]` 表示，右指针不断向右扩展，把新字符加进窗口；一旦窗口内出现重复字符，就移动左指针把重复字符排除，直到窗口重新合法。

## 4. LC 53 最大子数组和

### 题目描述

给你一个整数数组 `nums`，请你找出一个具有**最大和**的连续子数组（子数组最少包含一个元素），返回其最大和。

示例：

```
输入：nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
输出：6  子数组 [4, -1, 2, 1] 的和最大，为 6
```

### 解题思路

经典 **Kadane 算法**，本质是 DP 的滚动优化。

定义「以 `nums[i]` 结尾的最大子数组和」为 `dp[i]`，则：

- 要么只取当前元素：`nums[i]`；
- 要么接在前一个最优子数组后面：`dp[i-1] + nums[i]`。

转移方程：`dp[i] = max(nums[i], dp[i-1] + nums[i])`。

直观理解：如果前面的累加和是「负的」，那它对后面只会拖后腿，不如从当前元素重新开始。答案就是所有 `dp[i]` 的最大值。

由于 `dp[i]` 只依赖 `dp[i-1]`，用一个变量滚动即可，这就是贪心版写法。

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)（滚动变量）。

### Java 代码

```java
class Solution {
    public int maxSubArray(int[] nums) {
        // cur 表示以当前元素结尾的最大子数组和
        int cur = 0;
        int maxSum = nums[0]; // 至少一个元素，不能初始化为 0
        for (int x : nums) {
            cur = Math.max(x, cur + x); // 从头开始 or 接着累加
            maxSum = Math.max(maxSum, cur);
        }
        return maxSum;
    }
}
```

### 面试追问要点

- 为什么 `maxSum` 初始化为 `nums[0]` 而不是 0？因为全负数数组时，最大子数组和是最大的负数，初始化为 0 会错误返回 0。
- 和贪心的关系？Kadane 每一步做局部最优决策（负数前缀丢弃），可视为 DP 的滚动写法。
- 进阶：要求返回最大子数组的起止下标？记录 cur 重新开始的位置即可。
- 进阶：环形数组最大子数组和（LC 918）？答案 = max(最大子数组和, 总和 - 最小子数组和)。

## 5. LC 88 合并两个有序数组

### 题目描述

给你两个按**非递减顺序**排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的有效元素数目。请你**合并** `nums2` 到 `nums1` 中，使合并后的数组同样按非递减顺序排列。

注意：`nums1` 的长度为 `m + n`，前 `m` 个是有效元素，后 `n` 个为占位 0。

### 解题思路

要求原地合并到 `nums1`。如果从前往后合并，会覆盖 `nums1` 还没读的元素，所以标准做法是**从后往前**：

- `p1` 指向 `nums1` 的最后一个有效元素（`m - 1`）；
- `p2` 指向 `nums2` 的最后一个元素（`n - 1`）；
- `p` 指向 `nums1` 的末尾（`m + n - 1`）；
- 每一轮把 `nums1[p1]` 和 `nums2[p2]` 中较大的放到 `nums1[p]`，对应指针前移；
- 最后若 `p2` 还没走完，说明 `nums2` 剩余元素比 `nums1` 所有剩余元素都小，直接拷贝过来（`p1` 剩余的天然已在位）。

### 复杂度分析

- 时间复杂度：O(m + n)。
- 空间复杂度：O(1)，完全原地。

### Java 代码

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;       // nums1 最后一个有效元素
        int p2 = n - 1;       // nums2 最后一个元素
        int p = m + n - 1;    // 合并后数组的末尾

        while (p2 >= 0) {
            if (p1 >= 0 && nums1[p1] > nums2[p2]) {
                nums1[p--] = nums1[p1--]; // 取 nums1 的较大者
            } else {
                nums1[p--] = nums2[p2--]; // 取 nums2 的较大者
            }
        }
        // 若 nums2 有剩余，直接拷贝；nums1 剩余元素天然有序且在位
    }
}
```

### 面试追问要点

- 为什么从后往前而不是从前往后？从前往后会覆盖 `nums1` 尚未比较的元素，需要额外 O(m) 空间。
- 如果面试官要求「不使用额外空间」，这道题的标准答案就是这个。
- 变体：两个有序链表的合并（LC 21）？思路类似，用哑节点 + 双指针。

## 11. 两数组的公共元素

### 题目描述

给定两个整数数组，求出它们的**公共元素**（交集）。要求：

- 结果中每个元素只出现一次（去重）；
- 时间复杂度 O(n)；
- 数组长度可能不同，元素顺序不限。

示例：

```
输入：a = [1, 2, 2, 3], b = [2, 3, 4]
输出：[2, 3]  或 [3, 2]
```

这是一道运营商研究院算法笔试中的编程能力测试真题，考查哈希集合的基本应用。

### 解题思路

**用哈希集合去重 + 判断存在**：

1. 把第一个数组的所有元素放入一个 `HashSet`；
2. 遍历第二个数组，若当前元素在集合中，说明是公共元素，加入结果集合（自动去重）；
3. 返回结果集合。

如果题目要求返回「重复出现次数取较少的交集」（即 LC 350 两个数组的交集 II），则改用 `HashMap` 计频，取两个数组中的较小出现次数。本题按原题要求，返回去重后的公共元素即可。

### 复杂度分析

- 时间复杂度：O(m + n)，m、n 分别为两个数组长度。
- 空间复杂度：O(m + n)（两个集合，最坏情况）。

### Java 代码

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List commonElements(int[] a, int[] b) {
        // 集合 1：存数组 a 的所有元素
        Set setA = new HashSet<>();
        for (int x : a) setA.add(x);

        // 集合 2：结果去重
        Set resultSet = new HashSet<>();
        for (int x : b) {
            if (setA.contains(x)) {
                resultSet.add(x);
            }
        }
        return new ArrayList<>(resultSet);
    }
}
```

### 面试追问要点

- 为什么用 HashSet？判断「是否包含」平均 O(1)，整体 O(n)。
- 如果要求保留交集出现的次数（LC 350）？用 `HashMap` 对短数组计频，再遍历长数组时减频，能降低空间。
- 两个数组都已排序？可用双指针 O(m + n)、O(1) 空间，面试时可以主动提一句展示扩展思考。

## 三、总结与复盘清单

1. **哈希表三连问**：两数之和（互补查找）、两数组公共元素（交集）、无重复字符最长子串（窗口内去重）。核心都是「用空间换时间」。
2. **双指针三种形态**：相向（三数之和）、同向快慢（移动零、移除元素）、从后往前（合并有序数组、替换空格）。
3. **排序让问题变简单**：三数之和、合并区间，都先排序再贪心 / 双指针。
4. **回文类模板**：最长回文子串记住中心扩展，奇数 / 偶数两种中心。
5. **手撕建议**：这 11 题建议全部达到「5~8 分钟 bugfree」水准；两数之和、三数之和、无重复字符最长子串、最大子数组和这 4 题是出现率最高的，优先练到肌肉记忆。
6. **讲解习惯**：写完代码主动讲清时间 / 空间复杂度，并说明「为什么不用暴力法」，这是银行 / 运营商面试官最看重的算法素养。
