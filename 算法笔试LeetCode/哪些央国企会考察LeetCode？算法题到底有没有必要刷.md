# 哪些央国企会考察 LeetCode？算法题到底有没有必要刷

先给结论，别被网上的焦虑带偏：

**90% 以上的央国企笔试不考 LeetCode，央国企面试也不会像互联网大厂那样现场手撕代码。**

这句话不是安慰，是把公开笔经、面经和真题翻过一遍之后的判断。真正会考算法的，只有一小撮「真做技术」的技术岗，而且多数是把编程放在笔试的线上机试环节，而不是面试时让你当面写代码。这篇文章就把「到底谁考、考到什么程度、你要不要刷」一次讲清。

## 一、90% 以上的央国企笔试不考 LeetCode

把央国企校招的笔试摊开看，主流是「考试型」卷子：行测 + 企业文化 + 公共基础。代表单位是国家电网、烟草、中石油、中石化、国铁集团，以及大量银行非科技岗、运营商非技术岗。这类卷子里没有编程题，LeetCode 更是完全用不上。

反面数据是撑得住的：从公开真题看，国家电网、中石油、国铁集团的笔试真题以行测、企业文化、公共基础为主，算法基本不考。

那「央国企都要刷 LeetCode」的说法是怎么传开的？三个原因。

第一，幸存者偏差。会写面经、会发帖的，恰恰是考过算法的技术岗同学；考行测进电网、烟草的同学，很少专门写一篇「我没考算法」的面经。你刷到的算法面经密度，被严重放大了。

第二，把互联网招聘的模板套到了央国企头上。大厂考算法、现场手撕，不代表央国企也这样。央国企的招聘逻辑是「稳」，考察的是能不能长期留得住，而不是编程比谁快。

第三，把个别单位的做法当成了普遍现象。确实有单位考算法，但它们是例外，不是常态。

## 二、面试不会手撕代码，央国企技术面到底考什么

先把「手撕代码」这件事说透。央国企面试的主流形式是结构化 / 半结构化面试，问的是学历、表达、综合素养、业务理解和项目经历。即便是技术岗，面试官也是以问项目、问八股原理、问业务场景为主，不会像互联网一样甩一道题让你当场在白板或共享屏上手撕。

打开央国企技术岗的典型面试流程看，普遍是：自我介绍 → 项目深挖 → 八股提问 → 业务场景 / 综合素质。全程没有「给你 20 分钟写一道算法题」这个环节。

面试里真正要准备的，是把算法原理讲清楚：快排最坏情况为什么是 O(n²)、哈希冲突怎么解决、DP 和贪心的适用场景。这是「讲」，不是「写」。

## 三、那不到 10% 会考的单位，长什么样

真考算法的单位有个共同特征：真做技术，且大多集中在银行软开、运营商研究院、军工科研院所这有限的几条赛道。下面这张表汇总了公开笔经、面经与真题回忆中出现的情况，你可以把它当成「例外清单」来读。

| 单位 | 考过的题 | 考察形式 |
|---|---|---|
| 招商银行（含信用卡中心） | LC 121 买卖股票的最佳时机、LC 122 买卖股票的最佳时机 II | 笔试原题 |
| 招商银行金融科技岗 | 笔试加试含算法题；深圳金融科技面试手撕快速排序 | 笔试加试 + 面试手撕（个案） |
| 微众银行 | LRU 缓存，要求线程安全版 | 面试手撕（个案） |
| 中国移动研究院 | 检测无向图是否存在环、LRU 缓存、手写快速排序 | 算法工程师笔试的编程能力测试 |
| 中国移动（近年技术类面试） | 二叉树层序遍历 | 技术面试编程题（个案） |
| 中国联通（近年 IT 岗） | 无重复字符最长子串、数组第 K 大、手写快速排序 | 一次笔试 3 题连考 |
| 中国电信（省分 / 地市 IT 岗） | 行测 + 专业课（408 计算机基础选择题）+ 算法编程题；江苏自主命题含三道算法题 | 线上机试，按省自主命题或集团统一命题 |
| 某军工科研院所 | 判断闰年、排序题、旋转矩阵等 6 道编程大题 | 牛客线上机试 |
| 银行科技岗 | 反转链表、两数之和、三数之和、岛屿数量、编辑距离、最近公共祖先、二叉树遍历（迭代法）等 | 笔试线上机试为主，个别分行面经出现手撕 |

这张表怎么读，说三条。

第一，真正的「面试手撕」，公开面经里能翻到的就集中在微众、招银网络科技、宁波银行这类互联网化程度最高的金融科技子公司，属于个例中的个例，不代表央国企主流。对绝大多数同学来说，不值得按这个标准去准备。

第二，这些单位覆盖两条最大的赛道：一条是银行科技岗和软开中心，工行、农行、中行、建行、交行、邮储、招商、微众、渤海、城商行都在里面；另一条是运营商，移动、联通、电信，再加上军工科研院所。但即便在这两条赛道里，编程也多数出现在「笔试线上机试」环节，而不是面试现场。

第三，两数之和是银行笔试原题里出现率最高的一题；「剑指」「Hot100」是经典高频题。真进了会考的范围，用这些资料完全够。

## 四、三个容易被高估的赛道

很多同学以为「银行总行软开考，其他地方都不考」，其实还有三个地方会上机。但你注意看，它们几乎全是笔试环节。

### 1. 中国电信，省分和地市 IT 岗笔试含算法题

电信的地市公司一般只设两类岗位，IT 岗和网络运维岗。IT 岗笔试含算法题，网络运维岗不考。笔试结构一般是行测，加 408 计算机基础的选择题，再加编程题。

先看三个省的真实情况。

江苏电信省公司自主命题，难度偏大，一张卷子里有三道算法题；浙江等地参加集团统一命题。

广州电信市分公司走牛客平台机试，考行测、数学知识和简单编程，有往届反馈称运营商笔试疑似不挂人。

湖南电信笔试跟普通私企一样考 408，数据结构、操作系统、网络、组成原理都来，技术底子不能虚。

把电信的题再往细里看，集团统一卷其实比想象中温柔。近年秋招某批计算机卷，2 小时 25 道行测加 25 道专业基础，再加 3 道编程题，3 道编程全是送分题：判断两位数、RGB 交换排序、赛跑排名。真正拉分的反而是行测速度跟专业基础。到了天翼云、数字智能科技分公司这类子公司，编程题才升到 Medium，数位 DP、前缀和加异或区间计数、递归判断完全平方数，部分题目还有超时坑。

所以电信省分和地市的技术岗不是纯行测。算法和计算机基础都要准备，只是各省难度差得很远，江苏这类自主命题省明显更难。

### 2. 银行金融科技岗，笔试加试为主，面试手撕是个案

总行软开中心考编程，分行金融科技岗照样考，还会加试算法。举几个例子。

招商银行金融科技岗有笔试加试环节，一小时纸质试卷，20 道客观题加 3 道主观题，考数据库、系统设计、项目管理、算法。这里是笔试加试，不是面试。

招银网络科技在公开面经里能翻到比较密集的手撕：手撕 Python 编程题涉及链表，给 10 分钟做一道 DFS 类型的题，判断 s2 是不是 s1 全排序的一种，用哈希表统计一串数字里每个数字重复出现的次数。同一场面试塞进这么多手撕，节奏很快。但招银网络科技是招商银行旗下互联网化程度很高的科技子公司，属于个案中的个案。

宁波银行金融科技岗定向面试，出现过手撕算存款 10 年后本息的题，要区分单利和复利，直接用 Java 写一个计算器。题目本身不难，特别贴银行业务，但这同样是金融科技岗定向面试里的个案，不是央国企面试的普遍形态。

微众银行再往上走一层，面试手撕 LRU 缓存，还要求线程安全版。这家银行互联网化程度高，属于最接近大厂手撕的一档。但它恰恰说明：连这种最「卷」的单位，手撕的也是 LRU、快排这类基础题，跟大厂 Hard 白板题完全两个量级。

### 3. 某军工科研院所，牛客网 6 道编程大题

军工科研院所里，计算机岗笔试上机同样典型。以某所软件开发岗应届招聘为例，笔试平台是牛客网，线上双机位监考；一共 6 道编程大题，第 5、6 题二选一；难度标的就是 LeetCode 中等及以下；回忆出来的原题有判断闰年、排序题（不指定具体算法）、旋转矩阵（LeetCode Hot100 原题）；官方备考建议就一句，以刷 LeetCode 为主即可。

注意，这里依旧是笔试线上机试。算法不刷到及格线，连笔试都过不了。

## 五、考到什么程度

如果你确认自己投的是那不到 10% 的单位，再看这张表。整体难度封顶 Medium。高频题里绝大多数是 Easy 和 Medium，只有滑动窗口最大值（LC 239）标了 Hard，而且它属于备考第三档，看余力。某军工科研院所的难度直接写在备考说明里，LeetCode 中等及以下。

准备央国企算法，不需要按大厂标准刷到 Hard。把「剑指 Offer」和 LeetCode Hot 100 刷透就够。

50 道题的专题分布见下表。

| 专题 | 题量 | 占比 | 一句话重点 |
|---|---|---|---|
| 数组 / 哈希 / 字符串 | 11 | 22% | 出现率最高，两数之和、无重复字符最长子串 |
| 二叉树 | 9 | 18% | 三序遍历 + 层序，笔试机试常考 |
| 链表 | 8 | 16% | 反转链表是敲门砖，常连环追问反转一段或 K 个一组 |
| 动态规划 | 8 | 16% | 爬楼梯、打家劫舍、买卖股票是入门三件套 |
| 栈 / 队列 / 堆 | 6 | 12% | LRU、最小栈是金融科技岗最爱 |
| 回溯 / DFS / BFS / 图 / 贪心 | 5 | 10% | 岛屿数量是代表作 |
| 排序 / 二分 / 位运算 | 3 | 6% | 手写快排 + 二分查找 + 异或去重，练到肌肉记忆 |

高频题之外，有余力的同学还可以再补充 7 道变体题，练一练大厂变形题。但要记住：这是给那 10% 的同学的加餐，不是央国企校招的标配。

## 六、要不要刷，先确认你在不在那 10%

先把央国企的笔试分成两类。

一类是考试型。国家电网、烟草、中石油、国铁集团，考行测、企业文化、公共基础，算法基本不考。备考重心放在行测和企业文化上。这类单位占绝大多数。

一类是技术型。银行科技岗、金融科技岗、软开中心、运营商技术岗、电信省分 IT 岗、研究院、军工科研院所，笔试是行测加基础再加编程上机，算法是硬门槛。这类单位是少数。

判断方法不复杂。打开目标单位技术岗 JD：如果要求「熟悉常用算法与数据结构、掌握一门编程语言」，笔试大概率有算法题；如果 JD 写的是「综合素质、公文写作」，按考试型准备就行。电信 IT 岗、金融科技岗、军工科研院所软件开发岗的 JD 都属于前者。

不同岗位怎么分配时间，区别主要在算法投入的档位。

银行科技岗、金融科技岗、软开中心，笔试等于行测加计算机基础选择题加近年新增的编程题，有的分行还有笔试加试。算法刷到 Easy 到 Medium 就够用，但 SQL 也要同步准备。银行非常重视数据库，笔试常配 SQL 题，去牛客网刷 SQL 专项。

运营商技术岗和研究院，笔试和面试直接上算法编程题，还喜欢让你讲原理，快排最坏情况复杂度、哈希冲突解决、DP 和贪心的适用场景，算法权重最高。

电信省分和地市 IT 岗，行测、408 专业课选择题、算法编程题三样并行准备。江苏等自主命题省份算法题量更大，别只刷行测。

军工科研院所，牛客线上编程是主战场，把 LeetCode 中等题刷熟。官方备考建议就是以刷 LeetCode 为主。

考试型单位，电网、烟草、石油，把时间让给行测、企业文化和计算机专业课，算法按 50 道高频题的最低档准备就够。

一句定位。算法只在极少数单位卡你的笔试下限；对绝大多数央国企岗位来说，决胜局在面试本身。央国企技术面八股浅、项目深，面试官更看重业务思维、技术判断和结果意识，而且不会让你手撕代码。把省下来的时间留给项目深挖和面试表达，是投入产出比最高的选择。

## 七、备考行动清单（仅限会考的那 10%）

以下清单只适用于确认会考算法的技术岗。如果你投的是考试型单位，直接跳过，去刷行测和企业文化。

1. 整理一份银行与运营商校招 LeetCode 高频题清单，按三档优先级推进。

2. 第一档，必会，练到肌肉记忆，包括反转链表、两数之和、LRU、二叉树三序遍历加层序、快速排序、归并排序、二分查找、买卖股票 I、最大子数组和、第 K 大元素。

3. 第二档，常考，包括无重复字符最长子串、有效括号、最小栈、最近公共祖先、爬楼梯、打家劫舍、零钱兑换、全排列、子集、岛屿数量。

4. 第三档，看余力，包括滑动窗口最大值、K 个一组翻转、编辑距离、最长公共子序列、排序链表、背包类。

5. 每道题先自己写一遍，再看思路与代码，最后脱稿在纸上或白板手写一次，直到 bugfree。

6. 并行准备 SQL（牛客网 SQL 专项）和八股。央国企八股较浅，数据结构、操作系统、网络、数据库基础即可，不必深挖。

7. 投递前先查目标单位笔试形式，看是集团统一命题还是省、所自主命题。江苏电信、军工科研院所这类自主命题单位算法题量更大，再决定算法复习的投入档位。

最后再强调一遍：**90% 以上的央国企笔试不考 LeetCode，央国企面试不手撕代码**。别被网上的焦虑带偏。先确认你的目标单位在哪一类，再决定要不要刷题；技术岗里那不到 10% 的单位，用上面这份清单按档位准备就够，不需要按大厂标准刷到 Hard。
