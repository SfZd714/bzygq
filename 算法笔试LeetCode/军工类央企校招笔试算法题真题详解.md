## 一、30 秒结论

1. **考不考**：央企技术岗分两种考法。一是软件开发岗 / 算法岗基本必考编程大题，常见平台是牛客网线上机试，有的研究所一次考 6 道编程大题；二是大量研究所笔试以客观题为主（计算机基础选择题 + 特色专业题 + 行测），编程题不固定出现。总体「客观题为主、编程题看岗」。

2. **考多难**：整体封顶 Medium。某研究所备考说明直接写明「LeetCode 中等及以下」；已确认原题如判断闰年、排序题、旋转矩阵（LC 48）、全排列、链表环检测，均为 Easy~Medium。央企研究所不按互联网大厂标准卡 Hard。

3. **题型结构**：主流是「行测 + 特色公共基础 + 计算机专业客观题 + 编程（选考）」四件套。特色专业题是区别于其它央企的最大差异：航空总线（ARINC429）、实时系统调度、卡尔曼滤波、FFT / 信号处理、DO-178C 航电软件标准、嵌入式 C/C++。

4. **怎么准备**：编程按 LeetCode Hot 100 的 Easy~Medium 刷透（旋转矩阵、全排列、判断闰年、排序、链表环检测、括号匹配是高频已确认题）；计算机基础按 408 复习；再加特色专题（信号处理、实时系统、嵌入式、组合计数）。客观题与编程题两线并行，缺一不可。

### 4.1 判断闰年（某研究所，Easy）

**题目描述**：输入一个整数年份 y，判断是否为闰年并输出 YES / NO。闰年定义：能被 4 整除但不能被 100 整除，或者能被 400 整除。

**输入格式**：单行一个整数 y。

**输出格式**：单行 YES 或 NO。

**样例**

```
输入：2024
输出：YES

输入：1900
输出：NO
```

**解题思路**：按闰年定义直接写条件判断。注意「能被 400 整除」优先级最高，1900、2100 这类整百年份不是闰年。

**参考代码（Python）**

```python
y = int(input())
if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0:
    print("YES")
else:
    print("NO")
```

**复杂度**：O(1)。

**易错点**：整百年份必须被 400 整除才是闰年；不要漏掉 y % 400 == 0 的分支。

### 4.7 偶数求和（大型央企研发岗通用，Easy）

**题目描述**：实现一个函数，接受整数列表作为输入，返回列表中所有偶数的和。

**输入格式**：第一行一个整数 n；第二行 n 个整数。

**输出格式**：单行一个整数，偶数和。

**样例**

```
输入：4
1 2 3 4
输出：6
```

**解题思路**：遍历列表，用 x % 2 == 0 判断偶数并累加。

**参考代码（Python）**

```python
def sum_of_even(num_list):
    return sum(x for x in num_list if x % 2 == 0)

n = int(input())
a = list(map(int, input().split()))
print(sum_of_even(a))
```

**复杂度**：O(n)。

**易错点**：负数偶数的判断同样是 % 2 == 0，无需额外处理；注意 0 也是偶数。

### 4.8 栈的实现（Java，push / pop / peek）（大型央企研发岗通用，Easy）

**题目描述**：用数组实现一个栈，包含入栈 push、出栈 pop、查看栈顶 peek 三个方法，并处理栈满与栈空异常。

**输入格式**：接口实现题。

**输出格式**：无直接输出，方法调用语义正确即可。

**解题思路**：用一个数组 data 存储元素，top 指向栈顶下标（初始 -1）。push 时先判断是否已满，满则抛异常；pop / peek 时先判断是否为空，空则抛异常。数组扩容策略可省略（题目未要求时定长即可）。

**参考代码（Java）**

```java
public class MyStack {
    private final int[] data;
    private final int capacity;
    private int top;

    public MyStack(int capacity) {
        this.capacity = capacity;
        this.data = new int[capacity];
        this.top = -1;
    }

    public void push(int val) {
        if (top == capacity - 1) {
            throw new IllegalStateException("Stack is full");
        }
        data[++top] = val;
    }

    public int pop() {
        if (isEmpty()) {
            throw new IllegalStateException("Stack is empty");
        }
        return data[top--];
    }

    public int peek() {
        if (isEmpty()) {
            throw new IllegalStateException("Stack is empty");
        }
        return data[top];
    }

    public boolean isEmpty() {
        return top == -1;
    }
}
```

**复杂度**：push / pop / peek 均为 O(1)。

**易错点**：top 先自增再写入（data[++top]）；pop 是先取再自减（data[top--]）；满 / 空判断的边界别写反。

### 4.9 完全二叉树叶子节点数（航空类研究所客观题高频，Easy）

**题目描述**：一棵完全二叉树共有 n 个节点，求叶子节点个数。

**输入格式**：单行一个整数 n。

**输出格式**：单行一个整数，叶子节点数。

**样例**

```
输入：15
输出：8
```

**解题思路**：对于完全二叉树，最后一个非叶节点是第 n//2 个节点（编号从 1 开始），所以叶子数 = n − n//2 = (n+1) 向上取整的一半，即 (n+1)//2。这是一道以客观题形式出现的高频题，也可用此公式编程作答。

**参考代码（Python）**

```python
n = int(input())
print((n + 1) // 2)
```

**复杂度**：O(1)。

**易错点**：n 为奇数时 (n+1)//2 与 n//2 结果不同，取 (n+1)//2；n=1 时叶子数为 1，公式同样成立。

### 4.12 括号匹配（算法岗通用，Easy）

**题目描述**：给定一个只包含 ()、[]、{} 三种括号的字符串，判断括号是否合法匹配。

**输入格式**：单行字符串。

**输出格式**：合法输出 YES，否则输出 NO。

**样例**

```
输入：()[]
输出：YES

输入：([)]
输出：NO
```

**解题思路**：用栈：遇到左括号入栈，遇到右括号时检查栈顶是否为对应左括号，是则出栈，否则非法；遍历结束后栈必须为空。

**参考代码（Python）**

```python
s = input().strip()
stack = []
pairs = {")": "(", "]": "[", "}": "{"}
ok = True
for ch in s:
    if ch in "([{":
        stack.append(ch)
    else:
        if not stack or stack[-1] != pairs[ch]:
            ok = False
            break
        stack.pop()
if ok and not stack:
    print("YES")
else:
    print("NO")
```

**复杂度**：O(n)，空间 O(n)。

**易错点**：右括号出现时栈空直接判非法；([)] 这类「交错」是不合法的，不能用计数法判断，必须用栈匹配相邻关系。

### 4.13 特色高频概念题（客观 / 问答方向）

央企笔试客观题常夹带信号处理、实时系统、嵌入式、航空软件领域概念，属于「有背就有分」的送分点，单独列一份速查：

1. **FFT**：离散傅里叶变换 DFT 的快速算法，复杂度 O(N log N)，用于频谱分析；DFT 直接计算是 O(N²)。
2. **卡尔曼滤波**：递归状态估计算法，每步分「预测」与「更新」两个阶段，适用于线性高斯系统的导航、目标跟踪；扩展卡尔曼滤波 EKF 用于非线性系统。
3. **实时系统调度**：核心特征是确定性响应时间；常见算法有优先级抢占式调度、EDF（最早截止时间优先）、时间片轮转；高优先级进程持续占用会导致低优先级进程「饥饿」。
4. **DO-178C**：民用航空软件适航标准，按安全等级 A~E 分级，A 级软件要求达到 MC/DC（修正条件判定覆盖）。
5. **ARINC429**：航空领域广泛采用的单向、点对点数据总线协议，速率 100 kbps 量级（高速档可选 1 Mbps），用于飞控、航电等关键系统。
6. **IEEE754**：浮点数规格化表示，由符号位、阶码、尾数三部分构成。
7. **嵌入式 C**：数组名在表达式中退化为指向首元素的指针常量；a[i] 等价于 *(a+i)；指针加减步长取决于所指类型大小；shared_ptr 引用计数线程安全但所指对象不一定线程安全。
8. **数字电路**：与门（全 1 出 1）、或门（有 1 出 1）、异或门（相同出 0、不同出 1）；布尔代数化简。

## 五、难度对比与备考策略

### 5.1 央企与其它赛道编程题难度对比

| 赛道 | 代表笔试内容 | 难度 |
| --- | --- | --- |
| 央企（软件 / 算法岗） | 判断闰年、旋转矩阵、全排列、链表环检测、排序 | Easy~Medium，官方明确「LeetCode 中等及以下」 |
| 银行金融科技岗 | 连续自然数分解、合并区间、约瑟夫环、LRU、SQL 聚合 | Easy~Medium |
| 运营商 | 判断两位数、RGB 交换、赛跑排名 | Easy |
| 互联网大厂 | 图论、复杂 DP、困难数据结构 | Medium~Hard |

### 5.2 备考优先级

1. **保底层（必须全对）**：判断闰年、字符串反转、偶数求和、数组操作、排序（快排 / 归并）、栈实现、括号匹配。判断闰年、排序、旋转矩阵是已确认的原题，务必练到脱稿 bugfree。
2. **进阶层（拿稳 Medium）**：旋转矩阵、全排列（DFS / 回溯）、数组第 K 大（快选）、链表环检测、链表反转、二分查找、二叉树遍历（前中后序 / 层序）。这些是笔试与手撕的高频题。
3. **特色层**：信号处理（FFT / DFT / 卡尔曼滤波）、实时系统调度（优先级抢占 / EDF）、嵌入式 C/C++（指针、数组名退化、智能指针、拷贝构造）、航空总线与适航标准（ARINC429、DO-178C）、组合计数（无人机航线 / 排列组合）。这一层是区别于银行、运营商的差异点，客观题多出自这里。
4. **客观题层**：408 计算机基础（数据结构、OS、网络、数据库、C/C++）；部分研究所还会考数字电路（逻辑门、布尔代数）。各研究所的客观题都以 408 为主干。

### 5.3 应试技巧

- 各研究所笔试平台多为牛客、北森等，注意 ACM 模式的输入输出格式，先确认是「单组输入」还是「多组输入」，必要时写好循环读取。
- 编程题难度官方标注「LeetCode 中等及以下」，不会卡 Hard；拿到题先想暴力解法保分（全排列 DFS、旋转矩阵 O(n²)、偶数求和直接遍历），AC 后再优化。
- 若出现「二选一」大题（如某所第 5、6 题二选一），先快速浏览两题，挑自己有把握的那道做，别在难题上耗时间。
- 语言选择：认可度最高的是 C/C++ 与 Java（嵌入式、实时系统场景多），算法岗可用 Python；提前确认平台语言支持，用自己最熟的语言作答。
- 特色客观题要专门背：ARINC429、DO-178C、卡尔曼滤波两阶段、FFT 复杂度、实时调度算法、IEEE754、逻辑门真值表，这些「背了就有分」。
- 非软件岗（如总体、电气、控制类）笔试通常不考编程，重点转去行测、企业文化和岗位专业课；投递前先确认目标单位往年笔试题型，避免复习错方向。
