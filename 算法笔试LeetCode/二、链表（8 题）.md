## 一、这一专题怎么学

「链表」是银行与运营商笔试 / 面试手撕的**常驻专题**，题目不多但几乎每题都有边界坑。学习时抓住四条主线：

1. **反转三件套（最常考）**：LC 206 反转链表（迭代 + 递归）、LC 92 反转链表 II（反转一段区间）、LC 25 K 个一组翻转链表（按组反转）。核心是「画图 + 哑节点 + 头插法」，链表反转会连环问「反转一段 / K 个一组」。
2. **双指针 / 快慢指针**：LC 19 删除倒数第 N 个节点（快指针先走 N 步）、LC 141 环形链表（快慢指针相遇判环）、LC 160 相交链表（两端对齐 / 双指针走对方链表）。
3. **归并 / 合并**：LC 21 合并两个有序链表（哑节点 + 双指针，或递归）、LC 148 排序链表（归并排序，快慢指针找中点）。
4. **哑节点技巧**：凡是删除、反转会导致头节点变化的题，统一加 `dummy` 哑节点，把「头节点可能变」的问题变成「返回 dummy.next」的固定套路。

链表节点定义（LeetCode 默认提供）：

```java
public class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
```

## 12. LC 206 反转链表

### 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表头。

示例：

```
输入：head = [1, 2, 3, 4, 5]
输出：[5, 4, 3, 2, 1]
```

### 解题思路

这是**银行 / 运营商手撕第一高频题**，几乎必考，且要求迭代、递归两种都要会。

**迭代法（三指针）**：用 `prev`、`cur`、`next` 三个指针从头遍历，每步保存下一个节点，把当前节点的 `next` 指向前一个节点，然后三个指针整体后移。最后 `prev` 就是新链表的头。

**递归法**：`reverseList(head)` 反转以 `head` 为头的链表。先反转 `head.next` 之后的子链，再把 `head` 接在子链末尾。递归返回的是新链表头（原尾节点）。

### 复杂度分析

- 时间复杂度：O(n)，每个节点处理一次。
- 空间复杂度：迭代 O(1)；递归 O(n)（递归调用栈深度）。

### Java 代码

迭代版（面试推荐优先写这个）：

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode next = cur.next; // 先保存下一个节点，防止断链
            cur.next = prev;          // 反转当前节点的指针
            prev = cur;               // prev 后移
            cur = next;               // cur 后移
        }
        return prev; // prev 最后指向新链表头
    }
}
```

递归版：

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode newHead = reverseList(head.next); // 反转后面所有节点
        head.next.next = head; // 让原来 head 的下一个节点指回 head
        head.next = null;      // 断开 head 原来的 next
        return newHead;
    }
}
```

### 面试追问要点

- 为什么需要保存 `next`？因为反转 `cur.next = prev` 之后，原来的 `cur.next` 就丢了，不先保存会断链。
- 递归怎么理解？`reverseList(head.next)` 返回的是「head 之后那段链表反转后的新头」，它恰好是原链表的尾节点；`head.next.next = head` 就是让新尾接上 head。
- 空链表 / 单节点链表？迭代与递归都要先处理，避免空指针。
- 会不会问「反转一段」或「K 个一组」？会，见下面两题，属于 206 的连环追问。

## 13. LC 92 反转链表 II

### 题目描述

给你单链表的头指针 `head` 和两个整数 `left`、`right`，其中 `left  1 在环长不是步长差的倍数时可能跳过相遇，且无环时也更早出界。
- 能不能用哈希表？能，但空间 O(n)，面试先给快慢指针。
- 追问：找出环的入口节点（LC 142 / 剑指 23）？快慢相遇后，让 `slow` 回到 `head`，`fast` 留在相遇点，两者都每次走 1 步，再次相遇处就是入环点。数学依据：`a = (环长 - b)`，其中 a 是头到入环点距离，b 是入环点到相遇点距离。

## 17. LC 19 删除链表的倒数第 N 个节点

### 题目描述

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

示例：

```
输入：head = [1, 2, 3, 4, 5], n = 2
输出：[1, 2, 3, 5]
```

### 解题思路

**双指针（快慢指针）一次遍历**：

1. 加哑节点 `dummy`，`fast` 和 `slow` 都从 `dummy` 出发；
2. `fast` 先走 `n` 步；
3. `slow` 和 `fast` 同时走，直到 `fast.next == null`，此时 `slow` 正好停在倒数第 `n + 1` 个节点（被删节点的前驱）；
4. `slow.next = slow.next.next` 跳过被删节点。

注意：被删的可能是头节点（倒数第 n 个正好是 head），哑节点保证 `slow` 永远有前驱可操作，不需要特判。

### 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)。

### Java 代码

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);
        ListNode fast = dummy;
        ListNode slow = dummy;
        // 1. fast 先走 n 步
        for (int i = 0; i < n; i++) {
            fast = fast.next;
        }
        // 2. 两者同时走，fast 到末尾时 slow 停在倒数第 n+1 个节点
        while (fast.next != null) {
            fast = fast.next;
            slow = slow.next;
        }
        // 3. 删除 slow 后面的节点
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

### 面试追问要点

- 为什么 slow 停在倒数第 n+1 个而不是第 n 个？因为单链表删除必须知道前驱。
- 为什么加哑节点？删除头节点时没有前驱；哑节点让代码统一。
- 能不能先遍历一遍数长度、第二遍删？可以，O(n) 两遍；双指针一遍更优，面试官更喜欢。
- 追问：链表中倒数第 k 个节点（剑指 22）？同样的快慢指针，`fast` 先走 k 步，然后同步走，`fast` 到末尾时 `slow` 就是答案。

## 18. LC 160 相交链表

### 题目描述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

### 解题思路

相交链表的特点是：从某个节点开始，两个链表共用同一段尾巴。

**经典双指针解法（最简洁）**：`pA`、`pB` 分别从两个头出发，每次走 1 步；走到 `null` 时换到对方链表的头继续走。因为两个指针走过的总路程最终相等（`lenA + lenB`），所以：

- 若相交，`pA` 和 `pB` 会在第一个公共节点相遇；
- 若不相交，它们会同时走到 `null`（`pA == pB == null`）。

**另一种思路（长度对齐）**：先分别算出两链表长度，长的先走差值步，然后同步走找相同节点。理解直观，但代码更长。

**哈希集合思路**：先把 `headA` 所有节点放入 `HashSet`，再遍历 `headB`，第一个出现在集合中的节点即交点。空间 O(m)。

### 复杂度分析

- 时间复杂度：双指针 O(m + n)。
- 空间复杂度：双指针 O(1)；哈希集合 O(m)。

### Java 代码

双指针版（推荐手撕）：

```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode pA = headA;
        ListNode pB = headB;
        while (pA != pB) {
            pA = (pA == null) ? headB : pA.next;
            pB = (pB == null) ? headA : pB.next;
        }
        return pA; // 不相交时 pA 最终为 null，也正确
    }
}
```

### 面试追问要点

- 为什么走对方链表就能相遇？两个指针各自都走「自己链 + 对方链」的总长，相交段之前的长度差被抹平，之后必然在交点汇合。
- 不相交时会不会死循环？不会，两者都走 lenA + lenB 步后同时为 null，退出循环返回 null。
- 能不能用哈希？能，先存一个链表再遍历另一个，O(m + n) 时间 O(m) 空间，能写出来也是加分项。

## 19. LC 148 排序链表

### 题目描述

给你链表的头结点 `head`，请将其按**升序**排列并返回排序后的链表。要求时间复杂度 O(n log n)，空间复杂度 O(1)（进阶要求），不使用额外数组。

### 解题思路

数组排序可以 O(1) 空间随机访问，但链表做不到随机访问，所以 O(n log n) 的稳定选择是**归并排序**：

1. **找中点**：快慢指针，`slow` 每次 1 步、`fast` 每次 2 步，`fast` 到头时 `slow` 在中点；把链表从 `slow` 处断开成左右两半；
2. **递归排序**：左右两半分别 `sortList`；
3. **合并**：用「合并两个有序链表」（LC 21）的思路把两个有序子链表合并。

进阶：题目希望 O(1) 空间，即**自底向上归并**（先 1 个 1 个归并、再 2 个 2 个归并……），实现更繁琐。面试一般先写对递归版并讲清思路即可，主动提一句「可以改自底向上做到 O(1) 空间」就是加分项。

### 复杂度分析

- 时间复杂度：O(n log n)。
- 空间复杂度：递归版 O(log n)（递归栈）；自底向上版可做到 O(1)。

### Java 代码

递归归并版：

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        // 1. 快慢指针找中点
        ListNode slow = head;
        ListNode fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode mid = slow.next; // 右半部分起点
        slow.next = null;         // 断开成两条链表
        // 2. 递归排序左右两半
        ListNode left = sortList(head);
        ListNode right = sortList(mid);
        // 3. 合并两个有序链表
        return merge(left, right);
    }

    private ListNode merge(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) {
                cur.next = l1;
                l1 = l1.next;
            } else {
                cur.next = l2;
                l2 = l2.next;
            }
            cur = cur.next;
        }
        cur.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

### 面试追问要点

- 为什么不用快速排序？快排需要随机访问和交换 pivot，链表做交换 / 分区繁琐，最坏 O(n²)；归并对链表天然友好。
- 找中点时 `fast` 为什么从 `head.next` 开始？避免偶数长度时中点偏右，保证左右规模均衡。
- 为什么是 O(n log n)？每次把规模减半（log n 层），每层合并总代价 O(n)。
- 进阶：自底向上怎么做到 O(1) 空间？按长度 1、2、4、8……逐层归并，不递归，空间 O(1)；能讲清思路即可，手撕通常不要求。

## 三、总结与复盘清单

1. **反转三件套是一条线**：LC 206（整段反转，三指针 / 递归）→ LC 92（反转一段，哑节点 + 头插法）→ LC 25（每 k 个反转一段，分段 + 接回）。把 206 写到肌肉记忆，另外两题是它的「加条件」版本。
2. **双指针三种用途**：快慢指针判环（141）、快指针先走 n 步再同步（19、剑指 22）、双指针走对方链表对齐长度（160）。
3. **哑节点是链表手撕的万能钥匙**：删除倒数第 n、反转一段、合并、排序，只要头节点可能变，就加 `dummy`，返回 `dummy.next`，能省掉一半的边界 bug。
4. **链表归并的模板**：LC 21（合并两个有序链表）是基础，LC 148（排序链表）= 找中点断开 + 递归排序 + 21 的合并，两者共享同一段 merge 代码。
5. **手撕建议**：LC 206、LC 21、LC 141 这三题出现率最高，建议达到「5 分钟 bugfree」；LC 92、LC 25、LC 148 属于进阶，会写 206 的循环版本后顺着改即可。全专题练熟后，遇到「反转」「删除」「合并」「判环」四类变体都能套模板。
6. **讲解习惯**：写完主动讲时间 / 空间复杂度，说明为什么用哑节点、为什么用快慢指针；遇到 LC 141 主动提「延伸可以找入环点」，遇到 LC 148 主动提「可以自底向上做到 O(1) 空间」，这些主动延伸最加分。
