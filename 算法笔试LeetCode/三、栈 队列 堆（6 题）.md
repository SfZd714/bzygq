## 一、这一专题怎么学

「栈 / 队列 / 堆」三种线性容器有一个共同点：**只允许在端部操作**。用 O(1) 的端部存取，换来的是「最近 / 最急」信息的维护能力。银行和运营商对这块的考点高度集中，按数据结构分四条主线：

1. **栈 Stack（后进先出）**：处理「最近相关性」问题——括号匹配、表达式、单调栈找下一个更大 / 更小元素。Java 中推荐用 `ArrayDeque` 当栈用，而不是老的 `Stack` 类（它继承自 `Vector`，带锁、性能差，面试提一嘴就是加分项）。
2. **队列 Queue（先进先出）**：处理「按顺序消费」问题——BFS 层序、滑动窗口、生产者消费者。`Deque`（双端队列）头尾都能操作，是单调队列的数据基础。
3. **堆 Heap（优先队列 `PriorityQueue`）**：处理「Top K / 第 K 大 / 合并有序流」，频率仅次于排序。Java 默认是小顶堆，大顶堆要传比较器；这是面试官爱问「默认实现」的点。
4. **数据结构设计题**：最小栈、用栈实现队列、LRU 缓存——银行科技岗手撕最爱，考察「多种结构组合」。LRU 常被列为金融科技岗「最高频没有之一」，多家银行与运营商技术岗都考过。

Java 里四种标准写法的速查：

```java
import java.util.*;

// 1. 栈：官方推荐 ArrayDeque，不用 Stack
Deque stack = new ArrayDeque<>();
stack.push(1);           // 入栈
int top = stack.peek();  // 看栈顶
int v = stack.pop();     // 出栈

// 2. 队列：LinkedList 或 ArrayDeque
Queue queue = new LinkedList<>();
queue.offer(1);          // 入队（offer 失败返回 false，add 会抛异常）
int head = queue.peek(); // 看队头
int h = queue.poll();    // 出队

// 3. 双端队列（单调队列的基础）
Deque deque = new ArrayDeque<>();
deque.addLast(1);        // 尾部入
deque.addFirst(2);       // 头部入
deque.pollFirst();       // 头部出
deque.pollLast();        // 尾部出

// 4. 堆：PriorityQueue 默认小顶堆，大顶堆传比较器
PriorityQueue minHeap = new PriorityQueue<>();
PriorityQueue maxHeap = new PriorityQueue<>((a, b) -> b - a);
```

## 20. LC 20 有效的括号

### 题目描述

给定一个只包括 `(`、`)`、`{`、`}`、`[`、`]` 的字符串 `s`，判断字符串是否有效。有效字符串需满足：左括号必须用相同类型的右括号闭合，且必须按正确的顺序闭合。

示例：

```
输入：s = "()[]{}"
输出：true

输入：s = "(]"
输出：false
```

### 解题思路

这是**栈最经典的入门题**，也是银行笔试题库常客，务必做到 3 分钟 bugfree。

用「左括号入栈、右括号匹配」的思路：

1. 遍历字符串，遇到左括号 `(`、`[`、`{` 就入栈；
2. 遇到右括号时，先看栈是否为空（为空说明没有匹配的左括号，直接返回 false），再弹出栈顶并判断是否是对应的左括号；
3. 遍历结束后，栈必须为空（防止有未闭合的左括号）。

优化点：可以把「右括号 -> 对应左括号」的映射放进 `Map`，比较时直接查表，代码更简洁；也可以在入栈时直接压入「对应的右括号」，遇到右括号时弹出比较是否相等。

### 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度，每个字符处理一次。
- 空间复杂度：O(n)，最坏全是左括号时栈深 n。

### Java 代码

```java
class Solution {
    public boolean isValid(String s) {
        Deque stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false; // 没有可匹配的左括号
                char top = stack.pop();
                if (c == ')' && top != '(') return false;
                if (c == ']' && top != '[') return false;
                if (c == '}' && top != '{') return false;
            }
        }
        return stack.isEmpty(); // 栈空说明所有括号都闭合
    }
}
```

也可以写成「入栈压右括号」的版本，判断更短：

```java
class Solution {
    public boolean isValid(String s) {
        Deque stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(')');
            } else if (c == '[') {
                stack.push(']');
            } else if (c == '{') {
                stack.push('}');
            } else {
                // 当前是右括号，栈顶必须是对应的那个右括号
                if (stack.isEmpty() || stack.pop() != c) return false;
            }
        }
        return stack.isEmpty();
    }
}
```

### 面试追问要点

- 为什么用栈而不是队列？括号闭合是「后出现的左括号先闭合」，符合后进先出；队列先进先出解决不了。
- 遇到右括号时栈为空意味着什么？说明右括号没有左括号匹配，比如 `")("` 这种直接 false。
- 遍历结束后为什么要检查栈空？防止 `"(("` 这种只有左括号的非法串。
- 三种括号要分别匹配，`"(]"` 虽然数量对，但类型不匹配，也要 false。
- 变体：只有一种括号（比如只有小括号）怎么做？判断更简单，用计数器或栈都行；三种括号必须用栈。

## 21. LC 155 最小栈

### 题目描述

设计一个支持 `push`、`pop`、`top` 操作，并能在常数时间内检索到最小元素的栈。要求 `getMin` 操作时间复杂度 O(1)。

示例：

```
输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]
```

### 解题思路

核心难点：普通栈只能 O(1) 拿到栈顶，拿不到最小值；如果每次都遍历找最小值是 O(n)，不满足要求。

**辅助栈法（最推荐）**：用两个栈。

- 数据栈 `data` 正常存所有元素；
- 辅助栈 `minStack` 的栈顶始终是「当前数据栈中的最小值」；
- `push(x)`：数据栈入栈；辅助栈入栈 `min(x, minStack 当前栈顶)`，也就是「当前新最小值」；
- `pop()`：两个栈一起出栈，保证同步；
- `getMin()`：直接返回辅助栈栈顶。

这样空间换时间，两个操作都是 O(1)。还有一个「单个栈存差值」的省空间技巧，面试能说出来是加分项，但容易出错，手撕先写辅助栈法。

### 复杂度分析

- 时间复杂度：push / pop / top / getMin 均为 O(1)。
- 空间复杂度：O(n)，两个栈合计最多存 2n 个元素。

### 面试追问要点

- 为什么搬一次之后连续 pop 都是 O(1)？因为 `out` 栈顶已经是「最先进队列」的元素，队首的顺序在搬运时已固定，之后直接弹栈即可。
- 每次 pop 都搬一遍吗？不是，只有当 `out` 为空时才搬；均摊下来每个元素只被压栈两次、弹栈两次，总复杂度 O(1)。
- 反过来「用队列实现栈」（LC 225）怎么做？核心是让新元素成为队首：入栈时把新元素放到队尾后，把前面的元素依次重新排到它后面；或者说每次入栈把前面所有元素重新入队，保证队首 = 栈顶。
- 为什么要用 ArrayDeque 而不是 Stack？ArrayDeque 无锁、性能好，是 Java 官方推荐的栈实现；能说出这一点面试官印象分会好。

## 23. LC 146 LRU 缓存

### 题目描述

请你设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构。实现 `LRUCache` 类：

- `get(key)`：如果关键字存在于缓存中，则返回其值，否则返回 `-1`；
- `put(key, value)`：如果关键字已存在，则变更其数据值；如果不存在，则插入该组「关键字 - 值」。当缓存容量达到上限时，在写入新数据之前删除最久未使用的数据值。

要求 `get` 和 `put` 的时间复杂度都是 O(1)。

### 解题思路

本题常被定位为「最高频没有之一」，多家银行与运营商技术岗都考过，部分机构还要求线程安全版本。核心是**哈希表 + 双向链表**：

- **哈希表 `HashMap`**：O(1) 定位到节点；
- **双向链表**：按访问顺序排列，头部是最近使用、尾部是最久未使用。

具体规则：

1. `get(key)`：哈希表查不到返回 -1；查到了就把该节点从链表中移到头部（标记为最近使用），返回 value；
2. `put(key, value)`：
   - key 已存在：更新节点值，并把节点移到头部；
   - key 不存在：新建节点插入头部；若容量超限，删除尾部节点（最久未使用）并同步从哈希表删除。

用「头尾两个哨兵节点（dummy）」能省掉大量判空逻辑，这是手撕不 bugfree 的关键技巧。

补充：`LinkedHashMap` 开启访问序后一行能实现，但面试官通常要求手写哈希表 + 双向链表，理解底层结构更重要。

### 复杂度分析

- 时间复杂度：get 和 put 均为 O(1)（哈希定位 O(1) + 链表头尾操作 O(1)）。
- 空间复杂度：O(capacity)，哈希表和链表各存一份节点引用。

### Java 代码

```java
class LRUCache {
    // 双向链表节点
    static class Node {
        int key, value;
        Node prev, next;
        Node(int k, int v) { key = k; value = v; }
    }

    private final int capacity;
    private final Map map = new HashMap<>();
    private final Node head = new Node(0, 0); // 头部哨兵，head.next 是最近使用
    private final Node tail = new Node(0, 0); // 尾部哨兵，tail.prev 是最久未使用

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node); // 访问后变为最近使用
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value; // 更新值
            moveToHead(node);
        } else {
            Node fresh = new Node(key, value);
            map.put(key, fresh);
            addToHead(fresh);
            if (map.size() > capacity) { // 超容量，删最久未使用
                Node last = tail.prev;
                removeNode(last);
                map.remove(last.key);
            }
        }
    }

    private void addToHead(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }
}
```

### 面试追问要点

- 为什么用双向链表不用单向？删除尾部节点时，单向链表拿不到它的前驱，无法 O(1) 删除；双向链表靠 `node.prev` 一步到位。
- 哈希表和链表怎么配合？哈希表负责「按 key 找节点」，链表负责「记录访问顺序」，两者通过节点引用串联。只有哈希表能 O(1) 访问，只有链表能 O(1) 调序，缺一不可。
- 为什么用哨兵节点？避免头插、尾删时大量判空和特殊处理，让 add / remove 逻辑统一。
- 如果面试官要求线程安全版本怎么做？最简单的做法是用 `synchronized` 把 get / put 包起来；进阶可用 `ConcurrentHashMap` 配合锁或分段思想，面试能说清「加锁保证并发下 map 与链表一致」即可。
- 和 LFU 的区别？LRU 按「最近使用」淘汰，LFU 按「使用频率」淘汰，LFU 需要额外维护频次桶，复杂度更高；面试如果追问，说出这个区别就是加分项。
- 用 LinkedHashMap 一行实现怎么写？`new LinkedHashMap<>(capacity, 0.75f, true)` 开启 accessOrder，重写 `removeEldestEntry` 即可；能写出来说明你熟悉 Java 集合，但手撕仍建议用双向链表版本。

## 24. LC 215 数组中的第 K 个最大元素

### 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

示例：

```
输入：nums = [3, 2, 1, 5, 6, 4], k = 2
输出：5

输入：nums = [3, 2, 3, 1, 2, 4, 5, 5, 6], k = 4
输出：4
```

### 解题思路

这是**国企技术岗笔试的高频题**，要求能讲清楚至少两种解法并说明复杂度区别。

**法一：小顶堆（优先队列）**。维护一个大小为 k 的小顶堆，堆里永远是「当前最大的 k 个元素」，堆顶就是第 k 大：

- 遍历数组，每个元素入堆；
- 堆大小超过 k 时，弹出堆顶（当前最小的那个），保证堆里始终是最大的 k 个；
- 遍历结束，堆顶就是第 k 大的元素。

时间复杂度 O(n log k)，空间 O(k)，思路简单、代码稳定，笔试首选。

**法二：快速选择（Quickselect）**。利用快速排序的 partition：每次 partition 后，pivot 到达它最终位置 p，左边都小于它、右边都大于它。第 k 大 = 升序数组下标 `n - k` 的位置，所以：

- 若 `p == n - k`，pivot 就是答案；
- 若 `p  n - k`，答案在左侧。

平均 O(n)，最坏 O(n²)（pivot 选得不好）。面试能先写堆法，再补充讲清快速选择思路即可。

### 复杂度分析

- 堆法：时间复杂度 O(n log k)，空间复杂度 O(k)。
- 快速选择：平均 O(n)，最坏 O(n²)；空间复杂度 O(log n)（递归栈，可优化到 O(1)）。

### Java 代码

堆法（推荐笔试先写这个）：

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 小顶堆，只保留最大的 k 个元素
        PriorityQueue minHeap = new PriorityQueue<>();
        for (int num : nums) {
            minHeap.offer(num);
            if (minHeap.size() > k) {
                minHeap.poll(); // 弹出当前最小的，堆里留下的一定是最大的 k 个
            }
        }
        return minHeap.peek(); // 堆顶即第 k 大
    }
}
```

快速选择版：

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        int target = nums.length - k; // 第 k 大 = 升序下标 n - k
        int lo = 0, hi = nums.length - 1;
        while (true) {
            int p = partition(nums, lo, hi);
            if (p == target) {
                return nums[p];
            } else if (p = k - 1`）时，队头下标对应的值就是当前窗口最大值。

关键理解：一个元素一旦比队尾元素「新且大」，队尾那个就永远没有出头之日，可以提前删掉——这就是单调队列省时间的原因。

### 复杂度分析

- 时间复杂度：O(n)，每个元素最多入队一次、出队一次。
- 空间复杂度：O(k)，队列里最多同时存 k 个下标。

### Java 代码

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] res = new int[n - k + 1];
        // 单调递减队列：存下标，队头到队尾对应的值单调递减
        Deque deque = new ArrayDeque<>();

        for (int i = 0; i = k - 1) {
                res[i - k + 1] = nums[deque.peekFirst()];
            }
        }
        return res;
    }
}
```

### 面试追问要点

- 为什么弹出所有「不大于当前值」的队尾元素？它们在当前元素之前且值不更大，窗口滑过后迟早被淘汰，留着只会挡路。注意是 `<=`，这样重复值也淘汰，保证窗口内相同值的更靠后者胜出。
- 为什么队列里存下标而不是值？需要判断队头是否滑出窗口，只有下标才能做 `i - k` 的过期判断。
- 复杂度为什么是 O(n) 而不是看起来的 O(k)？每个元素入队一次、出队一次，while 循环里的弹出操作总数是 O(n)。
- 变体：滑动窗口最小值？对称，改成「单调递增队列」即可，队头是最小值。
- 和单调栈的区别？单调栈用于「下一个更大 / 更小元素」，处理静态序列；单调队列用于「窗口内最值」，处理动态滑动窗口。两者思想同源，都靠「及时淘汰不可能成为答案的元素」。

---

## 三、总结与复盘清单

1. **三种容器的选择口诀**：栈用 `ArrayDeque`、队列用 `LinkedList` 或 `ArrayDeque`、堆用 `PriorityQueue`。能说出「Java 官方推荐 ArrayDeque 代替 Stack」是第一个加分点。
2. **栈的三类题型**：括号匹配（LC 20，入门）、最小栈（LC 155，辅助栈）、用栈实现队列（LC 232，双栈）。共同点：栈顶保存「最近 / 最急」的信息，辅助结构记录「额外信息」。
3. **单调栈 / 单调队列是一条线**：单调队列（LC 239）是「滑动窗口最值」的标准解法，核心是「淘汰不可能成为答案的元素」；把这条思路延伸到「下一个更大元素」（LC 496 / 739）就是单调栈，理解一个就能迁移到另一个。
4. **LRU 是设计题的巅峰**：哈希表 + 双向链表 = O(1) 查找 + O(1) 调序，哨兵节点保证边界不出 bug。银行 / 运营商要求练到 10 分钟 bugfree，且能回答线程安全版本方案。
5. **第 K 大双解法**：堆（O(n log k)，稳定好写）与快速选择（平均 O(n)，partition 理解）。国企技术岗笔试常考此题，要求讲清两种复杂度，笔试先写堆法。
6. **手撕建议**：LC 20、LC 155、LC 232 属于「5 分钟内 bugfree」的基础题；LC 146 和 LC 239 是拉开差距的进阶题，重点是讲清楚「为什么是 O(1) / O(n)」。全专题练熟后，遇到「括号 / 最值 / Top K / 缓存淘汰」四类问题都能快速定位到对应容器。
7. **讲解习惯**：写完主动报时间 / 空间复杂度；讲 LRU 时主动提线程安全版，讲第 K 大时主动提第二种解法，讲滑动窗口时主动提单调栈延伸——这些主动补充最加分。
