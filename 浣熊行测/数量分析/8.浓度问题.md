# 浓度问题概述
我们先从生活场景切入：一杯糖水，糖的多少决定了甜度 —— 这里的 “糖” 就是溶质，“水” 是溶剂，“糖水整体” 是溶液，而 “甜度” 就是浓度。本质上，浓度问题是研究溶质、溶剂、溶液三者之间比例关系的计算题，常考场景包括溶液混合、稀释、蒸发、加溶质等。
## 概念定义
- 溶质：被溶解的物质（如糖、盐、酒精等）；
- 溶剂：溶解溶质的物质（如 water，行测中默认溶剂多为水）；
- 溶液：溶质与溶剂的混合体（溶质 + 溶剂 = 溶液）；
- 浓度：溶质占溶液的比例（反映溶液 “浓淡” 程度），通常用百分数表示。
##  核心公式（必背）
- 浓度 =（溶质质量 / 溶液质量）× 100%
- 溶质质量 = 溶液质量 × 浓度
- 溶液质量 = 溶质质量 ÷ 浓度
- 溶液质量 = 溶质质量 + 溶剂
# 浓度问题的解法
## 根据溶质的量不变列方程
在众多浓度问题的情境里，溶质的总量在溶液经历各种混合、稀释、蒸发等变化历程中始终维持恒定，这一特性成为我们解决浓度问题的关键突破口。

例如，假设有一杯浓度为$$a\%$$的溶液$$A$$克，另一杯浓度为$$b\%$$的溶液$$B$$，将它们混合后得到浓度为$$c\%$$的混合溶液。我们设混合后溶液的总质量为$$M$$克（$$M = A + B$$）。根据溶质质量不变的原理，溶液$$A$$中所含溶质的质量为$$A\times a\%$$，溶液$$B$$中所含溶质的质量为$$B\times b\%$$，而混合后溶液中溶质的质量为$$M\times c\%$$。由此，我们可以建立方程：$$A\times a\%+ B\times b\%=(A + B)\times c\%$$。

再比如，在溶液稀释的场景中，若有初始浓度为$$m\%$$的溶液$$X$$克，向其中加入$$Y$$克溶剂（如水）后，溶液浓度变为$$n\%$$。因为溶质质量不变，所以可列方程：$$X\times m\%=(X + Y)\times n\%$$。

又或者在溶液蒸发的情况下，设有浓度为$$p\%$$的溶液$$Z$$克，蒸发掉$$W$$克溶剂后，浓度变为$$q\%$$。依据溶质不变原则，方程为： $$Z\times p\%=(Z - W)\times q\%$$。

通过设未知数，精准地依据溶质质量恒定这一不变量构建方程，我们就能够有效地求解出未知的浓度、溶液量等关键信息，从而破解浓度问题。

## 十字相乘法原理
十字相乘法在处理两种溶液混合问题时展现出极大的便利性与高效性。当我们面对两种不同浓度的溶液混合时，操作步骤如下：首先，将两种溶液的浓度分别清晰地写在左上角和左下角，把混合后的浓度准确地写在中间位置。然后，进行交叉相减的运算，所得到的差值之比恰好等于两种溶液的量之比。

十字相乘法原理推导

1. 首先根据溶液混合前后溶质质量不变：
  - 浓度为$$A\%$$的溶液$$m$$克，其中溶质质量为$$m\times A\%$$克；浓度为$$B\%$$的溶液$$n$$克，其中溶质质量为$$n\times B\%$$克。
  - 混合后溶液总质量为$$(m + n)$$克，浓度为$$C\%$$，混合后溶质质量为$$(m + n)\times C\%$$克。
  - 由混合前后溶质质量相等可得：$$m\times A\%+n\times B\%=(m + n)\times C\%$$。
2. 然后对等式进行化简：
  - 展开等式右边：$$m\times A\%+n\times B\%=m\times C\%+n\times C\%$$。
  - 移项可得：$$m\times A\%-m\times C\%=n\times C\%-n\times B\%$$。
  - 提取公因式：$$m(A\% - C\%)=n(C\% - B\%)$$。
  - 进一步变形为：$$\frac{m}{n}=\frac{C\% - B\%}{A\% - C\%}$$。

例：有浓度为$$20\%$$的盐水$$300$$克，浓度为$$50\%$$的盐水$$200$$克，混合后盐水浓度是多少？
解设混合后盐水浓度为$$x\%$$ 。
  - 根据十字相乘法,两种溶液质量比为$$300:200 = 3:2$$，所以$$\frac{300}{200}=\frac{50\% - x\%}{x\% - 20\%}$$，即$$\frac{3}{2}=\frac{50 - x}{x - 20}$$ 。
  - 交叉相乘得：$$3(x - 20)=2(50 - x)$$。
  - 展开式子：$$3x-60 = 100 - 2x$$$ 。
  - 移项：$$3x + 2x=100 + 60$$ 。
  - 合并同类项：$$5x = 160$$ ，解得$$x = 32$$，即混合后盐水浓度为$$32\%$$ 。 

这意味着，通过十字相乘法，我们能够迅速且直观地确定混合溶液中两种成分的比例关系，进而为求解诸如溶液量、浓度等相关问题开辟了捷径。它巧妙地避开了复杂的计算过程，以一种简洁明了的方式呈现出溶液混合问题中的内在数量联系，大大提高了解题效率。

## 特殊值法

特殊值法是一种极具技巧性的解题策略，其核心在于紧密依据题目所呈现的独特特点，巧妙地选取适宜的特殊值，以此来简化原本复杂繁琐的计算流程，达成快速准确得出答案的目标。

在选取特殊值时，通常会优先考虑溶质的量或溶液的量为特定数值。较为常用的是选取浓度分母的公倍数作为特殊值，这是因为这样的取值能够在后续计算中有效地消除分母，极大地简化计算过程。

$$\frac{m}{n}=\frac{C\% - B\%}{A\% - C\%}$$

比如，若题目中涉及到浓度分别为$$\frac{1}{3}$$和$$\frac{1}{4}$$的两种溶液，我们可以选取$$12$$（$$3$$和$$4$$的最小公倍数）作为溶质的特殊值。假设浓度为$$\frac{1}{3}$$的溶液中溶质为$$12$$克，根据浓度公式可推出该溶液质量为$$36$$克；同理，对于浓度为$$\frac{1}{4}$$的溶液，若溶质也为$$12$$克，则溶液质量为$$48$$克。这样，在进行溶液混合或其他相关计算时，就能够避免分数运算带来的不便，使计算过程更加简洁流畅，从而快速地得出答案。特殊值法的巧妙运用，充分展现了在数学解题过程中灵活应变与巧妙构思的重要性，能够帮助我们在面对浓度问题时更加高效地找到解决方案。 

# 浣熊真题

**例1、甲杯中有浓度 17%的溶液 400 克，乙杯中有浓度为 23%的同种溶液 600 克，现在从甲，乙取出相同质量的溶液，把甲杯取出的倒入乙杯中，把乙杯取出的倒入甲杯中，使甲，乙两杯溶液的浓度相同，问现在两溶液浓度是多少？**

- 解法一（十字相乘法）：
设混合后浓度为$$x$$ ，则有 $$\frac{x-17}{23 - x}=\frac{400}{600}=\frac{3}{2}$$ ，即 $$3\times(x-17) = 2\times(23 - x)$$ ， $$5x=103$$ 。所以答案是 $$20.6\%$$ 。

- 解法二（整体混合法）：
假设他们全部混合，那么混合后溶液的总质量为400 + 600 = 1000 克，溶质的总量为 $$17\%\times400 + 23\%\times600 = 68 + 138 = 206$$ 克。所以混合后的浓度为 $$\frac{206}{1000}=20.6\%$$ 。答案为 $$20.6\%$$ 。

**例2、现有一种预防禽流感药物配置成的甲、乙两种不同浓度的消毒溶液。若从甲中取2100克，乙中取700克混合而成的消毒溶液的浓度为3%；若从甲中取900克，乙中取2700克，则混合而成的消毒溶液的浓度为5%。则甲、乙两种消毒溶液的浓度分别为:**
  
A. 3% 6% 
  B. 3% 4% 
  C. 2% 6% 
  D. 4% 6%

解法一（列方程法）：

设甲溶液浓度为$$a$$，乙溶液浓度为$$b$$,根据溶质不变可列方程组：
$$\begin{cases}2100a + 700b = (2100 + 700)\times3\%\\900a + 2700b = (900 + 2700)\times5\%\end{cases}$$
化简得：
$$\begin{cases}2100a + 700b = 84\\900a + 2700b = 180\end{cases}$$
将第一个方程乘以$$3$$减去第二个方程可得：
$$6300a + 2100b - (900a + 2700b)=252 - 180
$$
$$5400a - 600b = 72$$
$$9a - b = 0.12$$
由$$2100a + 700b = 84$$可得$$3a + b = 0.12$$
两式相加得$$12a = 0.24$$，$$a = 0.02$$，代入$$3a + b = 0.12$$得$$b = 0.06$$。所以答案是$$C$$。

解法二（浓度范围判断法）：

第一次混合后浓度为$$3\%$$，所以一种溶液浓度小于$$3\%$$，一种大于$$3\%$$；第二次混合后浓度为$$5\%$$，所以一种溶液浓度小于$$5\%$$，一种大于$$5\%$$。所以有，一种大于$$5\%$$，一种小于$$3\%$$。只有$$C$$选项符合，答案为$$C$$。

**例3、甲，乙两种含金样品熔成合金，如甲的重量是乙的一半，得到含金$$68\%$$的合金；如甲的重量是乙的$$3.5$$倍，得到含金$$62\frac{2}{3}\%$$的合金。则乙的含金百分数为多少?**

A. $$72\%$$ B. $$64\%$$ C. $$60\%$$ D. $$56\%$$

解析：据题中条件可知，乙的重量所占比例高时，合金的含金量高；乙的重量所占比例低时，合金的含金量低。由此可判断出乙的含金量大于甲的含金量。又因为有一块合金的含金量为$$68\%$$，所以必定甲乙一个大于$$68\%$$，一个小于$$68\%$$。根据前面的结论，则推出乙的含金量一定大于$$68\%$$，只有$$A$$答案符合。答案为$$A$$。

**例4、每次加同样多的水，第一次加水浓度$$15\%$$，第二次加浓度$$12\%$$，第三次加浓度为多少?**

解析：因为溶质质量始终不会改变，设盐水有$$60$$克盐（$$15$$和$$12$$的最小公倍数）。
第一次加水后溶液是$$60\div0.15 = 400$$克；
第二次加水后溶液是$$60\div0.12 = 500$$克；
所以可知加了500 - 400 = 100克水；
第三次加水后浓度是$$60\div(500 + 100)= 0.1$$，也就是$$10\%$$。答案为$$C$$。

**例5、一种溶液，蒸发掉一定量的水后，溶液的浓度变为$$10\%$$，再蒸发掉同样多的水后，溶液的浓度变为$$12\%$$，第三次蒸发掉同样多的水后，溶液的浓度将变为多少?**

解析：
设溶质盐是$$60$$（$$10$$和$$12$$的最小公倍数）。
第一次蒸发后溶液是$$60\div0.1 = 600$$；
第二次蒸发后溶液是$$60\div0.12 = 500$$；
所以每次蒸发600 - 500 = 100的水；
第三次蒸发后浓度是 $$60\div(500 - 100)= 0.15$$，即$$15\%$$。答案为$$D$$。

**例6、把浓度为$$20\%$$、$$30\%$$、$$50\%$$的某溶液混合在一起，得到浓度为$$36\%$$的溶液$$50$$升。已知浓度为$$30\%$$的溶液用量是浓度为$$20\%$$溶液的$$2$$倍，浓度为$$30\%$$的溶液的用量是多少升?**

解析（十字相乘法）：
设$$20\%$$溶液用量为$$x$$升，则$$30\%$$溶液用量为$$2x$$升，$$50\%$$溶液用量为 $$50 - 3x$$升。
先对$$20\%$$和$$30\%$$的溶液混合，混合后的浓度为$$\frac{20\%x + 30\%\times2x}{3x}=\frac{0.2x + 0.6x}{3x}=\frac{0.8x}{3x}=\frac{8}{30}\approx26.7\%$$。
然后对$$26.7\%$$与$$50\%$$的溶液用十字相乘法： $$\frac{26.7\%}{50\% - 36\%}=\frac{14}{9.3}$$
，即 $$\frac{3x}{50 - 3x}=\frac{3}{2}
$$，6x = 150 - 9x，15x = 150，x = 10。
所以$$30\%$$溶液的用量为$$2x = 20$$升。答案为$$D$$。

**例7、A、B、C为三种酒精溶液。按质量比2:6:1混合，质量分数为$$30\%$$；$$4:5:1$$混合时，为$$28\%$$；$$6:1:1$$混合时，为$$25\%$$。现缺少$$C$$种溶液，需要配置大量$$28\%$$的溶液需要A和B的质量比是**

A. 1:2 B. 1:3 C. 1:4 D. 1:5

解法一（列方程法）：
设A、B、C三种溶液的浓度分别为a、b、c，根据条件可得：
$$\begin{cases}2a + 6b + c = 9\times0.3\\4a + 5b + c = 10\times0.28\\6a + b + c = 8\times0.25\end{cases}$$
用第一个方程减去第二个方程得：$$-2a + b = 0.7$$  (4)
用第三个方程减去第一个方程得: $$4a - 5b = 0.1 $$    (5)
(4)式乘以5加上(5)式得: $$-10a + 5b + 4a - 5b = 3.5 + 0.1，-6a = 3.6，a = 0.2$$
将$$a = 0.2$$代入$$(4)$$式得：$$-2\times0.2 + b = 0.7$$，$$b = 0.3$$。
则$$A$$、$$B$$混合成$$28\%$$溶液时， $$\frac{A}{B}=\frac{0.3 - 0.28}{0.28 - 0.2}=\frac{0.02}{0.08}=\frac{1}{4}$$,答案为$$C$$。
解法二（十字相乘法）：
对于$$30\%$$的混合：$$30\%$$  $$3$$  $$36\%$$  $$8$$，$$24$$，$$4$$
对于$$25\%$$的混合：$$25\%$$  $$2$$  $$24\%$$  $$18$$，$$3$$，$$3$$
所以$$A$$、$$B$$、$$C$$按$$26:27:7$$的比例能配置出$$28\%$$的溶液，那么$$A$$和$$B$$的质量比为$$26:27 = 1: \frac{27}{26}\approx1:1.04$$，最接近$$1:4$$。答案为$$C$$。
