# 政治常识（核心模块）
1. 马克思主义基本原理
  - 哲学：唯物论、辩证法、认识论、历史唯物主义（高频考点：矛盾分析法、实践与认识的关系）
  - 政治经济学：商品与货币、剩余价值、资本主义基本矛盾
2. 中国特色社会主义理论体系
  - 邓小平理论、“三个代表” 重要思想、科学发展观
  - 习近平新时代中国特色社会主义思想（核心内容、重大论断、实践要求）
3. 党和国家重大方针政策
  - 最新党代会报告（核心要点、战略部署）
  - 中央经济工作会议、中央一号文件等重要会议精神
  - 治国理政新理念、新思想、新战略
4. 党史、新中国史、改革开放史、社会主义发展史
  - 重要历史事件、时间节点、历史意义
  - 党的重要会议（一大到二十大关键内容）、伟大精神谱系
# 法律常识（高频模块）
1. 宪法
  - 国家机构、公民的基本权利与义务、宪法修正案
  - 国旗、国歌、国徽、首都等基本规定
2. 行政法与行政诉讼法
  - 行政主体、行政行为（行政许可、行政处罚、行政强制）
  - 行政复议、行政诉讼的管辖与程序
3. 民法与民事诉讼法
  - 民事主体（自然人、法人、非法人组织）、民事权利（物权、债权、人格权）
  - 合同编、侵权责任编核心条款（如违约责任、过错责任）
4. 刑法与刑事诉讼法
  - 犯罪构成、正当防卫与紧急避险、刑罚种类
  - 常见罪名（盗窃、诈骗、交通肇事等高频考点）
5. 其他常用法律
  - 民法典最新修订内容、食品安全法、环境保护法、劳动法（劳动合同、工伤认定）
# 经济常识（基础模块）
1. 宏观经济学
  - 国民经济指标（GDP、CPI、PPI、失业率）
  - 财政政策与货币政策（工具、作用、调控目标）
  - 通货膨胀与通货紧缩
2. 微观经济学
  - 供求理论、价格机制
  - 市场类型（完全竞争、垄断竞争、寡头垄断、完全垄断）
3. 国际经济与贸易
  - 汇率、外汇储备
  - 国际贸易组织（WTO）、区域经济一体化
4. 中国经济热点
  - 供给侧结构性改革、高质量发展
  - 乡村振兴、共同富裕、数字经济等战略
