# 什么是词的辨析？

这类题的形式比较固定，都是给出一段话然后让你选择空白横线处应该选择的词，以一个2019年福建的行例子让大家明白这种题的形式是怎么回事儿。

![](../_images/quesion_imgs_1c688134e7f741138815ed0e398ce57f.png)

**题目形式：** 要清楚地认识现代与传统的区别以及东西方划分的误区，单从理论上加以\_\_\_\_是不够的，还需回放历史变迁的场景，探索东西方概念出现的历史渊源，\_\_\_\_\_造成这一思维定势的心理原因。依次填入画横线部分最恰当的一项是()

A.说明 辨识

C.说明 辨析

B.阐发 判别

D.阐扬 辨别

以上例子只为让大家明白题的形式，其实可以看出题的形式非常简单，并且考察的内容实际上也是高中语文类似的东西。

# 词义分类

词义分类是行测言语理解与表达中**逻辑填空题型**的核心解题依据，通过从语义范畴、侧重方向、程度轻重、搭配习惯、情感倾向五大维度辨析近义 / 易混词语，可精准匹配文段语境，锁定正确答案。

## 词义范围

指词语所指向的**适用对象、语义涵盖范畴的大小差异**，是词义辨析的基础维度。

-   水果 vs 苹果： “水果”范围大（包括苹果、香蕉等）； “苹果”范围小（单指苹果）。
-   行测考点： “开拓 vs 开辟”： “开拓”范围小（在原有基础上扩展，如“开拓市场”）； “开辟”范围大（从无到有，如“开辟新航线”）。

## 词义侧重点

指词语**核心语义指向、强调的角度与关注点**存在本质差异，是行测词义辨析的最高频考点。

-   看 vs 观察： “看”只是用眼睛； “观察”强调仔细看并分析。
-   行测考点： “大相径庭 vs 背道而驰”： “大相径庭”侧重差异大（如商品与照片不符）； “背道而驰”侧重方向相反（如“关闭菜市场”与便民相反）。

## 轻重程度

指词语表达的情感、行为、性质的**深浅、强弱层级不同**，需与文段语境的轻重程度严格匹配。

-   例子： 生气 vs 愤怒： “生气”程度轻； “愤怒”程度重。
-   行测考点： “理所当然 vs 天经地义”： “理所当然”程度轻（如“19岁应独立”）； “天经地义”程度重（如“民族荣誉不容置疑”）。

## 固定搭配

某些词只能和特定对象搭配。

-   例子： 穿衣服 vs 戴帽子： “穿”搭配上衣、裤子； “戴”搭配帽子、首饰。
-   行测考点： “沉淀 vs 积淀”： “沉淀”搭配具体事物（如“茶叶沉淀”）； “积淀”搭配抽象事物（如“文化积淀”）。

## 情感色彩

指词语在长期语言使用中形成的**约定俗成的搭配对象、语法习惯**，搭配关系不可随意替换，是逻辑填空快速破题的关键。

-   例子： 胖 vs 丰满： “胖”中性/略贬义； “丰满”褒义。
-   行测考点： “根深蒂固 vs 积重难返”： “根深蒂固”中性（如“陈旧观念”）； “积重难返”贬义（如“不良习惯难改”）。

## 词意分类总结
| 辨析角度 | 简单例子 | 行测例子 |
| --- | --- | --- |

# 例题解析

## 词义侧重
| 词义侧重：理解每个选项词语的基本含义及其侧重点。例如，“成果”和“结果”虽然都指事情的结局，但“成果”通常带有正面评价。 |

**例题：** 治理环境确为政府职责，环境出现问题，其监管\_\_\_\_\_\_\_\_，执法不严难逃其责，但是，当大家不断\_\_\_\_\_\_\_\_政府不作为时，是不是也应该\_\_\_\_\_\_\_\_一下自己：我们有没有污染环境? 依次填入划横线部分最恰当的一项是：

A.不周 斥责 检查

B.不力 指责 检讨

C.不善 苛责 检点

D.不当 谴责 检察

【解析】第一步，分析第一空。该空与“监管”搭配。A项“不周”可以拆字组词，不周到，比如，照顾不周;C项“不善”可以考虑常见搭配，比如处理不善、经营不善，体现不好的意思。二者一般不与“监管”搭配，排除A项和C项。B项“不力”可以拆字组词，不尽力、不得力。D项“不当”可拆字组词，不合适、不恰当。二者均可搭配“监管”。

第二步，分析第三空。根据“我们有没有污染环境?”这一反问句可知，第三空应是“反思自身、反躬自省”的意思。B项“检讨”可以考虑常见搭配“检讨书”“自我检讨”强调反省自己的过错，符合文意。D项“检察”可拆字组词，检举考察，不能体现“反省”之意，排除D项。因此，选择B选项。

## 固定搭配
| 固定搭配：考虑词语的固定搭配。有些词语在特定情况下有固定的搭配方式，如“提高水平”而不是“提升水平”。 |
| --- |

**例题2：** 冰川，顾名思义，冰之河流也。不同的是，河流动如脱兔，冰川\_\_\_\_\_\_\_\_;河流一泻千里，冰川却只能往前蠕动。当然，二者也有相似之处：河流可以载舟也可以覆舟，冰川也是一样。河流或哗哗流淌，像在低吟;或翻腾咆哮，像在高歌。冰川有时会劈啪作响，像在\_\_\_\_\_\_\_\_;有时会震天怒吼，像在\_\_\_\_\_\_\_\_。依次填入划横线部分最恰当的一项是：

A 镇定自如 鼓掌欢呼 愤怒焦虑

B 静若处子 自言自语 大声疾呼

C 幼稚调皮 嬉戏玩耍 激愤抗议

D 纯洁剔透 出声思考 激动欢呼

解析：第一步，分析第一空。根据语境“不同的是，河流动如脱兔”可知，此处彰显的是冰川的安静，另“静如处子，动如脱兔”是固定搭配，形容军队行动之前时像未出嫁的姑娘那样沉静，一旦行动就像飞跑的兔子那样敏捷。答案锁定B项。

第二步，验证第二空和第三空。冰川“劈啪作响”指发出的声音很低，“像在自言自语”与之对应，符合语境。冰川“震天怒吼”指声音很大，“大声疾呼”，与之对应，符合语境。因此，选择B选项。

## 轻重程度&感情色彩
| 轻重程度：词语的轻重程度指的是两个词语意思相近，但轻重程度不同。例如，“失望”和“绝望”都有“没有希望，失去信心”的意思，但“绝望”的程度比“失望”更重。理解词语的轻重程度对于正确解答行测题目至关重要，因为它涉及到选择与文段程度最为匹配的词语。如果文段中出现表示程度重的词语，如“最”、“彻底”、“完全”、“必须”、“非常”，这通常意味着后面填入的词语程度也是比较重的。相反，如果文段中出现表示程度轻的词语，如“稍微”、“略微”、“有点”、“仅仅”，这通常意味着后面填入的词语程度是比较轻的。文段中的递进关系也是一个重要的指示，如果递进关系中前后感情色彩一致，那么语义前轻后重。 |
| --- |

| 感情色彩： 根据感情色彩，词语可分为：褒义词、贬义词、中性词。大家在做题时，需要根据现有句子所提供的语境，判断作者的感情态度和褒贬意味，从而选出与作者感情色彩最相符合的词语。 |
| --- |

**例题3：** 疯狂扩散的蓝藻起初并没有使人们感到（ ）。往年正常情况下，它顶多影响太湖的一些景观，不会带来什么骚乱。雨季一来，这些小生物会被大量的雨水冲刷稀释，人们会渐渐（ ）它，直到第二年的来临。还有一些农民把它们捞起来当肥料，（ ） 地称之为“海油”。

填入划横线部分最恰当的一项是：

A、焦虑 淡忘 亲切 B、担忧 漠视 形象

C、异样 适应 生动 D、奇怪 习惯 幽默

解析：此题答案为A。蓝藻存在多年，人们都习以为常，所以第一空填“异样”、“奇怪”不恰当，排除C、D。第三空中，“形象”、“亲切”看起来都可以填，但由“一些农民把它们捞起来当肥料”可知，蓝藻能够为农民所用，因此从感情色彩的角度来看，“亲切”更符合句意，它比“形象”更能表达出蓝藻对农民有利的那层含义。

# 浣熊真题
| 【航天科技（2025 年）】依次填入横线处的词语，最恰当的一组是（ ）。①他______着青春的天真，在事业上取得了很大的成绩。②为了______未来的需要，我们必须努力储存精力。③这场比赛失败了，但他们并没有灰心，而是______经验教训，准备再干。A. 天真 储存 吸取B. 蹉跎 储备 汲取C. 挥霍 储备 汲取D. 无邪 储存 吸取答案：A解析：B 项“挥霍”常与金钱、时间搭配，C 项“蹉跎”常与时间搭配，均不能与“精力”搭配，排除 B、C 两项；第一空需填与“成熟态度”反义的“天真”（形容青春更贴切）；“储存”指为未来积累，更契合“以备寒冬之用”的语境。 |

| 【中国石化（2019 年）】定义的使命是抽象、概括出某类事物的本质特征。当定义概括不了时，本应修正定义，而有人却常常“开除”那些概括不了的同类事物，以维护定义的纯洁性，这无疑是_________。A. 指鹿为马B. 削足适履C. 自欺欺人D. 瓜田李下答案：B解析：“削足适履”比喻为迁就现成条件而不合理地调整自己，此处指“为维护定义纯洁性开除概括不了的事物”，完全符合词义。 |

| 【中储粮（2019 年）】刚从事遥感考古工作的同志，________希望能验证一下自己的成果，_____希望在验证过程中获取经验和教训，________有误，________可以弄清失误的原因，找到正确的方向。A. 即使 也 不但 更B. 也 更 即使 不但C. 不但 更 即使 也D. 更 也 不但 即使答案：C解析：第一、二空为递进关系（“验证成果”→“获取经验教训”），用“不但……更”；第三、四空为假设关系（“有误”→“弄清原因”），用“即使……也”。 |

| 【国家管网（2025 年）】①中晚唐时期藩镇割据，人们在动荡的社会中对现实不满，把兴仁除害的期盼_____伸张正义的侠客身上。②这届领导班子成员年轻有为，会想能干，村民们_____厚望，盼着选出的领头人能带领大家脱贫致富。③进入新世纪的这一年，我不断审视自己，从头认识生活，重新估量生活每天_____了我什么。A. 寄于 寄予 赋予B. 寄于 寄予 给予C. 寄予 寄于 给予D. 寄予 寄于 赋予答案：B解析：“寄于”指寄托在（某处/人）（第一空“期盼寄于侠客”）；“寄予”指寄托（希望/厚望）（第二空“寄予厚望”）；“给予”为一般意义的供给（第三空“生活给予我什么”，非重大使命，不用“赋予”）。 |

| 【中国联通（2025 年）】近年来因程序违法败诉的行政诉讼案件不少。尽管有前车之鉴，但是依然不乏职能部门________。说到底，还是“重结果，轻程序”，不把程序当回事，行政行为自然经不起推敲。程序是保证我们有效实现结果的合理设计，程序正当得不到________，必然给我们的事业造成损害。A. 明知故犯 履行B. 老调重弹 落实C. 重蹈覆辙 尊重D. 以身试法 认同答案：C解析：第一空“重蹈覆辙”指不吸取失败教训、重犯过去错误（对应“有前车之鉴仍犯”的语境）；第二空“程序正当得不到尊重”直接呼应“不把程序当回事”的核心逻辑。 |
