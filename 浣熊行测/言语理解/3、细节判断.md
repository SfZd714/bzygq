# 什么是细节判断题？

细节判断题是行测中要求根据文段的具体细节，判断某个陈述是否与原文内容一致的题型。正确答案必须完全符合文段内容，不能有任何偏差或引申。解题时需回到原文仔细对比题目中的陈述与文段中的描述，特别注意否定词、数量词等细节。常见的干扰选项包括对原文的细微扭曲、无关信息或过度引申，考生应避免凭借常识推测答案，必须严格依据原文内容作出判断。

![](../_images/quesion_imgs_aba14ef9f77944f5b7e3e5655f09b362.png)

# 提问方式？

-   对以下文本理解正确/不正确的是？
-   符合/不符合这段话意思的是？
-   从文段中可以得出/推出的是？
-   关于……，上文提到了/没有提及……

# 解题方法

## 解题步骤

行测中的细节判断题要求考生根据文段内容，判断给定选项是否与原文一致，以下是常用的解题方法：

![](../_images/quesion_imgs_1b349378296d44e786d3f89015d099f8.png)

1.  回读原文：首先仔细阅读题干中的陈述或选项，明确其核心内容，然后回到原文找到对应的细节进行对比，确保理解准确。
2.  逐字对比：对比选项与原文中的表述，注意细节上的一致性，特别关注数量词、否定词、程度词等可能改变意思的细节。
3.  排除干扰：排除选项中包含无关信息、断章取义或过度引申的内容，确保选择的答案是与原文完全一致的。
4.  注意常见陷阱：无中生有、偷换概念、偷换时态、偷换逻辑、绝对化表述

## 细节判断题五大陷阱

### 无中生有

无中生有是指选项中的信息在原文中并不存在，或者选项中的内容并未在原文中提及，但选项却无故添加了这些内容。
| 【例题】“近年来，随着人们环保意识的提高，电动汽车逐渐成为市场的主流选择。这些车辆不仅能够减少碳排放，还因为其低噪音和低维护成本而受到消费者的青睐。许多城市也在大力推动电动汽车的普及，提供了诸如充电站建设等政策支持。”根据文段内容，下列说法正确的是：A. 电动汽车已经完全取代了传统燃油车。B. 电动汽车因环保优势逐渐受到欢迎。C. 所有城市都在推广电动汽车。D. 电动汽车的高价格使得消费者难以接受。答案：B解析：A选项，文段提到电动汽车“逐渐成为市场的主流选择”，但没有说“完全取代了传统燃油车”，这个选项属于无中生有；B选项，文段提到电动汽车因环保优势和其他优点受到欢迎，因此这个选项是正确的；C选项，文段提到“许多城市”在推广电动汽车，但并没有说“所有城市”都在推广，所以这个选项也是无中生有；D选项，文段中没有提到电动汽车的价格问题，所以这个选项也是无中生有。 |

### 偷换概念

偷换概念是指选项对原文中的概念进行了替换（如主体、范围、性质），用相似或相关的概念误导考生。例如：
- 原文：”某手机支持IP68级防水”
- 选项：该手机可以在水下10米长时间使用
- 分析：这就属于无中生有，因为原文“防水等级”是实验室测试标准，选项偷换为“实际使用场景”，概念范围被扩大。 

| 【例题】“随着健康意识的提升，越来越多的人选择有机食品，因为它们不含人工添加剂。”下列哪项是对文段内容的正确理解？A. 人们选择有机食品是因为它们没有任何化学成分。B. 有机食品受欢迎是因为其不含人工添加剂。C. 有机食品能够完全避免化学污染。D. 所有有机食品都是天然生长的。答案：B解析：A选项，偷换概念，文段提到的是“不含人工添加剂”，而选项替换为“没有任何化学成分”，两者并不等同；B选项，符合原文，正确；C选项，偷换概念，“完全避免化学污染”与原文的“无人工添加剂”不同；D选项，偷换概念，文段未提到“天然生长”。 |
| --- |

### 偷换时态

偷换时态是指改变事件发生的时间状态（过去/现在/将来），示例：
- 原文：老师说：“明天作业要交”
- 选项：老师昨天布置了作业
- 分析：原文“明天交”（将来时）被偷换为“昨天布置”（过去时）。 

| 【例题】“去年，公司发布了新款智能手机，获得了市场的积极反馈。”根据文段，下列哪项是正确的？A. 公司即将发布新款智能手机。B. 去年，公司发布了新款智能手机。C. 公司发布的新款智能手机未获得市场好评。D. 公司正在考虑发布新款智能手机。答案：解析：A选项，偷换时态，将过去的事件改为未来发生；B选项，与原文一致，正确；C选项，与原文相反，错误；D选项，无中生有，原文未提到正在考虑。 |
| --- |

### 偷换逻辑

所谓偷换逻辑是指颠倒因果关系或混淆逻辑关系，改变了原文中的逻辑关系示例：
- 原文：坚持运动的人更健康
- 选项：健康的人才能坚持运动
- 分析：原文“运动→健康”的因果关系被倒置为“健康→运动” 

| 【例题】“因为城市绿化的改善，所以空气质量明显提升。”下列哪项符合原文的意思？A. 因为空气质量提升，所以城市绿化改善。B. 城市绿化的改善导致空气质量提升。C. 空气质量的改善与城市绿化无关。D. 城市绿化未改善，空气质量却提升了。答案：B解析：A选项，偷换逻辑，将因果关系倒置；B选项，符合原文逻辑，正确；C选项，与原文内容相反；D选项，与原文内容相悖。 |
| --- |

### 绝对化表述

绝对化表述是指选项使用绝对化词语，如“所有”、“必须”、“绝不”等，而原文可能只提到了一种倾向或大多数情况，示例：
- 原文：考试前复习可能提高成绩
- 选项：考试前复习一定能拿满分
- 分析：原文“可能”被替换为“一定”，表述绝对化。 

**绝对标志词：** 一定、全部、完全、所有、均、永远、任何、取代、主导、唯一、只要……就……、无论……都……等
**相对标志词：** 可能、也许、或许、大概、一般、尽量、往往、容易、之一。

| 【例题】“大多数医生认为定期锻炼对健康有益，但也有少数医生持不同观点。”根据文段，下列哪项是正确的？A. 所有医生都认为定期锻炼对健康有益。B. 大多数医生认为定期锻炼对健康有益。C. 绝不可能有人反对定期锻炼。D. 定期锻炼对健康无益。答案：B解析：A选项，绝对化表述，将“大多数”扩大为“所有”；B选项，与原文一致，正确；C选项，绝对化表述，文段提到了“少数医生”持不同观点；D选项，与原文内容相反。 |

## 浣熊真题
| 【中国石化2014】科学家发现产生某些人对药物反应不同的现象的原因在于这类人拥有特定的基因。下列关于原文内容的表述，正确的一项是（ ）
A. 基因学的研究成果已广泛应用于医学实践；
B. 用药不当导致基因变异；
C. 产生这种现象的原因是这类人拥有特定的基因；
D. 人的健康长寿离不开正常的菌群
答案 ：C
解析 ：根据原文“但是要真正实现（基因学研究成果应用于医学），恐怕为时尚早”可知 A 项错误；原文指出“不是用药不当导致基因变异，而是基因的差异使得人体对药物的反应不一样”，故 B 项错误；原文明确“科学家发现产生这种现象的原因在于这类人拥有特定的基因”，因此 C 项正确；D 项“人的健康长寿离不开正常的菌群”为无中生有 |
| --- |

| 【中航工业2025】医学上的失语症是指一个人与语言功能有关的脑组织出现严重病变，他的语言认知能力、语言判断能力和语言表达能力遭到严重损害，他对语音、语法、语义等的理解和表达存在阻断性障碍。道德失语症不是指一个人对语音、语法、语义等的理解和表达存在阻断性障碍，而是指一个人在面对善恶选择问题时习惯性地不愿意或不敢借助道德语言能力表达其善恶判断、善恶评价和善恶选择。医学上的失语症患者确实没有语言能力，而道德失语症患者是拥有道德语言能力但习惯性地不愿意或不敢发挥这种能力的人。医学上的失语症是非选择性的，而道德失语症是选择性的。关于这段文字的理解和推测，有误的一项是（ ）
A. 作者接下去论述的重点应该是关于道德失语症；
B. 道德失语症在一定程度上是受医学失语症影响的；
C. 要治疗道德失语症，个体需要不断加强道德修养；
D. 一个人偶然性道德失语，那他还不算有道德失语症
答案 ：B
解析 ：原文仅分别解释“医学失语症”和“道德失语症”的定义及差异，未提及“道德失语症受医学失语症影响”，B 项无依据；A 项根据“道德失语症是选择性的”可推测作者后续会展开论述；C 项根据“道德失语症患者是拥有道德语言能力但习惯性不愿意/不敢发挥”可推出需加强道德修养；D 项根据“习惯性地不愿意或不敢”可推出偶然性不算 |
