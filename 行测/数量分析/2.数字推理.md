# 数字推理概述？

数字推理的题，你在初中高中考试的试卷上肯定做过类似的，形式比较单一都是给出一列数字，让你发现规律，然后添上空缺的部分。

例如：1、2、4、\_\_\_\_\_、16、32，其中横线部分应该填写什么？

这种简单的数字推理一眼就可以发现答案，都是从2的0次方一直到2的5次方，因此答案是8。当然，真实的行测考题中数字推理不会那么简单，但是也都是加减乘除规律组合而成的，需要我们多练习，花时间去了解和掌握。

## 常见规律

想要快速解决数字推理题型，那么对于数字推理常见的规律必须非常熟悉，才能在考试的时候快速找出题目当中的数字规律，这里帮大家总结好了14种全部数字推理的规律表格：
| 类别 | 数列示例 | 特征说明 |
| --- | --- | --- |
| 常数数列 | 7, 7, 7, 7, 7, 7, 7, ... | 每一项都是相同的常数。 |
| 自然数列 | 1, 2, 3, 4, 5, 6, 7, ... | 从1开始，每次增加1。 |
| 奇数列 | 1, 3, 5, 7, 9, 11, ... | 所有的奇数。 |
| 偶数列 | 2, 4, 6, 8, 10, 12, ... | 所有的偶数。 |
| 自然数平方 | 1, 4, 9, 16, 25, 36, ... | 每个自然数的平方。 |
| 自然数立方 | 1, 8, 27, 64, 125, 216, ... | 每个自然数的立方。 |
| 等差数列 | 1, 6, 11, 16, 21, 26, ... （公差为 5） | 相邻两项之差等于固定值（公差）。 |
| 等比数列 | 1, 3, 9, 27, 81, 243, ... （公比为 3） | 相邻两项之比等于固定值（公比）。 |
| 质数数列 | 2, 3, 5, 7, 11, 13, 17, 19, ... | 只能被1和自身整除的自然数。 |
| 合数数列 | 4, 6, 8, 9, 10, 12, 14, 15, ... | 除了1和质数之外的自然数。 |

| 幂次数列 | 平方数列：1, 4, 9, 16, 25, ..立方数列：1, 8, 27, 64, 125, ... | 每个自然数的平方或立方。 |

# 数字推理常见题型

## 多级数列

多级数列是指通过对原数列中的相邻项进行数学运算（如加、减、乘、除、乘方等）得到一个新的数列（称为次生数列），再通过对次生数列进行类似的运算得到更高层次的次生数列，以此类推，直到找到一个有明显规律的数列，然后利用这个规律反推回原数列，从而求解原数列中的未知项。

1、**12，13，15，18，22，（ ）**

规律：从第二个数开始，每个数与前一个数的差依次为1、2、3、4、...，所以接下来的差应该是5，即22+5=27。

2、**10，18，33，（ ），92**

规律：从第二个数开始，每个数与前一个数的差分别是8（2\*4）、15（3\*5）、24（4\*6）、35（5\*7）。

3、**5，12，21，34，53，80，（ ）**

规律：从第二个数开始，每个数与前一个数的差分别是7、9、13、19、27，这些差值本身构成了一个新的数列，其差值依次为2、4、6、8，因此下一个差值应该是10，即27+10=37，80+37=117。

4、**2/3, 3/2, 4/3, 3, 8/3, ( )**

规律：这个数列可以转换为2/3, 3/2, 4/3, 9/3, 8/3，即分子为2、3、4、9、8，分母为3、2、3、3、3。分子序列看起来没有直接规律，但如果考虑到分子实际上是2、3、4、(3\*3)、8，可以推测下一个数的分子可能是16（因为8\*2=16），保持分母为3不变。

5、**4, 10, 30, 105, 420, ( )**

规律：数列中相邻两项的比值依次为2.5、3、3.5、4，形成一个公差为0.5的等差数列，因此下一项的比值应该是4.5，即420 \* 4.5 = 1890。

6、**150，75，50，37.5，30，（ ）**

规律：数列中的每一个数都是前一个数的特定比例，即0.5、2/3、0.75、5/6，下一个比例应该是6/7，因此30 \* (6/7) = 25.714，最接近的是25。

7、 **0，4，16，40，80，（ ）**

规律：数列中的数分别是 ，下一个数应该是

8、 **（ ），36, 19, 10, 5, 2**

规律：数列中的每个数是前一个数减去一个递增的数列（17、9、5、3、1），因此缺失的第一个数应该是36 + 17 = 53。

以上8个例子，是多级数列当中比较常见的形式，大家务必多看几遍去领悟这类题型的规律。

## 递推数列

所谓递推数列，是指数列中从某一项开始，其每项都是通过它前面的项经过一定的运算得到。对给出的数列前两项或前三项进行加、减、乘、除、乘方、倍数等运算与后面一项进行比较，找出规律。有时还有修正项（重点也是难点），且修正项在变化。

### 递推和数列

![](../_images/quesion_imgs_1d71a8ec354f47ed8912ab635b0ba073.png)

**特点**：各项数值逐渐递增，变化幅度增大，但总体变化较平稳。

**解题方法**：前两项相加等于第三项或前几项相加与下一项进行比较。

**示例**：0，1，1，2，4，7，13，（ ）
**解析**：前三项的和等于下一项，，所以答案是24.

### 递推差数列

![](../_images/quesion_imgs_c319219fb15346abb45813bbc0083b80.png)

**解题方法**：将前两项之差与下一项进行比较。
**示例**：25，15，10，5，5，（ ）
**解析**：前两项的差等于下一项，，所以答案是0

### 递推积数列

![](../_images/quesion_imgs_f09774bba6bf40e0bad513617b31c0a7.png)

**特点**：如果前几项值较小，则后项值不太大；如果前几项值较大，则后项值会迅速增大。
**解题方法**：将前两项之积与下一项进行比较。
**示例**：2，3，9，30，273，（ ）
**解析**：前两项的积加3等于下一项，2 \* 3 + 3 = 9，3 \* 9 + 3 = 30，9 \* 30 + 3 = 273，30 \* 273 + 3 = 8193，所以答案是8193.

### 递推商数列

![](../_images/quesion_imgs_80f9bcc2501d4882b21031199a614b37.png)

**解题方法**：将相邻两项做商与前后项进行比较。
**示例**：9, 6, 3/2, 4，（ ）
**解析**：相邻两项相除等于下一项，，所以选答案是3/8

### 练习

**练习1：1，2，2，3，4，6，（ ）**

解析：这题是递推和数列的变式，前二项的和减1等于第三项，1 + 2 - 1 = 2，2 + 2 - 1 = 3，2 + 3 - 1 = 4，3 + 4 - 1 = 6，4 + 6 - 1 = 9，所以答案是 9

**练习2：12，4，8，6，7，（ ）**

解析：这题是递推和数列的变式，前二项的和除以2等于后一项，(12 + 4) / 2 = 8，(4 + 8) / 2 = 6，(8 + 6) / 2 = 7，(6 + 7) / 2 = 6.5，所以答案是 6.5

**练习3：1，3，5，11，21，（ ）**

解析：是递推和数列的变形，研究“5，11，21”三个数字递推联系，易知“5 × 2 + 11 = 21”，验算可知全部成立，所以答案是 11x2+21=43。

**练习4：1，3，3，9，（ ），243**

解析：这是典型的递推积数列题，从第三项起，每一项都是前两项的乘积，1 \* 3 = 3，3 \* 3 = 9，3 \* 9 = 27，9 \* 27 = 243，所以答案是 27.

**练习5：50，10，5，2，2.5，（ ）**
解析：这是典型的递推商数列题，从第三项起，每一项都是前两项之商，50 / 10 = 5，10 / 5 = 2，5 / 2 = 2.5，2 / 2.5 = 0.8，所以答案是 0.8.

## 分式数列

分式数列是指分式为主体，分子、分母成为数列元素。

### 基本知识点

-   **经典分数数列**：以“数列当中各分数的分子与分母”为研究对象的数列形式。
-   **整化分**：当数列中含有少量非分数形式时，常常需要以“整化分”的方式将其形式统一。
-   **含有少量分数的题型**：
    -   ① 负幂次形式
    -   ② 做积商多级数列
    -   ③ 递推积商数列
-   **基本分数知识**：
    -   **约分**：将分数化简。
    -   **通分**：分母通分、分子通分。
    -   **反约分**：约分的反过程，如：1 = 3/3，2/3 = 4/6，4/9 = 8/18。
    -   **有理化**：分子有理化、分母有理化。

### 常见题型详解

## 等差数列及其变式

![](../_images/quesion_imgs_0c3ecdaa41cd4333bd56ff09c11f14c1.png)

-   **示例**：2，11/3, 28/5, 53/7, 86/9, ( )
-   **解析**：将2写成2/1，分母1, 3, 5, 7, 9, (11)是等差数列；分子2, 11, 28, 53, 86, (127)相差：9, 17, 25, 33, (41)，公差为8的等差数列，所以答案是127/11=41

## 等比数列及其变式

-   **示例**：8/9，-2/3, 1/2, -3/8, ( )
-   **解析**：是公比为-3/4的等比数列，所以答案是 1/2。

## 和数列及其变式

![](../_images/quesion_imgs_7887644ee43344c680cbc44fb4268bc0.png)

-   **示例**：3/2，5/7, 12/19, 31/50, ( )

## 组合数列

组合数列是由两个或两个以上数列组合而成的数列，一般是把基础数列重新排列组合或者经过简单运算得到的新的数列。

### 常见组合数列类型

## 奇偶项分组

![](../_images/quesion_imgs_0596b7cef6ab411da51f45e9bbe9a16d.png)

-   **定义**：奇偶项组合数列指的是数列的奇数项满足某种规律，偶数项也满足某种规律。奇数项满足的规律和偶数项满足的规律可以相同，也可以不相同。
-   **特点**：奇数项适用一种规律，偶数项适用一种规律。
-   **示例**：2，4，8，16，14，64，20，（ ）
-   **解析**：奇数项组成公差为6的等差数列，偶数项组成公比为4的等比数列，2, 8, 14, 20，4, 16, 64, 所以答案是256.

## 相邻分组

![](../_images/quesion_imgs_7dccdf68dc5744a9b6306c9082388b83.png)

-   **定义**：每两（三）项分段得到规律的数列。
-   **特点**：每二项（或三项）为一段，适用某种共同的规律。
-   **示例**：4，5，8，10，16，19，32，（ ）
-   **解析**：每相邻两项分做一组，即（4，5)，(8，10)，(16，19)，(32，（ ））。二者之差分别是 1，2，3，所以（ ）＝32 + 4，所以答案是36。

## 单项分组

![](../_images/quesion_imgs_4b51f6fcbb30489082981fce4b4e3bef.png)

-   **定义**：将数列的每一项分解为两项或多项，然后把数列分为两个数列或多个数列进行分析推理的过程。
-   **特点**：数列各项的不同部分各自适用不同的规律。
-   **示例**：2.01，4.03，8.04，16.07，（ ）
-   **解析**：数列中整数部分组成的数列：2，4，8，16，是公比为2的等比数列，小数部分：1，3，4，7，为递推和数列，从而知（ ）＝32.11，所以答案是32。
