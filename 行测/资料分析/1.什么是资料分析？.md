# 1.什么是资料分析？

行测中的**资料分析**，是“给定统计材料（文字/表格/图表），快速提炼数据、列对公式、巧解答案”的模块——不考深奥逻辑，核心拼“找数效率”和“计算技巧”，是行测高分的“性价比之王”。

# 资料分析核心考查内容

## 类高频材料

-   文字资料：大段文字嵌套数据，需抓“关键词+时间+单位”快速定位
-   表格资料：数据结构化呈现，重点盯表头、行列标注，避免找错数据维度
-   图形资料：柱状图（比大小）、折线图（看趋势）、饼图（算占比）等，直观反映数据关联

## 大基础考点

资料分析的知识点实际上不难，基本全是小学+初中数学范畴，围绕“数据关系”展开，这里给大家汇总了一些常见的基础考点：

-   增长类：增长率、增长量（核心高频，占比超50%）
-   比例类：比重、倍数、平均数（公式固定，灵活套用即可）
-   时间类：基期（求过去值）、现期（求现在/未来值）
-   基础操作：比较大小、排序、直接查找（送分题，快速拿满）

## 解题核心准则

**找数快、列式准、算得巧**——硬算=浪费时间，技巧才是提分关键。

# 行测常见题型

## 文字资料：侧重 “定位数据 + 快速列式”

大段文字（通常 1-3 段）嵌套多个数据，信息分散，**找数比计算难**，易踩 “时间 / 单位 / 关键词” 陷阱，常见题型（按考频排序）：

1、**基期量计算**

-   题干特征：求 “去年 / 上一年 / 若干年前” 的某数据（例：2023 年 XX 值为 A，增长率 10%，求 2022 年 XX 值）
-   对应公式：基期量 = 现期量 ÷（1+r）（r≤5% 用近似公式：现期 ×（1-r））
-   速算技巧：截位直除（除数截前 2-3 位），结合选项差距判断估算精度

2、**增长率比较**

-   题干特征：“以下哪项增速最快 / 最慢”“同比增速排序正确的是”
-   对应公式：r =（现期 - 基期）÷ 基期 = 现期 ÷ 基期 - 1
-   解题关键：优先用 “现期 ÷ 基期” 估算（不用算完整值），结合分数比较技巧（分子大分母小则分数大）

3、**比重综合题**

-   题干特征：求 “某部分占整体的比重”“部分量占比同比上升 / 下降”
-   对应公式：比重 = 部分量 ÷ 整体量；部分量 = 整体量 × 比重
-   找数技巧：先圈出 “整体” 关键词（如 “全国总量”“总销售额”），再找对应 “部分” 数据，避免找错主体

4、**增长量计算**

-   题干特征：求 “同比增长了多少”（带单位，如亿元、万人）
-   对应公式：增长量 = 现期 ×r÷（1+r），r=1/n 时近似为现期 ÷（n+1）
-   高频应用：百分数化分数（如 r=16.7%=1/6，增长量≈现期 ÷7），快速得出答案

避坑要点：

-   注意文字中 “累计 / 当月”“同比 / 环比”“进口 / 出口” 等易混淆关键词；
-   单位统一（如亿元 vs 千万元、增长率 % vs 小数）。

# 表格资料：侧重 “数据匹配 + 高效计算”

数据以表格形式结构化呈现，表头 + 行列标注清晰，**找数快但易看错行列维度**，计算题型占比高，常见题型（按考频排序）

1、 **平均数计算 / 比较**

-   题干特征：“人均 XX”“每单位 XX 的产量”“以下类别平均水平最高的是”
-   对应公式：平均数 = 总数 ÷ 个数（例：人均收入 = 总收入 ÷ 总人数）
-   解题技巧：横向 / 纵向定位 “总数” 和 “个数” 列，用截位直除快速计算，比较类题目优先估算量级

2、**现期量计算**

-   题干特征：“按当前增速，2024 年 XX 值将达到多少”（求未来值）
-   对应公式：现期量 = 基期量 ×（1+r）
-   速算技巧：r 较小时（≤10%），可近似计算（基期 + 基期 ×r）；r 较大时，结合截位乘法

3、**倍数 / 多几倍问题**

-   题干特征：“A 是 B 的几倍”“A 比 B 多几倍”
-   对应公式：倍数 = A÷B；多几倍 = A÷B - 1（易错点：勿把 “多几倍” 当成 “是几倍”）
-   解题关键：直接定位表格中 A、B 对应数据，截位直除后快速匹配选项

4、**直接查找 + 排序**

-   题干特征：“2023 年 XX 值超过 100 的有几个”“按 XX 值从高到低排序正确的是”
-   解题技巧：不用计算，直接圈出目标数据，注意 “大于 / 小于”“从高到低 / 从低到高” 的题干要求，避免粗心错误

避坑要点：

-   先看表头（明确时间、主题），再看行列标注（如 “东部 / 中部 / 西部”“第一季度 / 第二季度”）；
-   注意表格中 “空格”“-” 可能代表 “0” 或 “无数据”，结合题干判断。

# 图形资料：侧重 “趋势判断 + 比例计算”

以柱状图、折线图、饼图为主，数据直观，**易看趋势但需注意图表细节**，比例类、趋势类题型高频。

## 柱状图（含条形图）：侧重 “比大小 + 算增长”

1、**增长量比较**

-   题干特征：“哪一年同比增长最多”“增长额最大的季度是”
-   解题技巧：直接看柱状图高度差（不用计算，高度差越大，增长量越大），差距不明显时再用公式估算

2、**现期比重计算**

-   题干特征：“2023 年 A 类占所有类别的比重”（柱状图多类别求和）
-   对应公式：比重 = A 类数值 ÷（所有类别数值之和）
-   速算技巧：尾数法求和（所有类别数值末 1-2 位相加），再用截位直除算比重

## 折线图：侧重 “增长率 + 趋势判断”

1、 **增长率计算**

-   题干特征：“折线图中 2023 年增速比 2022 年高多少个百分点”
-   对应公式：r=（现期 - 基期）÷ 基期
-   解题技巧：从折线图读取现期、基期数值，结合截位直除快速计算，注意 “百分点” 是增长率的差值（直接相减）

2、**趋势预测**

-   题干特征：“根据 2021-2023 年趋势，2024 年最可能的数值是”
-   解题技巧：观察折线斜率（增速变化），结合年均增长率估算，不用精确计算，匹配选项趋势即可

## 饼图：侧重 “比重 + 部分量计算”

1、**比重查找 / 计算**

-   题干特征：“占比最大的类别是”“A 类占比约为多少”
-   解题技巧：饼图扇区越大占比越高，标注 “占比” 直接读，未标注则用 “部分量 ÷ 总量” 计算（总量 = 所有部分量之和）

2、**部分量计算**

-   题干特征：“已知总量为 X，A 类占比 30%，求 A 类数值”
-   对应公式：部分量 = 总量 × 比重
-   速算技巧：百分数化小数（30%=0.3），截位乘法（总量截前 2-3 位）

避坑要点：

-   注意图表标题（明确时间、主题）和图例（区分类别）；
-   饼图 “未标注占比” 时，勿凭视觉判断（可能存在视角误差），优先用数值计算；
-   折线图、柱状图注意横轴（时间 / 类别）和纵轴（单位），避免混淆 “同比 / 环比”。
